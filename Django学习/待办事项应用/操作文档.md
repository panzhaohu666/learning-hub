## 2. 第2步：创建 App + 数据模型

### 2.1 概念

Django 项目由多个 **App** 组成，每个 App 是一个功能模块：

```
Project（项目）
├── App1（功能1）
├── App2（功能2）
└── ...
```

### 2.2 创建 tasks App

```bash
python manage.py startapp tasks
```

生成 `tasks/` 目录，包含：`models.py`、`views.py`、`admin.py` 等。

### 2.3 定义 Task 模型

编辑 `tasks/models.py`：

```python
from django.db import models
from django.contrib.auth.models import User


class Task(models.Model):
    """待办事项数据模型"""
    user = models.ForeignKey(User, on_delete=models.CASCADE, verbose_name="所属用户")
    title = models.CharField(max_length=200, verbose_name="标题")
    description = models.TextField(blank=True, null=True, verbose_name="描述")
    completed = models.BooleanField(default=False, verbose_name="是否完成")
    created_at = models.DateTimeField(auto_now_add=True, verbose_name="创建时间")

    class Meta:
        ordering = ['-created_at']    # 最新的排前面
        verbose_name = "待办事项"
        verbose_name_plural = "待办事项"

    def __str__(self):
        return self.title
```

**字段说明：**

| 字段 | 类型 | 参数 | 含义 |
|------|------|------|------|
| `user` | ForeignKey | `on_delete=CASCADE` | 关联用户，删用户时级联删任务 |
| `title` | CharField | `max_length=200` | 任务标题，最长200字符 |
| `description` | TextField | `blank=True` | 任务描述，可留空 |
| `completed` | BooleanField | `default=False` | 是否完成，默认未完成 |
| `created_at` | DateTimeField | `auto_now_add=True` | 创建时自动填入当前时间 |

> **`auto_now_add=True`**：创建记录时自动设置时间，之后不再更新。
> **`on_delete=models.CASCADE`**：删除用户时，自动删除他的所有任务。

### 2.4 注册 App

编辑 `todo_project/settings.py`，添加到 `INSTALLED_APPS`：

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'tasks',  # ← 添加这一行
]
```

### 2.5 生成并执行迁移

```bash
python manage.py makemigrations tasks    # 生成迁移文件（SQL草稿）
python manage.py migrate tasks           # 执行迁移（真正建表）
```

**两步走的原因**：`makemigrations` 只生成 SQL 脚本但不执行，`migrate` 才真正执行。这样你可以检查生成的 SQL 再决定是否执行。

## 3. 第3步：视图和 URL 路由

### 3.1 MVT 架构

```
浏览器请求 → URL路由 → View（视图）→ Model（数据库）
                                    ↓
                               Template（模板）→ HTML → 浏览器
```

### 3.2 编写视图函数

编辑 `tasks/views.py`：

```python
from django.shortcuts import render, redirect, get_object_or_404
from django.contrib.auth import authenticate, login, logout
from django.contrib.auth.forms import UserCreationForm
from django.contrib.auth.decorators import login_required
from django.contrib import messages
from .models import Task


# ── 认证相关 ──

def user_register(request):
    """用户注册"""
    if request.method == 'POST':
        form = UserCreationForm(request.POST)
        if form.is_valid():
            user = form.save()
            login(request, user)           # 注册后自动登录
            return redirect('task_list')
    else:
        form = UserCreationForm()
    return render(request, 'tasks/register.html', {'form': form})


def user_login(request):
    """用户登录"""
    if request.method == 'POST':
        username = request.POST['username']
        password = request.POST['password']
        user = authenticate(request, username=username, password=password)
        if user is not None:
            login(request, user)
            return redirect('task_list')
        else:
            messages.error(request, '用户名或密码错误')
    return render(request, 'tasks/login.html')


def user_logout(request):
    """用户登出"""
    logout(request)
    return redirect('login')


# ── 任务操作 ──

@login_required
def task_list(request):
    """首页：只显示当前用户的任务"""
    tasks = Task.objects.filter(user=request.user)
    return render(request, 'tasks/task_list.html', {
        'tasks': tasks,
        'completed_count': tasks.filter(completed=True).count(),
        'total_count': tasks.count(),
    })


@login_required
def task_create(request):
    """创建新任务"""
    if request.method == 'POST':
        title = request.POST.get('title')
        if title:
            Task.objects.create(
                user=request.user,
                title=title,
                description=request.POST.get('description', '')
            )
    return redirect('task_list')


@login_required
def task_toggle(request, pk):
    """切换完成状态（仅限自己的任务）"""
    task = get_object_or_404(Task, pk=pk, user=request.user)
    task.completed = not task.completed
    task.save()
    return redirect('task_list')


@login_required
def task_delete(request, pk):
    """删除任务（仅限自己的任务）"""
    task = get_object_or_404(Task, pk=pk, user=request.user)
    task.delete()
    return redirect('task_list')


@login_required
def task_clear_completed(request):
    """清除所有已完成任务"""
    Task.objects.filter(user=request.user, completed=True).delete()
    return redirect('task_list')
```

**关键函数的含义：**

| 函数 | 作用 |
|------|------|
| `render(request, 模板, 数据)` | 渲染模板返回 HTML |
| `redirect('路由名')` | 让浏览器跳转到另一个页面 |
| `get_object_or_404(Model, 条件)` | 查一条记录，找不到返回 404 |
| `@login_required` | 未登录用户自动跳转登录页 |
| `Task.objects.filter(user=request.user)` | 只查当前用户的数据 |

### 3.3 配置 App 路由

创建 `tasks/urls.py`：

```python
from django.urls import path
from . import views

urlpatterns = [
    # 任务操作
    path('', views.task_list, name='task_list'),
    path('create/', views.task_create, name='task_create'),
    path('toggle/<int:pk>/', views.task_toggle, name='task_toggle'),
    path('delete/<int:pk>/', views.task_delete, name='task_delete'),
    path('clear-completed/', views.task_clear_completed, name='task_clear_completed'),
    # 用户认证
    path('register/', views.user_register, name='register'),
    path('login/', views.user_login, name='login'),
    path('logout/', views.user_logout, name='logout'),
]
```

**路由语法：**
- `<int:pk>` — 捕获 URL 中的整数，传给视图的 `pk` 参数
- `name='task_list'` — 命名路由，模板中通过 `{% url 'task_list' %}` 引用

### 3.4 项目级路由接入

编辑 `todo_project/urls.py`：

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('tasks.urls')),  # 把 tasks 的所有路由接到根路径
]
```

**`include` 的工作原理**：项目路由写前缀，App 路由写后缀，Django 自动拼接。

```
项目: path('', include('tasks.urls'))
App:  path('login/', ...)
结果: http://localhost:8000/login/

项目: path('tasks/', include('tasks.urls'))
App:  path('login/', ...)
结果: http://localhost:8000/tasks/login/
```

### 3.5 设置登录跳转

编辑 `todo_project/settings.py`，文件末尾添加：

```python
LOGIN_URL = 'login'
LOGIN_REDIRECT_URL = 'task_list'
```

## 4. 第4步：前端页面美化

### 4.1 静态文件机制

Django 把 CSS / JS / 图片叫做**静态文件**，存放在 App 的 `static/` 目录。

```
tasks/static/tasks/style.css    ← CSS 文件
```

模板中引入：

```html
{% load static %}
<link rel="stylesheet" href="{% static 'tasks/style.css' %}">
```

### 4.2 模板语法速查

| 语法 | 用途 | 示例 |
|------|------|------|
| `{{ 变量 }}` | 输出变量 | `{{ task.title }}` |
| `{% if 条件 %}` | 条件判断 | `{% if task.completed %}...{% endif %}` |
| `{% for x in list %}` | 循环遍历 | `{% for task in tasks %}...{% endfor %}` |
| `{% url 'name' %}` | 反向生成 URL | `{% url 'task_toggle' task.pk %}` |
| `{% load static %}` | 加载静态文件标签 | 页面顶部 |
| `{% csrf_token %}` | CSRF 防护令牌 | 每个 POST 表单必须有 |

### 4.3 完整 URL 路由表

| URL | 视图 | 权限 | 作用 |
|-----|------|------|------|
| `/` | `task_list` | 需登录 | 任务列表 + 添加表单 |
| `/create/` | `task_create` | 需登录 | 创建任务（POST） |
| `/toggle/1/` | `task_toggle` | 需登录 | 切换完成状态 |
| `/delete/1/` | `task_delete` | 需登录 | 删除任务 |
| `/clear-completed/` | `task_clear_completed` | 需登录 | 清除所有已完成 |
| `/login/` | `user_login` | 公开 | 登录页 |
| `/register/` | `user_register` | 公开 | 注册页 |
| `/logout/` | `user_logout` | 公开 | 登出 |
| `/admin/` | Django Admin | 需管理员 | 后台管理 |

## 5. 第5步：Admin 后台管理

### 5.1 注册模型

编辑 `tasks/admin.py`：

```python
from django.contrib import admin
from .models import Task


@admin.register(Task)
class TaskAdmin(admin.ModelAdmin):
    list_display = ['title', 'completed', 'created_at']
    list_editable = ['completed']
    list_filter = ['completed', 'created_at']
    search_fields = ['title', 'description']
```

- `list_display` — 列表页显示哪些列
- `list_editable` — 直接在列表页编辑（打钩切换完成状态）
- `list_filter` — 右侧筛选面板
- `search_fields` — 顶部搜索框

## 6. 第6步：用户认证

### 6.1 数据隔离的核心逻辑

```python
# ❌ 错误：所有用户看到所有任务
tasks = Task.objects.all()

# ✅ 正确：只查当前用户的任务
tasks = Task.objects.filter(user=request.user)

# ✅ 创建时关联当前用户
Task.objects.create(user=request.user, title='...')

# ✅ 查/改/删时也限定用户（防越权）
task = get_object_or_404(Task, pk=pk, user=request.user)
```

如果有人尝试访问 `/toggle/别人的任务ID/`，`get_object_or_404` 会返回 404，因为 `user=request.user` 条件不匹配。

### 6.2 Django 内置认证函数

| 函数 | 作用 |
|------|------|
| `UserCreationForm` | 内置注册表单，含密码验证 |
| `authenticate(username, password)` | 验证用户名密码 |
| `login(request, user)` | 创建登录会话 |
| `logout(request)` | 清除会话 |
| `@login_required` | 装饰器，未登录自动跳转 |
| `request.user` | 当前登录的用户对象 |

## 核心技术回顾

```
                    浏览器
                       │
                       ↓
              ┌─────────────────┐
              │   urls.py       │  ① URL 路由匹配
              │   path('/', ...)│
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │   views.py      │  ② 视图处理逻辑
              │   task_list()   │     - 查数据库
              │                 │     - 验证权限
              └──┬──────────┬───┘
                 ↓          ↓
         ┌──────────┐ ┌──────────┐
         │ models.py│ │ 模板.html│  ③ 数据 + 模板 → HTML
         │ Task表   │ │  {{ }}   │
         └──────────┘ └────┬─────┘
                           ↓
                       HTML 响应
                           ↓
                        浏览器渲染
```

> 这是 Django 的 **MVT（Model-View-Template）** 完整数据流。
> - **Model** 定义数据结构
> - **View** 处理请求逻辑
> - **Template** 渲染 HTML
