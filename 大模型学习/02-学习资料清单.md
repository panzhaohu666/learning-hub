## 阶段一：大模型开发入门（第1-2周）


### A1-1
大模型基础概念 ⭐⭐⭐⭐⭐ 🌐📱 🕐 3天
**为什么推荐**：这是你进入大模型世界的第一扇门。Token、上下文窗口、Temperature 这三个概念会在后续所有阶段反复出现——你现在理解多深，后面就有多省力。
**内容**：什么是 LLM、Token、上下文窗口、Temperature、Top-p
训练 vs 推理 vs 微调的区别
**获取**：
- 知乎搜索 "大模型基础概念入门"
- 或直接看这篇文章（中文）：
https://zhuanlan.zhihu.com/p/634791131
**替代方案**（如果链接失效）：百度搜索"大模型基础概念 Token Temperature 上下文窗口"，任意一篇高质量中文博客即可。核心概念是通用的，不依赖特定文章。
**预计**：手机上 2-3 天读完

### A1-2
OpenAI Prompt Engineering Guide ⭐⭐⭐⭐⭐ 🌐📱 🕐 2天
**为什么推荐**：这是 Prompt Engineering 的"官方说明书"。里面 Every Prompt 策略都有示例代码，直接可跑。不是理论——是操作手册。
**内容**：Prompt 工程官方指南，Zero-shot / Few-shot / CoT 写法
**获取**：
https://platform.openai.com/docs/guides/prompt-engineering
**替代方案**：Anthropic 的 Prompt Engineering Guide（A1-3）覆盖了 80% 相同内容，如果 OpenAI 文档打不开（需科学上网），直接用 A1-3 替代。
**预计**：手机上 2 天读完

### A1-3
Anthropic Prompt Engineering Guide ⭐⭐⭐⭐ 🌐📱 🕐 1天
**为什么推荐**：Anthropic 的视角和 OpenAI 互补——更强调"给模型足够的上下文"而不是"给精确的指令"。两种理念都掌握，Prompt 能力才完整。
**内容**：Anthropic 的 Prompt 工程指南（与 OpenAI 互补视角）
**获取**：
https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
**替代方案**：Lil'Log 的 "Prompt Engineering" 文章（A2-8）是更好的系统性总结，适合在读完 A1-2 和 A1-3 后作为"复习+升华"。
**预计**：手机上 1 天读完

### A1-4
主流大模型对比 ⭐⭐⭐⭐ 🌐📱 🕐 2天
**为什么推荐**：你需要知道"工具箱里有哪些工具"。GPT-4 和 Qwen2-0.5B 的差距不是"好坏"——是"一个能开高速，一个能在你家电脑上跑"。了解每个模型的定位，才能选对工具。
**内容**：GPT-4 / Claude / DeepSeek / Qwen / ChatGLM 各自特点
**获取**：
- 知乎搜索 "2025 主流大模型对比"
- 或看 HuggingFace Open LLM Leaderboard：
https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard
**替代方案**：直接在各个模型的官方文档看 Overview 页：OpenAI 的 Models 页面、DeepSeek 的 API 文档、Qwen 的 GitHub README。
**预计**：手机上 2 天读完

### A1-5
GPT-3 论文（摘要+结论） ⭐⭐⭐ 📄📱 🕐 1天
**为什么推荐**：这篇论文是大模型时代的起点。不需要理解技术细节——读摘要和结论，感受一下 2020 年这个"暴力美学"想法有多震撼：把模型做大，Few-shot 能力就自然涌现了。
**内容**：Language Models are Few-Shot Learners
**获取**：
https://arxiv.org/abs/2005.14165
**预计**：手机上 1 天读完摘要和结论

### A1-6
Ollama 官方文档 ⭐⭐⭐⭐⭐ 🌐💻 🕐 实操
**为什么推荐**：Ollama 让你在 5 分钟内拥有一个本地大模型。不需要 Docker、不需要 CUDA 配置——一条命令下载，一条命令运行。这是你第一次和模型"面对面"聊天。
**内容**：安装、下载模型、命令行使用
**获取**：
https://github.com/ollama/ollama
https://ollama.com/library
**替代方案**：如果 Ollama 安装不了（Windows 权限问题等），用 LM Studio（https://lmstudio.ai）替代，同样简单。
**预计**：电脑上边看边装

### 📋 阶段一「15分钟速览」
如果今天只有 15 分钟，看这个：
1. **Token**：模型不认字，只认 Token。1 中文字 ≈ 1-2 Token。
2. **Temperature=0**：每问必答同样的，适合代码/翻译。**=1**：有创造性，适合写作。
3. **Zero-shot**：直接给任务。"翻译这句话"。**Few-shot**：给几个例子再让做。**CoT**：加一句"让我们一步一步思考"。
4. **Ollama**：`ollama pull qwen2:0.5b` 下载，`ollama run qwen2:0.5b` 对话。就这么简单。

https://pandas.pydata.org/docs/getting_started/index.html

### 📋 阶段二「15分钟速览」
1. **装饰器** = 给函数穿装备：`@timer` 让函数自动计时，`@retry` 让函数自动重试。不改变原函数代码。
2. **生成器** = 水龙头：用 `yield` 每次只产出一个值，不占内存。处理大文件必备。
3. **Pandas 六步清洗**：`head()`→`dropna()`→`drop_duplicates()`→`astype()`→过滤→`rename()`
4. **CoT 核心思想**：让模型写出推理过程再给答案。魔法话："让我们一步一步思考。"
5. **Coze/Dify**：低代码 Agent 平台。上传文档 → 配 Prompt → 发布。今天搭，明天就能用。

### 📋 阶段三「15分钟速览」
1. **d2l.ai** = 你的主力教材。手机看公式，电脑跑代码。
2. **Attention 公式**：`Attention(Q,K,V) = softmax(QK^T/√d_k)V`。Q=查询，K=键，V=值。Q 和 K 算相似度，用这个权重加权 V。
3. **Multi-Head**：把 QKV 切成 N 份，每份独立算 Attention，最后拼起来——让模型从不同角度"关注"输入。
4. **训练循环骨架**：`for batch in dataloader → pred = model(batch) → loss = criterion(pred, label) → optimizer.zero_grad() → loss.backward() → optimizer.step()`
5. **必读论文阅读顺序**：The Illustrated Transformer → Attention Is All You Need → The Illustrated GPT-2 → The Annotated Transformer

**为什么推荐**：理解 KV Cache 是理解"为什么大模型推理这么贵"的关键。Auto-regressive 生成时，每个新 token 都要重新计算 Attention——但 90% 的 K 和 V 矩阵和上一步是一样的！KV Cache 就是把这些重复计算的中间结果存起来复用。找 2-3 篇对照读，把 prefill vs decode 两个阶段搞清楚。
**内容**：理解 prefill vs decode 阶段
**获取**：
- HuggingFace 博客：
https://huggingface.co/blog/optimize-llm
- 或知乎搜索 "KV Cache 原理"
**预计**：手机上 2 天，找 2-3 篇对照读

### 📋 阶段五「15分钟速览」
1. **nanoGPT/model.py** = 你最重要的 300 行代码。目标：闭眼默写 CausalSelfAttention + MLP + Block + GPT 类。
2. **LoRA 核心思想**：大矩阵的变化 ≈ 小矩阵 A × 小矩阵 B。只训练 A 和 B，冻结原模型。
3. **QLoRA = 4-bit 量化 + LoRA**。3090 就能微调 70B 模型。
4. **DPO vs RLHF**：RLHF 需要训练 Reward Model 再用 PPO 优化（复杂、不稳定）。DPO 直接用偏好数据优化（简单、稳定）。
5. **vLLM PagedAttention**：把 KV Cache 分页管理，消灭显存碎片，吞吐量提升 10-20 倍。
