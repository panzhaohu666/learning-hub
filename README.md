## 🚀 先看这里：两个能跑的项目怎么启动

这是本仓库**仅有的两个可运行项目**。其余都是文档。启动步骤已实测通过（2026-11-04，Python 3.13.0 / Windows）。

### 项目一：待办事项应用（Django）

```bash
cd Django学习/待办事项应用

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt   # Django==6.1.3
python manage.py migrate
python manage.py runserver
```

打开 http://127.0.0.1:8000/ → 自动跳到登录页。先点「注册」建个账号，登进去就能增删改查。

跑测试：`python manage.py test`（21 个用例，覆盖登录隔离、越权访问、POST 约束）。

**注意：** Django 6.1 要求 **Python 3.12+**。用 3.11 及以下会装不上。

> 📖 想知道每一行代码怎么来的？看 [`Django学习/待办事项应用/操作文档.md`](./Django学习/待办事项应用/操作文档.md)（639 行，从建虚拟环境到部署配置逐步讲解，17KB）。这份文档此前 README 完全没提，实际上它才是最完整的使用说明。

### 项目二：图书管理 API（FastAPI）

```bash
cd API学习/demo

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt   # fastapi==0.162.0 + uvicorn==0.54.0
python server.py
```

打开 http://localhost:8000/docs → 交互式 API 文档，可以直接在网页上点「Try it out」测试每个端点。

跑测试的话，`server.py` 里没有内置测试，但可以直接对 `/docs` 里列出的 7 个业务端点手工验证（GET/POST/PUT/DELETE `/api/books`、GET `/api/books/{id}`、GET `/api/stats`、GET `/`）。数据存在内存里，重启就清空。

**注意：** FastAPI 要求 **Python 3.10+**。

> ⚠️ **两个项目默认都监听 8000 端口**（Django 的 `runserver` 和 `server.py` 里的 `uvicorn.run(port=8000)`）。同时跑会撞端口，第二个起不来。错开启动，或改一个端口：`python manage.py runserver 8001`。

### 两个项目的依赖都是锁定版本

`requirements.txt` 里 pin 了确切版本。**不要**直接 `pip install django` —— 那会装到最新版，行为可能和本文档不一致。这是本次补上的缺口：此前仓库里没有任何依赖声明文件。

## 🔥 快速预览：这份计划长什么样？

在往下翻之前，先看看你每天会面对什么——

**手机摸鱼时（上午 30 分钟）：**
```
📱 阅读主题：什么是大语言模型（LLM）

大语言模型本质上是一个"下一个词预测器"。
你给它一段文字，它预测接下来最可能出现的词是什么。

比如你输入 "今天天气真"，模型会计算：
  好 → 概率 60%    热 → 概率 25%
  冷 → 概率 10%    差 → 概率 5%

关键洞察：当模型足够大，"预测下一个词"这个简单任务
会迫使模型学会理解语法、推理、甚至逻辑。
```

**晚上电脑时（19:35-21:00）：**
```python
# 对着白天的知识写代码
from openai import OpenAI
client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

def chat():
    messages = [{"role": "system", "content": "你是一个友好的助手"}]
    while True:
        user_input = input("你: ")
        if user_input.lower() == 'quit': break
        messages.append({"role": "user", "content": user_input})
        response = client.chat.completions.create(
            model="qwen2:0.5b", messages=messages, temperature=0.7
        )
        reply = response.choices[0].message.content
        print(f"Bot: {reply}")
        messages.append({"role": "assistant", "content": reply})
```

**这就是你的日常——白天"预加载"，晚上"执行"。没有视频，没有手把手，只有你自己的头脑和键盘。**

## 📖 这是什么？

一个**开源自学平台**，围绕两大主线持续建设：

| 计划 | 时长 | 目标 | 每周投入 | 总时长 |
|------|------|------|----------|--------|
| 🧠 **6个月大模型学习计划** | 26 周 | 大模型开发工程师 / 算法工程师 | ~18.5h | 480h |
| 📝 **网络工程师备考计划** | 26 周 | 2027年上半年软考中级 · 两科 45+ | ~3h | 78h |

> ⚠️ 网络工程师这条线的预算很紧：**78 小时**（26 周 × 3 小时/周），约为常见备考投入（150–300h）的一半下限。计划的设计前提是**砍范围、不砍方法**，取舍顺序写在 [备考总纲第 2 节](./网络工程师/00-备考总纲.md)。

### 核心理念

```
白天手机 = 纯阅读输入（看/读/背/想）
晚上电脑 = 纯输出（写/训/调/测）
全程不依赖视频，只靠文字材料
```

### 为什么这样设计？

通勤路上看视频？信号差、耗流量、不能加速跳看、没法标注重点。
但文字材料可以：离线缓存 → 快速扫读 → 截图标注 → 随时重温。

更重要的是——**阅读是你自己的速度，视频是别人的速度。**
你可以在 30 秒内扫完一个已经理解的概念，也可以花 10 分钟反复推敲一段难懂的公式推导。视频做不到这种自由度。

## 🚀 如何使用

### 1. 克隆仓库

```bash
git clone https://github.com/panzhaohu666/learning-hub.git
cd learning-hub
```

### 2. 选择你的路线

- **只学大模型** → 从 `大模型学习/01-总纲-6个月大模型学习计划.md` 开始，按顺序走 7 个阶段
- **只备考网络工程师** → 从 `网络工程师/00-备考总纲.md` 开始，再看 `02-26周计划.md` 找到你这一周
- **想跑代码** → 直接看本文档顶部的[「两个能跑的项目怎么启动」](#-先看这里两个能跑的项目怎么启动)
- **双线并行**（推荐）→ 两份总纲都要看，里面有每周时间分配表

### 3. 跟着每周/每日指南走

大模型线是"每日指南"（按天，因为每周 18.5 小时撑得起每日强度），网络工程师线是"每周模板"（按周，因为每周只有 3 小时，拆到天会碎到无法执行）。

大模型线每个"阶段·每日学习指南"的结构：

```
📱 手机摸鱼（上午 30 分钟）
   ├── 核心知识点（直接看，不需要额外查资料）
   ├── 今日思考题（脑子里过一遍）
   └── 规划今晚要写什么

💻 晚上电脑（2 小时）
   ├── 回顾白天笔记（5 分钟）
   ├── 对着白天的知识写代码（30 分钟）
   ├── 核心任务（55 分钟）
   ├── 记录 + Obsidian 笔记（20 分钟）
   └── 规划明天（10 分钟）
```

## ❓ 常见问题（FAQ）

<details>
<summary><b>Q: 我只有手机，没有电脑，能学吗？</b></summary>

**不能。** 这份计划的核心是"手机输入 + 电脑输出"。学编程最终要动手写代码、训练模型，这些在手机上无法完成。如果你目前没有电脑，建议先攒一台（二手笔记本 ¥2000 就够前三个月），前三个月用 Google Colab 免费 GPU 跑实验。
</details>

<details>
<summary><b>Q: 我一点机器学习基础都没有，能直接开始吗？</b></summary>

**能。** 这份计划的前两周就是从零开始的——Token 是什么、Prompt 怎么写、怎么在本地跑一个模型。机器学习基础在第 8 周才正式开始，前面 7 周你在积累"手感"。前提是你至少会写 Python（函数、列表、字典、文件读写这些）。如果还不会，先花 2-3 周过一遍 `Python学习/Python基础完全指南.md`，再回来。
</details>

<details>
<summary><b>Q: 中途断了 2 周怎么办？</b></summary>

**从断掉的地方前一天重新开始。** 不要从头来——那会摧毁你的信心。也不要在断掉的地方直接继续——大脑需要"预热"。最好的做法：花 10 分钟把断掉前 3 天的 Obsidian 笔记看一遍，然后继续。计划第十四章有完整的"防崩策略"。
</details>

<details>
<summary><b>Q: 周六下午总被加班吃掉怎么办？</b></summary>

**把周六下午降级为"周六晚上 2 小时"。** 深度项目的代码可以拆成小块，分散到工作日的晚上完成。最关键的底线是：**允许降级，不允许归零**。只要这周至少 push 了一次代码到 GitHub，这周就没有白过。
</details>

<details>
<summary><b>Q: 阶段五训练 Mini-GPT 需要什么 GPU？</b></summary>

**AutoDL 租 RTX 3090，约 ¥2-3/小时。** 训练一个小型 GPT（几千万参数级别的）在 3090 上 1-2 小时就能跑完一个 epoch。整阶段五的 GPU 预算大约 ¥300-600。前四个阶段 Google Colab 免费 T4 就够了。
</details>

<details>
<summary><b>Q: 我能跳过某些阶段吗？</b></summary>

**阶段一和阶段二是所有后续阶段的基础，不能跳。** 阶段三的 Transformer 手写是整个计划的核心，不能跳。阶段六（多模态）是加分项，可以跳过不影响主线。阶段七面试准备和阶段五有重叠，可以灵活调整。简单来说：**一→二→三→五 是必走的主线**，四和六可以根据兴趣和进度调整。
</details>

<details>
<summary><b>Q: 这份计划和网上其他大模型教程有什么区别？</b></summary>

**大部分教程是"给你看"，这份计划是"让你做"。** 它不假设你有整块时间看视频，不假设你有顶配 GPU，不假设你能脱产。每一小时都经过真实的时间估算，每一个代码示例都经过本地验证。最核心的区别：它设计了"防崩策略"——承认你会累、会断、会想放弃，然后告诉你怎么爬起来。
</details>
