## 🔥 快速预览：这份计划长什么样？

在往下翻之前，先看看你每天会面对什么——

**手机摸鱼时（上午 30 分钟）：**
```
📱 阅读主题：什么是大语言模型（LLM）

大语言模型本质上是一个"下一个词预测器"。
你给它一段文字，它预测接下来最可能出现的词是什么。

比如你输入 "今天天气真"，模型会计算：
  好 → 概率 60%    热 → 概率 25%
  冷 → 概率 10%    差 → 概率 5%

关键洞察：当模型足够大，"预测下一个词"这个简单任务
会迫使模型学会理解语法、推理、甚至逻辑。
```

**晚上电脑时（19:35-21:00）：**
```python
# 对着白天的知识写代码
from openai import OpenAI
client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

def chat():
    messages = [{"role": "system", "content": "你是一个友好的助手"}]
    while True:
        user_input = input("你: ")
        if user_input.lower() == 'quit': break
        messages.append({"role": "user", "content": user_input})
        response = client.chat.completions.create(
            model="qwen2:0.5b", messages=messages, temperature=0.7
        )
        reply = response.choices[0].message.content
        print(f"Bot: {reply}")
        messages.append({"role": "assistant", "content": reply})
```

**这就是你的日常——白天"预加载"，晚上"执行"。没有视频，没有手把手，只有你自己的头脑和键盘。**

## 📖 这是什么？

这是一个**双线并行的自学计划**，包含两部分：

| 计划 | 时长 | 目标 | 每周投入 | 总时长 |
|------|------|------|----------|--------|
| 🧠 **6个月大模型学习计划** | 26 周 | 大模型开发工程师 / 算法工程师 | ~18.5h | 480h |
| 📝 **软件设计师备考计划** | 9 个月 | 2027年5月软考 · 上下午45+ | ~8h | 259h |

### 核心理念

```
白天手机 = 纯阅读输入（看/读/背/想）
晚上电脑 = 纯输出（写/训/调/测）
全程不依赖视频，只靠文字材料
```

### 为什么这样设计？

通勤路上看视频？信号差、耗流量、不能加速跳看、没法标注重点。
但文字材料可以：离线缓存 → 快速扫读 → 截图标注 → 随时重温。

更重要的是——**阅读是你自己的速度，视频是别人的速度。**
你可以在 30 秒内扫完一个已经理解的概念，也可以花 10 分钟反复推敲一段难懂的公式推导。视频做不到这种自由度。

## ❓ 常见问题（FAQ）

<details>
<summary><b>Q: 我只有手机，没有电脑，能学吗？</b></summary>

**不能。** 这份计划的核心是"手机输入 + 电脑输出"。学编程最终要动手写代码、训练模型，这些在手机上无法完成。如果你目前没有电脑，建议先攒一台（二手笔记本 ¥2000 就够前三个月），前三个月用 Google Colab 免费 GPU 跑实验。
</details>

<details>
<summary><b>Q: 我一点机器学习基础都没有，能直接开始吗？</b></summary>

**能。** 这份计划的前两周就是从零开始的——Token 是什么、Prompt 怎么写、怎么在本地跑一个模型。机器学习基础在第 8 周才正式开始，前面 7 周你在积累"手感"。前提是你至少会写 Python（函数、列表、字典、文件读写这些）。
</details>

<details>
<summary><b>Q: 中途断了 2 周怎么办？</b></summary>

**从断掉的地方前一天重新开始。** 不要从头来——那会摧毁你的信心。也不要在断掉的地方直接继续——大脑需要"预热"。最好的做法：花 10 分钟把断掉前 3 天的 Obsidian 笔记看一遍，然后继续。计划第十八章有完整的"防崩预案"。
</details>

<details>
<summary><b>Q: 周六下午总被加班吃掉怎么办？</b></summary>

**把周六下午降级为"周六晚上 2 小时"。** 深度项目的代码可以拆成小块，分散到工作日的晚上完成。最关键的底线是：**允许降级，不允许归零**。只要这周至少 push 了一次代码到 GitHub，这周就没有白过。
</details>

<details>
<summary><b>Q: 阶段五训练 Mini-GPT 需要什么 GPU？</b></summary>

**AutoDL 租 RTX 3090，约 ¥2-3/小时。** 训练一个小型 GPT（几千万参数级别的）在 3090 上 1-2 小时就能跑完一个 epoch。整阶段五的 GPU 预算大约 ¥300-600。前四个阶段 Google Colab 免费 T4 就够了。
</details>

<details>
<summary><b>Q: 我能跳过某些阶段吗？</b></summary>

**阶段一和阶段二是所有后续阶段的基础，不能跳。** 阶段三的 Transformer 手写是整个计划的核心，不能跳。阶段六（多模态）是加分项，可以跳过不影响主线。阶段七面试准备和阶段五有重叠，可以灵活调整。简单来说：**一→二→三→五 是必走的主线**，四和六可以根据兴趣和进度调整。
</details>

<details>
<summary><b>Q: 这份计划和网上其他大模型教程有什么区别？</b></summary>

**大部分教程是"给你看"，这份计划是"让你做"。** 它不假设你有整块时间看视频，不假设你有顶配 GPU，不假设你能脱产。每一小时都经过真实的时间估算，每一个代码示例都经过本地验证。最核心的区别：它设计了"防崩预案"——承认你会累、会断、会想放弃，然后告诉你怎么爬起来。
</details>
