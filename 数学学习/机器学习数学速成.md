## 一、为什么 ML 需要数学 + 学习策略

### 1.1 数学是工具，不是考试

先泼一盆冷水，也先给你松绑：**绝大多数人学机器学习数学失败，不是因为笨，而是因为用错了方法**。他们翻开一本《线性代数》教材，从向量空间的公理开始啃，啃到第二章就放弃了。

而工程师学数学的方式完全不同。工程师的问题是"我要让这条直线穿过这些点，怎么做？"，答案里碰巧用到了"梯度"。于是工程师去查梯度是什么，用代码验证一下，会用了，继续前进。

> 🧠 **核心心态**：数学是**工具箱**，不是**考试科目**。你不需要知道工具是怎么锻造的（定理证明），只需要知道**这个工具解决什么问题、怎么用**（直觉 + 代码）。本指南的一切内容都围绕这个原则组织。碰到不认识的符号，先跳过去看直觉解释，再回来——95% 的情况你根本不需要那个符号。

> 🚫 **明确不学的东西**：本指南**没有** ε-δ 极限证明，**没有**向量空间公理化，**没有**测度论，**没有**任何"定理-证明"结构。这些东西对写代码、训练模型没有直接帮助，等你真遇到了（大概率永远遇不到）再学。

### 1.2 ML 到底会用到哪些数学（总览表）

机器学习数学听起来吓人，但实际天天用的就四块。先看全景，再看细节：

| 数学分支 | 一句话直觉 | 在 ML 里解决什么问题 | 对应章节 |
|---------|-----------|---------------------|---------|
| **线性代数** | 一堆数字的排列与运算 | 数据的表示（向量/矩阵）、批量计算、神经网络层的计算 | 第二章 |
| **微积分** | 研究"变化" | 告诉模型"该往哪个方向调参数"（梯度下降） | 第三章 |
| **概率与统计** | 研究"不确定" | 让模型输出概率、从数据中估计参数（最大似然） | 第四章 |
| **信息论** | 研究"信息有多少" | 设计损失函数（交叉熵）、衡量模型好坏 | 第五章 |

> 💡 **Aha Moment**：这四个分支不是四个独立的科目，它们是同一条链子上的四环。数据先被装进**向量和矩阵**（线性代数）里；模型做出预测后，我们用一个基于**概率**的损失函数（信息论）来衡量错得有多离谱；然后微积分算出**梯度**（怎么调整参数）；最后梯度下降用这个方向更新参数。一个训练循环，四门数学各出场一次。你现在看不懂这条链没关系，读完全文再回来看这一节，你会会心一笑。

### 1.3 学习策略：用到什么学什么

> 📱 **策略一：以终为始**。你学数学的目的是读懂阶段三的代码。所以先花 10 分钟扫一眼 `05-阶段三上` 和 `06-阶段三下` 的目录，把里面出现的公式记下来：`y = wx + b`、`MSE = (1/n)Σ(ŷᵢ-yᵢ)²`、`σ(z) = 1/(1+e⁻ᶻ)`、`softmax(zᵢ) = e^zᵢ / Σe^zʲ`、`Attention(Q,K,V) = softmax(QKᵀ/√d_k)V`。这些就是你要学的全部数学的"目的地"。本指南每章末尾都会说"这对应 ML 里的什么"，就是帮你把数学和这些公式对上号。

> 📱 **策略二：先直觉，后公式，最后代码**。顺序不能乱。先问"这个玩意在解决什么问题"（直觉），再记公式（公式只是直觉的速记），最后跑代码验证（代码是公式的裁判）。如果你发现一个公式看完直觉还是不懂，说明它的前置知识还没学，往回找。

> 📱 **策略三：每个概念 20 分钟原则**。一个概念用 20 分钟还搞不懂，先标记跳过，学后面的。数学是高度耦合的，后面某个例子往往能反哺前面的概念。千万不要在一个概念上死磕两小时——那不是努力，是内耗。

> 📱 **策略四：用手敲，不用手抄**。所有代码块**手打**一遍（可以用自己的思路重写），不要复制粘贴。手打的过程中你会自然地发现"原来 softmax 是这么写的"。这和 Linux 指南、阶段三的"不要复制粘贴"哲学完全一致。

> ⚠️ **常见陷阱**：不要为了学数学而学数学。看到 "矩阵的特征值"、"希尔伯特空间"、"泰勒展开" 这些词，如果它没有出现在你的目标公式列表里，直接无视。本指南也不会讲它们。

## 二、线性代数

> 📱 **这一章是 ML 的"语言"**。数据在代码里是一个数组，在数学里就是一个向量或矩阵。线性代数就是研究"一堆数字怎么摆放、怎么运算"的学问。好消息是：它比初中代数还直观，因为它全都是具体的数字，没有任何抽象。坏消息（其实不是坏消息）是：它有很多看起来很绕的符号——但符号背后的意思都简单得离谱。

> 🎯 **本章目标**：学完你应能读懂 `y = wx + b`（这里 x、w 可以是向量），能看懂 `X @ w` 这种矩阵乘法，知道转置 `X.T`、单位矩阵 `np.eye`、逆矩阵 `np.linalg.inv` 是干嘛的，并且背下 2.9 节的矩阵求导速查表。这张表是你读阶段三所有梯度公式的"字典"。

### 2.1 标量：一个数

> 📱 **直觉**：标量就是单个数字，比如房价 250 万、今天温度 32 度。在机器学习里，标量通常用来表示"单个数值"，比如**学习率**（`lr = 0.01`）、**损失值**（`loss = 3.26`）、**偏置**（`b = 2.0`）。

> 📐 **公式与记法**：标量用小写斜体表示，如 `a`、`b`、`w`。你在阶段三看到的 `lr`、`loss`、`λ`（正则化系数）都是标量。

> 💻 **NumPy 验证**（建文件 `ch2_scalar.py`）：

```python
import numpy as np

# 用 np.float64 显式表示一个标量
lr = np.float64(0.01)
loss = np.float64(3.26)
print("学习率:", lr, "| 类型:", type(lr).__name__)

# 标量的运算和普通数字一模一样
print("lr * 10 =", lr * 10)          # 0.1
print("loss 的平方 =", loss ** 2)     # 10.6276
print("sqrt(loss) =", np.sqrt(loss)) # 约 1.81

# 检查：标量是 0 维的，没有"形状"
print("标量的 shape:", lr.shape, "| 维度 ndim:", lr.ndim)
```

> 📱 **这和 ML 有什么关系**：神经网络训练里的**学习率**（`lr`）、**损失值**（`loss`）、**正则化强度**（`λ`）全是标量。你在阶段三看到的第一行训练代码 `lr = 0.01`，就是一个标量。就这么简单。

### 2.2 向量：一列数

> 📱 **直觉**：向量就是**一串排好队的数字**。想象一列士兵，每个士兵是一个数字。比如一个学生的成绩单 [语文 90, 数学 85, 英语 88]，这就是一个 3 维向量。在 ML 里，**一个样本的特征就是一个向量**：比如"房价预测"的样本 [面积 80㎡, 卧室数 3, 楼龄 5年] 就是 3 维向量。

> 📱 **向量的两种直觉**（都要有）：
> - **数据的角度**：一列数字，表示一个样本的多个特征。
> - **几何的角度**：指向空间里某一点的一支箭。2 维向量 [3, 4] 就是从原点到点 (3,4) 的箭。箭的长度叫**模**（norm）。

> 📐 **公式与记法**：向量用小写粗体表示，如 `x = [x₁, x₂, x₃]`。向量的**模**（长度）：

> ||x|| = √(x₁² + x₂² + ... + xₙ²)

> 比如 `x = [3, 4]`，则 ||x|| = √(9+16) = 5。

> 💻 **NumPy 验证**（建文件 `ch2_vector.py`）：

```python
import numpy as np

# 一个 3 维向量（一个样本的 3 个特征）
x = np.array([90, 85, 88])          # 语文/数学/英语成绩
print("向量 x:", x)
print("形状 shape:", x.shape)        # (3,) 一维，3 个元素
print("第 0 个元素（语文）:", x[0])   # 90

# 向量的模（长度）：sqrt(90²+85²+88²)
norm = np.linalg.norm(x)
manual = np.sqrt(90**2 + 85**2 + 88**2)
print("np.linalg.norm:", norm, "| 手算:", manual)   # 两边应该相等

# 向量加法和数乘：逐元素运算
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print("a + b =", a + b)     # [5 7 9]  对应位置相加
print("2 * a =", 2 * a)     # [2 4 6]  每个元素乘以 2
```

> 📱 **这和 ML 有什么关系**：`05-阶段三上` 第 8 周的线性回归 `y = wx + b`，其中**一个样本的特征就是一个向量 x**（比如一张房子的多个属性）。而 `w`（权重）是另一个向量，`wx` 是它俩的**点积**（下一节）。整个数据集则是**一堆向量叠在一起**——那就是矩阵（2.4 节）。向量是 ML 数据的最小单位，请务必先把它搞熟。

### 2.3 点积：两个向量的"相似度"

> 📱 **直觉**：点积把两个同样长度的向量变成一个数字。它回答的问题："**这两个向量有多像，或者其中一个在另一个的方向上贡献了多少？**" 两个向量指向同一方向 → 点积大；指向相反方向 → 点积为负；互相垂直 → 点积为 0。

> 📐 **公式**：对应元素相乘，再求和。

> a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ

> 例：`a = [1, 2, 3]`, `b = [4, 5, 6]`，则 `a · b = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32`。

> 💡 **Aha Moment**：为什么 ML 里到处是点积？因为 `y = w·x + b` 的意思是："**每个特征按它的权重加权求和**"——工资高（特征大）且权重大 → 贡献多。点积就是"加权求和"的数学名字。神经网络里的每个神经元本质上就是一个点积 + 偏置。

> 💻 **NumPy 验证**（建文件 `ch2_dot.py`）：

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# 三种写法，结果一样
print("np.dot(a, b)      =", np.dot(a, b))   # 32
print("a @ b             =", a @ b)          # 32（@ 是点积/矩阵乘法的运算符）
print("手动 (sum a*b)    =", (a * b).sum())  # 32

# 点积 = 长度 × 长度 × 夹角的余弦
# 所以用"归一化"后的向量做点积，就是在算余弦相似度
x = np.array([3, 4])
y = np.array([6, 8])        # y = 2*x，方向完全相同
cos = np.dot(x, y) / (np.linalg.norm(x) * np.linalg.norm(y))
print("x 和 y 的余弦相似度:", cos)  # 1.0（同方向）

z = np.array([4, -3])       # 与 x 垂直
cos_z = np.dot(x, z) / (np.linalg.norm(x) * np.linalg.norm(z))
print("x 和 z 的余弦相似度:", cos_z)  # 约 0（垂直）

# 点积的几何验证：a·b = |a||b|cosθ，反解夹角
theta = np.arccos(np.dot(x, y) / (np.linalg.norm(x) * np.linalg.norm(y)))
print("夹角(弧度):", theta, "≈ 0（同方向夹角为 0）")
```

> 📱 **这和 ML 有什么关系**：点积出现在三个地方。① 线性回归 `y = w·x + b`（加权求和）；② 注意力机制 `Q @ K.T`（第 15 周，用"查询"和"键"的点积衡量两个词的相关度）；③ 余弦相似度（词向量、推荐系统里衡量"两个东西有多像"）。**"点积 = 相似度 = 加权求和"这个三位一体，请刻进脑子里**。

### 2.4 矩阵：一张数表

> 📱 **直觉**：矩阵就是把多个向量**横着叠在一起**形成的表格。行 = 样本，列 = 特征。比如 3 个学生、每科成绩，就是 3×3 的矩阵。矩阵在 ML 里就一个含义：**一批数据**。

> 📱 **为什么这个视角重要**：机器学习要"批量"处理数据（一次算 128 个样本），矩阵就是批量计算的容器。一次矩阵运算 = 同时处理所有样本。

> 📐 **记法**：矩阵用大写粗体，如 `X`（特征矩阵）、`W`（权重矩阵）。`X.shape = (3, 3)` 表示 3 行 3 列。`X[i, j]` 表示第 i 行第 j 列的元素。

> 💻 **NumPy 验证**（建文件 `ch2_matrix.py`）：

```python
import numpy as np

# 3 个学生 × 3 门课的成绩矩阵
X = np.array([
    [90, 85, 88],   # 学生 1
    [76, 92, 81],   # 学生 2
    [83, 79, 95],   # 学生 3
])
print("形状:", X.shape, "| 维度:", X.ndim)   # (3, 3) 2
print("学生 2 的成绩:", X[1])                 # [76 92 81]
print("英语成绩(第2列):", X[:, 2])           # [88 81 95]

# 矩阵逐元素运算：给所有成绩 +5 分
print("所有成绩加 5:\n", X + 5)

# 行向量/列向量的提取
print("第 1 行:", X[0, :].shape)   # (3,)
print("第 0 列:", X[:, 0].shape)   # (3,)

# 生成常用矩阵
print("全 1 矩阵:\n", np.ones((2, 3)))
print("全 0 矩阵:\n", np.zeros((2, 2)))
print("随机矩阵:\n", np.random.randn(2, 3))  # 标准正态随机数
```

> 📱 **这和 ML 有什么关系**：一个数据集（比如 128 张图片，每张 784 个像素）就是一个矩阵 `X`，形状 `(128, 784)`。权重也是矩阵 `W`。阶段三所有 `model(x)` 的调用，输入都是一个矩阵，PyTorch 里叫 Tensor，本质和矩阵一样（只是多了 batch 维）。**以后看到 shape，先分清哪一维是样本、哪一维是特征**，这是读所有 ML 代码的第一步。

### 2.5 矩阵乘法：矩阵的"引擎"

> 📱 **直觉**：矩阵乘法是线性代数最重要的运算，也是神经网络前向传播的核心。规则一句话：**结果矩阵的第 i 行第 j 列 = 左边矩阵第 i 行 和 右边矩阵第 j 列的 点积**。

> 📐 **形状规则（背下来）**：`A` 是 `(m, k)`，`B` 是 `(k, n)`，则 `A @ B` 是 `(m, n)`。**内维必须相等**（k == k），否则报错。这解释了为什么"注意矩阵的形状"是 ML 调试的第一课。

> 📐 **具体例子**：A 是 2×3，B 是 3×2：

> ```
> A = [1 2 3]      B = [7  8]
>     [4 5 6]          [9 10]
>                      [11 12]
>
> A@B 结果 (2,2):
> 第[0,0] = 1×7 + 2×9 + 3×11 = 58
> 第[0,1] = 1×8 + 2×10 + 3×12 = 64
> 第[1,0] = 4×7 + 5×9 + 6×11 = 139
> 第[1,1] = 4×8 + 5×10 + 6×12 = 154
> ```

> 💡 **Aha Moment**：把矩阵乘法理解为"**一批点积同时完成**"。`X @ W` 中，X 的每一行是一个样本，W 的每一列是一组权重。结果就是"每个样本 × 每组权重"，一次算完全部。`Linear(in, out)` 层就是 `y = X @ W.T + b`，其中 W 是 (out, in)。

> 💻 **NumPy 验证**（建文件 `ch2_matmul.py`）：

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])
B = np.array([[7, 8],
              [9, 10],
              [11, 12]])

C = A @ B
print("A@B 形状:", C.shape)            # (2, 3)@(3, 2) -> (2, 2)
print("A@B:\n", C)
print("验证第[0,0] = 1*7+2*9+3*11 =", C[0, 0])  # 58

# 用"批量点积"的视角验证：手动算每个元素 = 点积
print("第 0 行 × 第 0 列 =", np.dot(A[0], B[:, 0]))  # 58
print("第 1 行 × 第 1 列 =", np.dot(A[1], B[:, 1]))  # 154

# 一次处理一批样本：X (3个样本, 2特征) @ w (2,1)
X = np.array([[1., 2.], [3., 4.], [5., 6.]])   # 3 个样本
w = np.array([[0.5], [-1.0]])                    # 权重向量（列）
y = X @ w
print("批量线性计算 X@w:\n", y)   # (3,1) 每个样本一个输出
```

> ⚠️ **常见陷阱**：`A @ B` 和 `A * B` 完全不同！`@` 是矩阵乘法（行×列的点积求和），`*` 是逐元素相乘（对应位置相乘）。新手把 `*` 当矩阵乘法用，得到错误结果还不报错——这是 ML 调试里最阴的坑之一。**想知道模型在干嘛，先检查你的 `@` 和 `*` 用对没有。**

> 📱 **这和 ML 有什么关系**：神经网络前向传播 = 一串矩阵乘法。`y = X @ w` 是一次"线性变换"。第 10 周你学的 `nn.Linear(in, out)`、第 15 周 Attention 里的 `Q @ K.T`，本质都是矩阵乘法。**熟练掌握"内维相等，结果外维拼接"这条规则，你就能读懂任何网络层的形状变化。**

### 2.6 转置：翻个面

> 📱 **直觉**：转置就是把矩阵**翻个面**：行变成列，列变成行。就像把一张纸旋转 90 度。记法：`A` 的转置写作 `A.T` 或 `Aᵀ`。

> 📐 **规则**：`A` 是 `(m, n)`，则 `A.T` 是 `(n, m)`，且 `(A.T)[i, j] = A[j, i]`。

> 📱 **为什么转置那么常用**：因为矩阵乘法的"内维必须相等"规则，我们经常需要翻个面才能乘。比如"样本 × 权重"通常写作 `X @ W`，但如果你手头权重是按"特征×输出"存的，就得先转置：`X @ W.T`。**PyTorch 的 `nn.Linear` 内部就是这么干的**（`y = x @ W.T + b`）。

> 💻 **NumPy 验证**（建文件 `ch2_transpose.py`）：

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])       # (2, 3)
print("A.T:\n", A.T)            # (3, 2)
# 第一行 [1 2 3] 变成第一列
# [[1 4]
#  [2 5]
#  [3 6]]

print("形状:", A.shape, "->", A.T.shape)

# 转置两次回到原样
print("(A.T).T 等于 A:", np.array_equal((A.T).T, A))  # True

# 点积的转置写法：a·b = (a.T @ b) 对列向量成立
a = np.array([[1], [2], [3]])     # 列向量 (3,1)
b = np.array([[4], [5], [6]])
print("a.T @ b =", a.T @ b)       # 32，就是点积
print("np.dot(a.ravel(), b.ravel()) =", np.dot(a.ravel(), b.ravel()))
```

> 📱 **这和 ML 有什么关系**：① 特征工程里，特征矩阵经常需要转置来对齐形状；② `nn.Linear` 内部 `x @ W.T`；③ Attention 的 `K` 要做转置变成 `K.T` 才能和 `Q` 相乘（第 15 周）。**看到 `.T` 就想"翻面"，看到 `@` 就检查内维**。

### 2.7 单位矩阵：数字 1 的矩阵版

> 📱 **直觉**：单位矩阵（identity matrix）是对角线上全是 1、其余全是 0 的方阵，记作 `I`。它就像矩阵世界里的数字 1：**任何矩阵乘以它，等于没乘**。

> 📐 **公式**：`I @ A = A`，`A @ I = A`。单位矩阵在数学推导里用来"保持原样"，是化简公式的占位符。

> 💻 **NumPy 验证**（建文件 `ch2_identity.py`）：

```python
import numpy as np

I = np.eye(3)
print("3×3 单位矩阵:\n", I)
# [[1. 0. 0.]
#  [0. 1. 0.]
#  [0. 0. 1.]]

A = np.array([[2, 1],
              [0, 3],
              [5, 7]])
I2 = np.eye(2)
print("A @ I2:\n", A @ I2)          # 等于 A
print("等于 A:", np.allclose(A @ I2, A))   # True

# 单位矩阵在"残差连接"里的角色预演：
# 第 15 周 y = x + f(x)，如果 f 想"什么都不做"，I 就是那个"什么都不做"的矩阵
print("I @ x = x:", np.allclose(I @ np.array([1., 2., 3.]), np.array([1., 2., 3.])))
```

> 📱 **这和 ML 有什么关系**：单位矩阵的直接用途不多（主要在正则化 `L2 = λ·wᵀw` 和数学推导里），但**残差连接**（`x + f(x)`，第 15 周 Transformer 的灵魂）在数学上可以理解为"让梯度短路通过"——思想上和"乘以 I 不改变任何东西"一脉相承。看到 `np.eye` 知道它是"不干活的矩阵"就够了。

### 2.8 逆矩阵：矩阵的"除法"

> 📱 **直觉**：对数字来说，`2 × (1/2) = 1`。逆矩阵就是矩阵的"倒数"：`A @ A⁻¹ = I`。有了它，理论上可以"解方程"：如果 `A @ x = b`，两边左乘 `A⁻¹` 得 `x = A⁻¹ @ b`。

> 📱 **但 ML 里几乎不用逆矩阵**——为什么？因为求逆计算量大、数值不稳定，而且很多矩阵**没有逆**（叫"奇异矩阵"）。ML 的实际做法是：能用梯度下降就不用解析解。所以你只需理解逆矩阵"是什么"，不需要会算。

> ⚠️ **常见陷阱**：只有**方阵**（行列数相等）才可能有逆。长方形矩阵没有逆。而且即便方阵，如果某行是其它行的线性组合（线性相关），它也没有逆——`np.linalg.inv` 会直接报错 `LinAlgError: Singular matrix`。**看到这个报错别慌，意思是"这个矩阵没有逆"，换个思路即可。**

> 💻 **NumPy 验证**（建文件 `ch2_inverse.py`）：

```python
import numpy as np

# 一个 2×2 矩阵
A = np.array([[4., 7.],
              [2., 6.]])
A_inv = np.linalg.inv(A)
print("A⁻¹:\n", A_inv)

# 验证 A @ A⁻¹ = I（浮点数下用 allclose 比较）
print("A @ A⁻¹ ≈ I:", np.allclose(A @ A_inv, np.eye(2)))   # True

# 解方程 A @ x = b 的例子
b = np.array([1., 2.])
x_inv = A_inv @ b          # 用逆矩阵
x_solve = np.linalg.solve(A, b)   # 用 solve（数值更稳，ML 里推荐这个）
print("用逆矩阵解:", x_inv)
print("用 solve 解:", x_solve)
print("验证 A @ x = b:", np.allclose(A @ x_solve, b))       # True

# 演示奇异矩阵（没有逆）
try:
    np.linalg.inv(np.array([[1., 2.], [2., 4.]]))  # 第二行 = 2×第一行
except np.linalg.LinAlgError as e:
    print("奇异矩阵报错（预期内）:", e)
```

> 📱 **这和 ML 有什么关系**：线性回归有一个"解析解"公式 `w = (XᵀX)⁻¹Xᵀy`，它就用到了逆矩阵。但阶段三会让你**用梯度下降**而不是这个公式——因为当特征很多、数据很大时，求逆 `(XᵀX)⁻¹` 慢且不稳定，而梯度下降对任何规模都能跑。**记住：逆矩阵存在，但它不是 ML 的主角。主角是梯度下降（第三章）。**

### 2.9 矩阵求导结果速查表（背下来）

> 📱 **这一节是全指南最重要的一节**。阶段三里的所有梯度公式，都是下面这几条规则的组合。**不要推导，背结果，用代码验证**。这是"数学只是工具"的最佳体现。

> 📱 **先建立一个直觉**：函数 `loss(w)` 对 `w` 求导，就是问"w 稍微动一点点，loss 会怎么变"。结果是**一个和 w 形状相同的向量/矩阵**，里面的每个元素是"w 的这个分量对 loss 的影响"。

> 📐 **ML 里出现频率最高的 5 个求导结果**：

> **① `loss = w²`（标量）**
> d(loss)/dw = 2w
> 对应：L2 正则化项 `λ·Σwᵢ²` 的梯度。

> **② `loss = (ŷ - y)²`（标量）**
> 记 `e = ŷ - y`（误差），则 d(loss)/dŷ = 2e = 2(ŷ - y)
> 对应：MSE 的核心导数。误差越大，梯度越大。

> **③ `y = wx + b`，MSE = (1/n)Σ(wxᵢ + b - yᵢ)²`**
> ∂MSE/∂w = (2/n) Σ (wxᵢ + b - yᵢ)·xᵢ
> ∂MSE/∂b = (2/n) Σ (wxᵢ + b - yᵢ)
> 对应：第 8 周线性回归的梯度。**记忆口诀：∂w = 误差×输入，∂b = 误差。**

> **④ `σ(z) = 1/(1+e⁻ᶻ)`（sigmoid）**
> dσ/dz = σ(z)·(1 - σ(z))
> 对应：逻辑回归反向传播的第一环，也是"梯度消失"的根源（两端导数≈0）。

> **⑤ softmax + 交叉熵（多分类）**
> 若 `P` 是 softmax 输出，`Y` 是 one-hot 标签，则损失对 logits 的梯度 = P - Y
> 对应：第 11 周手写 Softmax 回归。**这条规律优雅得离谱：梯度 = 预测 - 真实。**

> 💻 **NumPy 验证**（建文件 `ch2_deriv_table.py`）：

```python
import numpy as np

# 用"数值梯度"验证每条公式：导数 ≈ (f(x+h) - f(x-h)) / (2h)
# 这是本指南最重要的验证工具，后面每章都会用到它
def num_grad(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

# ① d(w²)/dw = 2w
w = 3.0
print("① d(w²)/dw 解析 =", 2 * w, "| 数值 =", num_grad(lambda t: t**2, w))   # 6, 6

# ③ MSE 对 w 的梯度：用一个小数据集验证
X = np.array([1., 2., 3.])
y = np.array([2.1, 3.9, 6.2])
def mse_w(w_val, b_val):
    return ((w_val * X + b_val - y) ** 2).mean()
w0, b0 = 2.0, 0.5
# 解析梯度（公式 ③）
grad_w_analytic = (2 / len(X)) * ((w0 * X + b0 - y) * X).sum()
grad_b_analytic = (2 / len(X)) * (w0 * X + b0 - y).sum()
# 数值梯度
grad_w_numeric = num_grad(lambda v: mse_w(v, b0), w0)
grad_b_numeric = num_grad(lambda v: mse_w(w0, v), b0)
print("③ ∂MSE/∂w 解析 =", grad_w_analytic, "| 数值 =", grad_w_numeric)
print("③ ∂MSE/∂b 解析 =", grad_b_analytic, "| 数值 =", grad_b_numeric)

# ④ sigmoid 导数 = σ(1-σ)
def sig(z):
    return 1 / (1 + np.exp(-z))
z0 = 0.7
print("④ sigmoid' 解析 =", sig(z0) * (1 - sig(z0)),
      "| 数值 =", num_grad(sig, z0))   # 约 0.2217

# ⑤ softmax+交叉熵：梯度 = P - Y（第 7.4 节会完整验证）
logits = np.array([2.0, 1.0, 0.1])
z = logits - logits.max()
P = np.exp(z) / np.exp(z).sum()          # softmax
Y = np.array([1.0, 0.0, 0.0])            # 真实标签是第 0 类
print("⑤ softmax 输出 P =", np.round(P, 4), "| 求和 =", P.sum())
print("⑤ 梯度 P - Y =", np.round(P - Y, 4))
```

> 📱 **这份表就是你的"字典"**：阶段三里看到任何梯度公式，先到这张表里找"这是哪条的变体"。比如逻辑回归的梯度 `∂Loss/∂w = (ŷ - y)·x`，就是 ⑤ 的二元特例（第 5 章会展示为什么）。**学完本章，你至少要把 ①③④⑤ 四条默写出来。**

## 三、微积分

> 📱 **这一章是"梯度下降"的数学底座**。机器学习的全部训练过程，可以浓缩成一个动作：**不停地用"导数"告诉你该往哪个方向调参数**。所以微积分在 ML 里只有一个角色——算出"调整方向"。别被"微积分"这个名字吓到，我们要用的只有三个工具：**导数（变化率）、梯度（多维变化率）、链式法则（嵌套函数的变化率）**。

> 🎯 **本章目标**：学完你应能①解释"导数是变化率"并用代码验证；②读懂 2.9 节速查表里每条公式；③看到 `∂MSE/∂w` 这种符号知道它表示"对 w 求偏导"；④用链式法则解释 `loss.backward()` 在算什么。就这四个，没有更多。

### 3.1 导数：变化率

> 📱 **直觉（先忘掉一切公式）**：导数回答一个特别朴素的问题——"**输入变一点点，输出变多少？**"

> 📐 **用开车类比**：你在高速上开 120 km/h，这个"120"就是"位置随时间的变化率"，也就是位置的导数。如果你踩一脚油门到 140，变化率变大了。导数就是"此时此地的瞬间变化率"。

> 📐 **用数学语言**：函数 `f(x)` 在点 `x` 的导数，记作 `f'(x)` 或 `df/dx`，定义为"x 动了一点点 h，f 动了多少，再除以 h"：

> f'(x) = lim(h→0) (f(x+h) - f(x)) / h

> 📱 **对 ML 最重要的洞察**：导数还告诉你"**往哪边动，f 会变大/变小**"：
> - 导数 > 0：x 增大 → f 增大（往右走是上坡）
> - 导数 < 0：x 增大 → f 减小（往右走是下坡）
> - 导数 = 0：这里是"山顶"或"谷底"（梯度为零点）
>
> **梯度下降（第 8 周的明星算法）就是靠这条规则找谷底的**：站在当前点，问导数"哪个方向是下坡"，往那个方向走一小步，再问，再走…… 这就是 `05-阶段三上` 里"盲人下山"故事的全部数学。

> 💻 **NumPy 验证**（建文件 `ch3_derivative.py`）：

```python
import numpy as np

# f(x) = x²，它在 x=2 处的导数应该是 4（因为 d(x²)/dx = 2x）
def f(x):
    return x ** 2

x = 2.0
h = 0.001   # 让"一点点"足够小

# 用"差商"近似导数：(f(x+h) - f(x)) / h
slope = (f(x + h) - f(x)) / h
print(f"x=2 处，(f(x+h)-f(x))/h = {slope:.4f}")   # 约 4.001
print(f"解析导数 2x = {2 * x}")                    # 4

# 更精确的"中心差商"：(f(x+h) - f(x-h)) / (2h)
slope_center = (f(x + h) - f(x - h)) / (2 * h)
print(f"中心差商 = {slope_center:.6f}")            # 更接近 4.000001

# 直觉验证：导数 >0 表示上坡
# 在 x=2 处，x 增大，f 增大
print(f"f(2.001)={f(2.001):.4f} > f(2)={f(2):.4f}，导数正，是上坡")

# 画出"切线"的思想：导数是曲线的切线斜率
# 切线方程 y = f(x0) + f'(x0)(x - x0)
x0 = 2.0
tangent_x = np.array([1.5, 2.5])
tangent_y = f(x0) + 2 * x0 * (tangent_x - x0)
print("切线在 x=1.5 处的值:", tangent_y[0], "（这就是线性近似）")
```

> 📱 **这和 ML 有什么关系**：训练就是最小化 `loss(w)`。`loss` 对 `w` 的导数告诉你"w 该往左还是往右调"。第 8 周的更新公式 `w = w - lr × ∂loss/∂w`，那个减号就是为了"往导数相反的（下坡）方向走"。**"导数 = 方向指示牌"，这是本章最重要的心态转换。**

### 3.2 常见导数表

> 📱 **ML 里会反复出现的导数就这几条**。不要背推导，背结果（最好先自己用代码验证一遍，3.3 节有完整验证代码）。

> 📐 **导数速查表**：

| 函数 f(x) | 导数 f'(x) | ML 里出现在哪 |
|-----------|-----------|--------------|
| `c`（常数） | `0` | 常数项 |
| `x` | `1` | 线性项 |
| `x²` | `2x` | **L2 正则化、MSE** |
| `xⁿ` | `n·xⁿ⁻¹` | 多项式 |
| `eˣ` | `eˣ` | **softmax、交叉熵**（指数函数导数不变，超好算） |
| `ln(x)` | `1/x` | 交叉熵里的 log 的"原函数" |
| `sin(x)` | `cos(x)` | 位置编码（第 15 周） |
| `1/x` | `-1/x²` | 归一化、倒数 |

> 📐 **三条"操作规则"**（比单条函数更常用，因为复杂函数都由它们组合出来）：

> **加法法则**：(f + g)' = f' + g' —— 分开求导再加。

> **常数倍数**：(c·f)' = c·f' —— 常数可以直接提出来。比如 `(3x²)' = 6x`。

> **乘法法则**（少见但要知道存在）：(f·g)' = f'·g + f·g'。

> 💡 **Aha Moment**：看 eˣ 那行——`(eˣ)' = eˣ`。这条性质是 softmax 梯度计算简洁优美的根源。第 5 章你会发现，交叉熵选对数 log 也是为了求导时把 `1/p` 和 `p'` 约掉。**数学家在设计这些公式时，刻意让求导"变简单"——这解释了为什么 ML 用 e 和 log。**

### 3.3 用 NumPy 验证每一个导数

> 💻 **建文件 `ch3_deriv_table.py`**：把 3.2 的每一条都用"中心差商"验证一遍。这是让你真正"信"这些公式的唯一方法——不要相信任何你不验证的公式。

```python
import numpy as np

def num_grad(f, x, h=1e-6):
    """数值梯度：用中心差商近似导数"""
    return (f(x + h) - f(x - h)) / (2 * h)

x = 2.0
cases = [
    ("常数   f(x)=5",     lambda t: 5.0,              0.0),
    ("一次   f(x)=x",     lambda t: t,                1.0),
    ("二次   f(x)=x²",    lambda t: t**2,             2*x),
    ("三次   f(x)=x³",    lambda t: t**3,             3*x**2),
    ("指数   f(x)=eˣ",    lambda t: np.exp(t),        np.exp(x)),
    ("对数   f(x)=ln(x)", lambda t: np.log(t),        1/x),
    ("正弦   f(x)=sin(x)",lambda t: np.sin(t),        np.cos(x)),
    ("倒数   f(x)=1/x",   lambda t: 1/t,             -1/x**2),
]

for name, f, analytic in cases:
    numeric = num_grad(f, x)
    print(f"{name:14s} 解析={analytic:12.6f}  数值={numeric:12.6f}  差={abs(analytic-numeric):.2e}")

# 加法法则验证：(x² + 3x)' 在 x=2 = 2x + 3 = 7
f = lambda t: t**2 + 3*t
print("加法法则  (x²+3x)' 解析=7, 数值=", num_grad(f, 2.0))

# 常数倍数验证：(5x³)' 在 x=2 = 15x² = 60
f = lambda t: 5*t**3
print("常数倍数  (5x³)' 解析=60, 数值=", num_grad(f, 2.0))
```

> 📱 **验证结果应该是什么样**：每一行"解析"和"数值"的小数前 6 位基本一致，差值在 `1e-8` 量级。看到这个结果，你就知道导数表**没骗你**——它确实是"函数在一点的变化率"。

> 💡 **Aha Moment**：注意 `num_grad` 这个工具——它不需要任何求导公式，只需要能计算函数值。**这就是 PyTorch Autograd 的雏形！** `loss.backward()` 干的事在思想上和 `num_grad` 一样：算"参数动一点点，loss 怎么变"。只不过 Autograd 用的是精确的链式法则（3.6 节），而不是近似。**你在 3.3 节写的这个函数，是你理解 Autograd 的第一块基石。**

### 3.4 偏导数：多个方向的"变化率"

> 📱 **直觉**：前面的函数只有一个自变量 `x`。但 loss 往往依赖很多参数：`loss(w, b)`。偏导数就是"**只动其中一个变量，其它全部按住不动**"，看函数怎么变。

> 📱 **一个生活类比**：你的体重是"吃多少"和"运动多少"的函数。问"多吃一碗饭，体重涨多少？"——按住运动不变，只看吃的效应，这就是体重对"吃"的偏导数。同理可以问体重对"运动"的偏导数。

> 📐 **记法**：`∂loss/∂w` 读作"loss 对 w 的偏导"。`∂` 是"偏导"符号。计算时把其它变量当常数。

> 📐 **例**：`f(w, b) = w² + 3wb`：
> - ∂f/∂w = 2w + 3b（把 b 当常数）
> - ∂f/∂b = 3w（把 w 当常数）

> 💻 **NumPy 验证**（建文件 `ch3_partial.py`）：

```python
import numpy as np

def f(w, b):
    return w**2 + 3*w*b   # 这就是 loss(w,b)

def num_partial_w(f, w, b, h=1e-6):
    return (f(w + h, b) - f(w - h, b)) / (2 * h)

def num_partial_b(f, w, b, h=1e-6):
    return (f(w, b + h) - f(w, b - h)) / (2 * h)

w, b = 2.0, 5.0
# 解析（把另一个变量当常数）
dw_analytic = 2*w + 3*b    # 4 + 15 = 19
db_analytic = 3*w          # 6
print(f"∂f/∂w 解析 = {dw_analytic}, 数值 = {num_partial_w(f, w, b):.6f}")
print(f"∂f/∂b 解析 = {db_analytic}, 数值 = {num_partial_b(f, w, b):.6f}")

# 关键直觉：∂f/∂b 计算时，w 被"按住"了
# 对比：如果 w 从 2 变成 3，∂f/∂b 会跟着变（因为公式里有 w）
print(f"w=3 时 ∂f/∂b = {3*3}（说明偏导是'在某个点上'的值）")
```

> 📱 **这和 ML 有什么关系**：`loss(w, b)` 就是一个有两个参数的函数。`05-阶段三上` 里线性回归的梯度公式 `∂MSE/∂w` 和 `∂MSE/∂b` 就是两个偏导数。**梯度下降一次更新全部参数，每个参数都要算一个偏导数。** 你看到的所有 `∂` 符号，都表示"对这一个变量求导，其它按住不动"。

### 3.5 梯度：把所有偏导数组装起来

> 📱 **直觉**：把函数对所有参数的偏导数**打包成一个向量**，这个向量就叫**梯度**。梯度向量告诉你的不是"往某个方向变"，而是"**朝哪个方向走，函数涨得最快**"。

> 📱 **为什么梯度的方向是"最陡上坡"**：这是梯度的核心性质，不需要证明，用一个例子感受即可。你在山坡上，梯度向量的方向 = 最陡峭的上坡方向。所以梯度下降的更新是 `参数 = 参数 - 学习率 × 梯度`：**沿着梯度反方向走（下坡），每一步都走最陡的下坡路**。

> 📐 **公式**：对 `loss(w₁, w₂, ..., wₙ)`，梯度是：

> ∇loss = [ ∂loss/∂w₁, ∂loss/∂w₂, ..., ∂loss/∂wₙ ]

> 梯度下降更新（第 8 周的核心，先混个脸熟）：

> w ← w - lr × ∇loss(w)

> 💻 **NumPy 验证**（建文件 `ch3_gradient.py`）：

```python
import numpy as np

# 一个"碗形"损失函数 loss(w1,w2) = w1² + 2*w2²
# 它的最小值在 (0,0)，梯度就是指向"爬升最快"的方向
def loss(w):
    return w[0]**2 + 2*w[1]**2

def grad_loss(w):
    return np.array([2*w[0], 4*w[1]])   # 解析梯度

def num_grad(f, w, h=1e-6):
    g = np.zeros_like(w)
    for i in range(len(w)):
        wp = w.copy(); wp[i] += h
        wm = w.copy(); wm[i] -= h
        g[i] = (f(wp) - f(wm)) / (2*h)
    return g

w = np.array([3.0, 1.0])
g_analytic = grad_loss(w)
g_numeric = num_grad(loss, w)
print("解析梯度:", g_analytic)     # [6 4]
print("数值梯度:", np.round(g_numeric, 6))
print("两者一致:", np.allclose(g_analytic, g_numeric))

# 验证"梯度指向最陡上坡"：朝梯度方向走一小步，loss 涨得最多
# （梯度方向是最陡方向是"无穷小步长"下的结论，所以用小步长 h=0.01）
h = 0.01
loss_up = loss(w + h * g_analytic / np.linalg.norm(g_analytic)) - loss(w)
rng = np.random.default_rng(0)
random_incs = []
for _ in range(500):
    d = rng.normal(size=2); d /= np.linalg.norm(d)
    random_incs.append(loss(w + h * d) - loss(w))
random_incs = np.array(random_incs)
print(f"沿梯度方向 loss 增量: {loss_up:.6f}")
print(f"随机方向平均增量: {random_incs.mean():.6f}，最大才 {random_incs.max():.6f}")
print("→ 梯度方向 > 全部 500 个随机方向:", loss_up > random_incs.max(), "✓")

# 梯度下降：沿着梯度反方向走，找到谷底 (0,0)
w_cur = np.array([3.0, 2.0])
lr = 0.1
for step in range(50):
    w_cur = w_cur - lr * grad_loss(w_cur)
    if step % 10 == 0:
        print(f"step {step:2d}: w={np.round(w_cur, 4)}, loss={loss(w_cur):.6f}")
print("最终位置（应接近 0,0）:", np.round(w_cur, 4))
```

> 📱 **这和 ML 有什么关系**：**梯度下降就是 ML 训练的"发动机"**。第 8 周手写线性回归时，你算 `∂MSE/∂w` 和 `∂MSE/∂b` 然后 `w -= lr*grad`，那就是在"沿着梯度反方向下山"。第 10 周 PyTorch 的 `loss.backward()` 帮你算出梯度，`optimizer.step()` 做 `w -= lr*grad`。**你能手写这个循环，PyTorch 的训练循环就只是把它自动化了。**（3.6 节我们看看 loss 更复杂时，这个梯度怎么算。）

### 3.6 链式法则：反向传播的数学心脏

> 📱 **直觉**：链式法则回答的问题："**如果 A 影响 B，B 影响 C，那 A 对 C 的影响是多大？**" 答案：把每一段的变化率乘起来。

> 📐 **公式**：如果 `y = f(u)` 且 `u = g(x)`，则

> dy/dx = dy/du × du/dx

> 📱 **生活类比（蛋糕工厂）**：面粉 → 面团 → 蛋糕。面粉量 x 变了，面团 u 变（du/dx）；面团变了，蛋糕 y 变（dy/du）。那么"面粉一变，蛋糕变多少" = 两段相乘。**这就是反向传播的骨架：误差从最后一层往回传，每一层把自己的"变化率"乘上去。**

> 📐 **一个具体例子**（后面会反复用）：`z = (2x + 1)²`。
> 拆成两步：`u = 2x + 1`，`z = u²`。
> - du/dx = 2
> - dz/du = 2u = 2(2x+1)
> - 所以 dz/dx = dz/du × du/dx = 2(2x+1) × 2 = 8x + 4
> - 在 x=3 处：dz/dx = 28

> 💻 **NumPy 验证**（建文件 `ch3_chain.py`）：

```python
import numpy as np

# 链式法则验证：z = (2x+1)², 解析 dz/dx = 8x+4
x = 3.0

def z_of(x):
    u = 2*x + 1
    return u**2

def dz_dx_analytic(x):
    return 8*x + 4   # 链式法则乘出来的结果

# 分步验证（链式法则的每一步）
u = 2*x + 1
du_dx = 2
dz_du = 2*u                     # d(u²)/du
dz_dx = dz_du * du_dx           # 链式法则：相乘
print(f"u={u}, du/dx={du_dx}, dz/du={dz_du}")
print(f"链式法则 dz/dx = {dz_dx}")          # 28
print(f"解析公式 8x+4 = {dz_dx_analytic(x)}")  # 28
print(f"数值验证 = {(z_of(x+1e-6)-z_of(x-1e-6))/(2e-6):.6f}")  # ≈28

# 多个自变量：z = (w1*x + w2)² 对 w1 的偏导 = 2(w1*x+w2)*x
w1, w2, xv = 2.0, 1.0, 3.0
z = lambda w1, w2: (w1*xv + w2)**2
dz_dw1 = 2*(w1*xv + w2)*xv     # 链式法则：d(z²)/d(inner) × d(inner)/dw1
dz_dw2 = 2*(w1*xv + w2)*1.0
print(f"∂z/∂w1 = {dz_dw1}（数值验证 {(z(w1+1e-6,w2)-z(w1-1e-6,w2))/(2e-6):.6f}）")
print(f"∂z/∂w2 = {dz_dw2}（数值验证 {(z(w1,w2+1e-6)-z(w1,w2-1e-6))/(2e-6):.6f}）")
```

> 📱 **这和 ML 有什么关系**：神经网络就是一个巨大的嵌套函数：`loss = f(f(f(x, w₁), w₂), w₃)`。反向传播就是**用链式法则从最后往前逐层乘**，算出每一层的权重该往哪调。`06-阶段三下` 第 12 周的手写反向传播，代码本质上就是这句话。

### 3.7 从链式法则到反向传播

> 📱 **用一个 2 层小网络走一遍全流程**（这是 `06-阶段三下` 第 12 周手写反向传播的迷你版，这里只讲数学，第 7 章会有完整代码）。

> 📐 **网络结构**：`x → z₁ = w₁x + b₁ → a₁ = ReLU(z₁) → ŷ = w₂a₁ → loss = ½(ŷ - y)²`

> 📱 **正向（前向传播）**：输入 x 一层层算上去，得到预测 ŷ 和损失 loss。**反向（反向传播）**：从 loss 出发，用链式法则往回乘。

> 📐 **反向传播的四步链式乘法**（数字例子：x=1, w₁=2, b₁=0.5, w₂=3, 目标 y=9）：

> ① `∂loss/∂ŷ = ŷ - y = 7.5 - 9 = -1.5`（对 ½(ŷ-y)² 求导）
> ② `∂loss/∂w₂ = ∂loss/∂ŷ × ∂ŷ/∂w₂ = -1.5 × a₁ = -1.5 × 2.5 = -3.75`
> ③ `∂loss/∂a₁ = ∂loss/∂ŷ × ∂ŷ/∂a₁ = -1.5 × w₂ = -4.5`，再乘 ReLU 导数（a₁>0 时为 1）得 `∂loss/∂z₁ = -4.5`
> ④ `∂loss/∂w₁ = ∂loss/∂z₁ × ∂z₁/∂w₁ = -4.5 × x = -4.5`

> 💡 **Aha Moment**：看 ② 和 ④——`∂loss/∂w₁` 的计算用到了 `∂loss/∂z₁`，而 `∂loss/∂z₁` 是用 `∂loss/∂a₁` 乘来的，`∂loss/∂a₁` 又是 `∂loss/∂ŷ` 乘来的。**梯度就是像多米诺骨牌一样，从后往前一层层"传递"的**——这就是"反向传播"这个名字的由来。每一层只需要记住"自己这一段的导数"，把上一层传下来的梯度乘上去，再传给下一层。**PyTorch 的 Autograd 干的正是这件事，只是自动化了。**

> 💻 **NumPy 验证**（建文件 `ch3_backprop.py`）：手算的四个梯度，全部用数值梯度验证。这是你第一次"手写反向传播"——第 12 周你会用 PyTorch 的 Autograd 再做一次一模一样的验证。

```python
import numpy as np

# ---- 固定参数，走一遍 2 层小网络 ----
x, w1, b1, w2, y_target = 1.0, 2.0, 0.5, 3.0, 9.0

def forward(x, w1, b1, w2):
    z1 = w1*x + b1
    a1 = z1 if z1 > 0 else 0.0          # ReLU
    y_hat = w2 * a1
    loss = 0.5 * (y_hat - y_target)**2  # MSE 的一半（求导干净）
    return loss, y_hat, a1

loss, y_hat, a1 = forward(x, w1, b1, w2)
print(f"前向: ŷ={y_hat}, a1={a1}, loss={loss}")

# ---- 反向传播（链式法则，手写）----
dL_dyhat = y_hat - y_target                     # ①
dL_dw2 = dL_dyhat * a1                          # ②
dL_da1 = dL_dyhat * w2
dL_dz1 = dL_da1 * (1.0 if a1 > 0 else 0.0)      # ③ ReLU 导数
dL_dw1 = dL_dz1 * x                             # ④
dL_db1 = dL_dz1 * 1.0
print("手写梯度: dL/dw1 =", dL_dw1, " dL/db1 =", dL_db1, " dL/dw2 =", dL_dw2)

# ---- 数值梯度验证（每个参数动一丁点，看 loss 变化）----
def num_g(f, p, h=1e-6):
    return (f(p + h) - f(p - h)) / (2 * h)

print("数值验证: dL/dw1 =", round(num_g(lambda v: forward(x, v, b1, w2)[0], w1), 6))
print("数值验证: dL/db1 =", round(num_g(lambda v: forward(x, w1, v, w2)[0], b1), 6))
print("数值验证: dL/dw2 =", round(num_g(lambda v: forward(x, w1, b1, v)[0], w2), 6))
# 三对手写/数值都应该一致（-4.5, -4.5, -3.75）
```

> 📱 **这和 ML 有什么关系**：`06-阶段三下` 第 12 周的核心练习是"手写 2 层 MLP 的反向传播，并用 PyTorch Autograd 验证差异 < 1e-10"。你刚才在纯 NumPy 里已经完成了同一件事的骨架。**第 12 周你只需要做两件事：把层数加多、把验证工具从数值梯度换成 Autograd。** 数学的部分你现在就懂了。

> ⚠️ **常见陷阱（梯度消失的预告）**：注意 ③ 步里 ReLU 的导数是"a₁>0 时 1，否则 0"。如果 a₁ ≤ 0，梯度直接变 0——那个神经元死了。而如果中间层用 sigmoid（导数最大只有 0.25），梯度每传一层就最多缩 4 倍，几十层后接近 0——这就是 `06` 文件里"梯度消失"的数学根源。**现在看到这条，第 12 周你会想起它。**

### 3.8 微积分小结

> 📱 **把这一章压缩成四句话**：
> 1. **导数 = 变化率 = 方向指示牌**：`loss` 对 `w` 的导数告诉你 w 往哪调。
> 2. **梯度 = 所有偏导数的向量**：它指向"涨得最快"的方向，训练就朝反方向走。
> 3. **链式法则 = 分段相乘**：嵌套函数的变化率等于每一段变化率的乘积。
> 4. **反向传播 = 把链式法则从后往前套一遍**：这就是 `loss.backward()` 在做的事。

> 📊 **本章公式速查**：

| 概念 | 公式 | 一句话直觉 |
|------|------|-----------|
| 导数 | f'(x) ≈ (f(x+h)-f(x-h))/(2h) | 变化率，可数值验证 |
| 偏导 | ∂f/∂w（其它变量按住） | 只看一个变量的影响 |
| 梯度 | ∇loss = [∂loss/∂w₁, ...] | 最陡上坡方向 |
| 链式法则 | dy/dx = dy/du × du/dx | 分段相乘 |
| 梯度下降 | w ← w - lr·∇loss | 沿反方向下山 |

## 四、概率与统计

> 📱 **这一章解释一个关键转变**：线性回归输出任意实数（"房价 250 万"），但很多问题需要"这件事有多大概率的把握"（"这封邮件有 98% 的可能是垃圾邮件"）。从"输出一个数"到"输出一个概率"，中间隔着的就是概率论。同时，**机器学习训练的本质**——"从数据里估计参数"——也是一个统计问题（最大似然估计，4.10 节）。

> 🎯 **本章目标**：学完你应能①用代码生成各种分布的随机数并验证它们的统计量；②知道期望 ≈ 平均值、方差 ≈ 数据的离散程度；③理解条件概率 P(A|B) 并算贝叶斯定理；④说清"最大似然估计"的直觉，并理解它如何导出损失函数。这几样是第 8 周逻辑回归和损失函数的直接地基。

### 4.1 随机变量：不确定性的数学化

> 📱 **直觉**：随机变量不是一个"确定的数"，而是一个"还没揭晓的数"。比如"明天的降雨量"、"掷一次骰子的点数"、"随机抽一个用户的身高"——在结果揭晓前，它们都是随机变量。机器学习里，"从一批数据里抽样"这个动作，天然产生随机变量。

> 📱 **两个关键概念**：
> - **样本（sample）**：随机变量的一次具体取值。掷骰子得到 3，3 就是一个样本。
> - **分布（distribution）**：随机变量"可能取哪些值、每个值多大可能"的完整描述。掷骰子就是均匀分布（每面 1/6）。

> 📱 **为什么要关心分布**：因为"某个事件发生的概率"就是它的分布。逻辑回归输出的是"正类的概率"，这个概率从哪来？——从 sigmoid 压缩后的分布中来。**模型本质上在"猜"一个分布。**

> 💻 **NumPy 验证**（建文件 `ch4_random.py`）：

```python
import numpy as np

# NumPy 的随机数生成器（新版推荐 np.random.default_rng）
rng = np.random.default_rng(42)   # 固定种子 → 结果可复现

# 均匀分布：从 [0, 1) 里随机抽 5 个数
samples = rng.uniform(0, 1, size=5)
print("均匀分布样本:", np.round(samples, 4))

# 每个样本都不一样 → 这就是"随机变量"
print("再抽 5 次:", np.round(rng.uniform(0, 1, size=5), 4))

# 抽很多次，统计"落在 [0.5, 1) 的比例" → 应该接近 0.5（概率的直觉）
big = rng.uniform(0, 1, size=100000)
frac = (big >= 0.5).mean()
print(f"10 万次里 ≥0.5 的比例: {frac:.4f}（理论值 0.5）")
```

> 📱 **这和 ML 有什么关系**：模型输出不是"确定的答案"，而是一个概率。这个概率可以理解为一个随机变量的分布参数。第 8 周逻辑回归里 `ŷ = σ(wx+b)` 输出的 `ŷ` 被解释成"样本属于正类的概率"——它就是在描述一个伯努利分布（4.4 节）。

### 4.2 概率分布总览

> 📱 **先给全景**。ML 里常见分布就 4 种，各有各的用途：

| 分布 | 取值 | 直觉 | ML 里的用途 |
|------|------|------|------------|
| **均匀分布** | 连续区间 [a, b] | 处处等可能 | 随机初始化、随机采样 |
| **伯努利分布** | {0, 1} | 单次"抛硬币" | 逻辑回归（二分类）的输出分布 |
| **二项分布** | {0, 1, ..., n} | n 次抛硬币，正面几次 | 数据生成、统计检验 |
| **高斯（正态）分布** | 整个实数轴 | 大多数自然现象 | 噪声建模、参数初始化、注意力缩放 |

> 📱 **区分"离散"和"连续"**：掷骰子的结果只可能是 1-6（离散）；身高可以是 170.1 或 170.13（连续）。离散分布用"每个值的概率"描述（概率质量函数 PMF），连续分布用"概率密度函数 PDF"描述（一个区间上的面积才是概率）。

### 4.3 均匀分布

> 📱 **直觉**：在区间 [a, b] 里"处处等可能"。闭着眼睛在数轴上随手一指，落在任何长度相等的小区间里的概率都一样。

> 📐 **公式**：`X ~ Uniform(a, b)`，密度函数在 [a, b] 上是常数 `1/(b-a)`。期望 `(a+b)/2`，方差 `(b-a)²/12`。

> 💻 **NumPy 验证**（建文件 `ch4_uniform.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

# 从 [0, 10) 里抽 20 万个数
x = rng.uniform(0, 10, size=200000)
print(f"样本均值: {x.mean():.4f}（理论期望 (0+10)/2 = 5）")
print(f"样本方差: {x.var():.4f}（理论方差 (10-0)²/12 = 8.333）")

# 密度函数验证：任意小区间 [2,3) 里的比例 ≈ 区间长度/总长度 = 0.1
frac = ((x >= 2) & (x < 3)).mean()
print(f"落在 [2,3) 的比例: {frac:.4f}（理论 1/10 = 0.1）")

# 可视化数据分布（用直方图）——如果你装了 matplotlib 可以画
try:
    import matplotlib.pyplot as plt
    plt.hist(x, bins=40, density=True)
    plt.axhline(1/10, color='r', linestyle='--', label='理论密度 0.1')
    plt.legend(); plt.title('Uniform(0,10)')
    plt.savefig('ch4_uniform.png'); print("已保存直方图 ch4_uniform.png")
except ImportError:
    print("（没装 matplotlib，跳过画图，不影响验证）")
```

> 📱 **这和 ML 有什么关系**：均匀分布用于**随机初始化**——模型参数在训练开始前通常从 `Uniform(-0.05, 0.05)` 之类的小区间里随机抽取。第 12 周你会学到 Xavier / Kaiming 初始化，那正是更聪明的均匀分布。另外，`np.random` 抽取训练样本（比如 shuffle）本质上也是均匀随机。

### 4.4 伯努利分布：单次"抛硬币"

> 📱 **直觉**：伯努利分布描述**一次只有两种结果**的随机试验：正面/反面、垃圾邮件/正常邮件、患病/健康。用一个参数 `p` 表示"结果为 1（成功）的概率"。

> 📐 **公式**：`P(X=1) = p`，`P(X=0) = 1-p`。期望 `E[X] = p`，方差 `p(1-p)`。

> 📱 **这个分布为什么是逻辑回归的心脏**：逻辑回归的输出 `ŷ ∈ (0,1)` 被解释为"标签=1 的概率 p"。于是"真实标签 y"就服从一个参数为 ŷ 的伯努利分布。**预测越准，说明你猜的伯努利分布越接近真实情况。** 第 5 章的交叉熵就是量化"你猜的分布有多不对"。

> 💻 **NumPy 验证**（建文件 `ch4_bernoulli.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

p = 0.7    # 70% 概率出 1
# np.random.binomial(n=1, p=p) 就是伯努利
x = rng.binomial(n=1, p=p, size=100000)

print(f"1 出现的比例: {x.mean():.4f}（理论 p = {p}）")
print(f"0 出现的比例: {(1 - x).mean():.4f}（理论 1-p = {1-p}）")
print(f"样本方差: {x.var():.4f}（理论 p(1-p) = {p*(1-p):.4f}）")

# 模拟一次"分类预测"：模型输出 ŷ=0.9，就按这个概率抛硬币
y_hat = 0.9
simulated_label = rng.binomial(1, y_hat, size=10)
print("模型输出 0.9 时，模拟 10 次标签:", simulated_label)
print("→ 大概率是 1（约 9/10），偶尔是 0")
```

> 📱 **这和 ML 有什么关系**：`05-阶段三上` 逻辑回归的预测 `ŷ = σ(wx+b)` 就是一个伯努利分布的参数。你训练逻辑回归，就是在学"这个样本有多大概率属于正类"。评价时 `ŷ > 0.5` 判为正类，等于选择概率更大的一边。

### 4.5 二项分布：多次"抛硬币"

> 📱 **直觉**：二项分布回答："连抛 n 次硬币，正面出现 k 次的概率是多少？"它是伯努利的"重复版"。如果 n=1，退化成伯努利。

> 📐 **公式**：`X ~ Binomial(n, p)`，期望 `E[X] = n·p`，方差 `np(1-p)`。一次抽样就得到"n 次试验里成功了几次"。

> 💻 **NumPy 验证**（建文件 `ch4_binomial.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

# 抛 10 次硬币（p=0.5），记录正面次数；重复 10 万次
n, p = 10, 0.5
trials = rng.binomial(n=n, p=p, size=100000)

print(f"平均正面次数: {trials.mean():.3f}（理论 n*p = {n*p}）")
print(f"方差: {trials.var():.3f}（理论 np(1-p) = {n*p*(1-p):.3f}）")

# 分布的形状：k=5 的次数应该最多（对称的中间）
import collections
counts = collections.Counter(trials)
print("正面次数分布（前几个）:", dict(sorted(counts.items())[:6]))

# 大数定律的预感：试验次数越多，均值越稳定
for size in [100, 10000, 1000000]:
    t = rng.binomial(n=n, p=p, size=size)
    print(f"试验 {size:8d} 次，均值 {t.mean():.4f}")
```

> 📱 **这和 ML 有什么关系**：二项分布最常见的用途是理解"统计检验"和"采样的稳定性"。训练里少有用它做主角，但**大数定律**（试验越多，样本均值越接近理论期望）是"为什么数据越多模型越稳"的数学依据——这个思想在 ML 里贯穿始终。

### 4.6 高斯（正态）分布：无处不在的钟形曲线

> 📱 **直觉**：高斯分布是所有分布里的"主角"。它的形状是钟形——**中间高、两边低，关于均值对称**。身高、考试成绩、测量误差……大量自然现象都近似服从高斯分布。参数有两个：**均值 μ**（钟的对称中心）和**标准差 σ**（钟的胖瘦）。

> 📐 **公式**：`X ~ N(μ, σ²)`，密度函数：

> f(x) = 1/(σ√(2π)) · e^(-(x-μ)²/(2σ²))

> ⚠️ **重要**：**这个公式不用背**！你要背的是它的**形状直觉**：μ 决定中心在哪，σ 决定有多宽。约 68% 的样本落在 μ±σ 内，约 95% 落在 μ±2σ 内（"68-95-99.7 法则"）。

> 💻 **NumPy 验证**（建文件 `ch4_gaussian.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

# 标准正态 N(0,1)
x = rng.standard_normal(1000000)
print(f"均值: {x.mean():.4f}（理论 0）")
print(f"标准差: {x.std():.4f}（理论 1）")

# 68-95-99.7 法则验证
print(f"|x|<1σ 的比例: {(np.abs(x) < 1).mean():.4f}（理论 68%）")
print(f"|x|<2σ 的比例: {(np.abs(x) < 2).mean():.4f}（理论 95%）")
print(f"|x|<3σ 的比例: {(np.abs(x) < 3).mean():.4f}（理论 99.7%）")

# 变换参数：N(5, 2²) = 5 + 2 * N(0,1)
y = 5 + 2 * x[:100000]
print(f"N(5,4) 均值: {y.mean():.4f}，标准差: {y.std():.4f}")

# 用密度函数公式画个验证：峰值出现在 x=μ，高度 1/(σ√(2π))
mu, sigma = 0.0, 1.0
peak = 1 / (sigma * np.sqrt(2 * np.pi))
print(f"标准正态在 x=0 的密度值: {peak:.4f}（也是它的最大值）")
```

> 📱 **这和 ML 有什么关系**：高斯分布四处出没。① **噪声建模**：`05` 第 8 周生成数据 `y = 3x + 2 + np.random.randn(n,1)*2`，那个 `randn` 就是标准正态噪声；② **参数初始化**：`w = np.random.randn(...)` 让参数初始在 0 附近；③ **最大似然估计（4.10 节）**：假设误差服从高斯分布，MSE 损失就"自动冒出来"了——这是本章最精彩的连接；④ **Attention 的 `÷√d_k`**：`06` 第 15 周解释过，Q、K 的元素均值 0 方差 1 时，QKᵀ 的元素服从方差为 d_k 的分布，除以 √d_k 把它拉回方差 1。

### 4.7 期望与方差

> 📱 **直觉**：**期望（Expectation）** = "如果反复抽很多很多次，平均会得到什么"。**方差（Variance）** = "每次抽的结果离平均有多远（平均偏离的平方）"。

> 📐 **公式**：对随机变量 X（假设有 N 个样本）：
> - 期望：`E[X] = (1/N) Σ xᵢ`（就是样本均值）
> - 方差：`Var(X) = (1/N) Σ (xᵢ - E[X])²`（偏离均值的平方的平均）
> - 标准差：`σ = √Var`（把方差的"平方"还原，和原始数据同单位）

> 💡 **Aha Moment**：期望和方差就是数据的"两个核心摘要"：**期望告诉你"在哪"**（中心），**方差告诉你"散不散"**（离散度）。所有数据预处理（标准化）就是基于这两兄弟：`x_normalized = (x - μ) / σ`（减去中心，除以离散度）。

> 💻 **NumPy 验证**（建文件 `ch4_expect_var.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

# 两批数据：一批集中，一批分散
data_a = rng.normal(5, 1, 100000)    # μ=5, σ=1
data_b = rng.normal(5, 10, 100000)   # μ=5, σ=10

print(f"data_a: 均值 {data_a.mean():.3f}，方差 {data_a.var():.3f}，标准差 {data_a.std():.3f}")
print(f"data_b: 均值 {data_b.mean():.3f}，方差 {data_b.var():.3f}，标准差 {data_b.std():.3f}")
print("→ 均值相同（都在 5），但 b 的方差大得多（数据更散）")

# 手动算方差：偏离均值的平方的平均
mu = data_a.mean()
manual_var = ((data_a - mu) ** 2).mean()
print(f"手动方差: {manual_var:.4f}（和 np.var 一致: {np.isclose(manual_var, data_a.var())}）")

# 标准化：(x - μ) / σ → 均值 0，标准差 1
std_a = (data_a - data_a.mean()) / data_a.std()
print(f"标准化后: 均值 {std_a.mean():.5f}，标准差 {std_a.std():.4f}")

# 期望的线性性质：E[2X+3] = 2E[X]+3
print(f"E[2X+3] = {data_a.mean()*2 + 3:.3f}，等于 2E[X]+3 = {2*5+3} 附近 ✓")
```

> 📱 **这和 ML 有什么关系**：① **标准化**（阶段三上第 9 周特征工程）就是 `(x-μ)/σ`——你刚亲手验证了它的效果；② **MSE 损失** `(1/n)Σ(ŷ-y)²` 本质就是"误差的方差"（把误差当成随机变量）；③ **模型评估**里"均值 ± 标准差"到处出现（比如交叉验证的 `0.85 ± 0.02`）。期望和方差是数据科学的基本词汇。

### 4.8 条件概率

> 📱 **直觉**：条件概率回答："**在已知 B 发生的情况下，A 发生的概率是多少？**" 记作 `P(A|B)`，读作"给定 B 的条件下 A 的概率"。

> 📐 **公式**：P(A|B) = P(A ∩ B) / P(B)

> 📱 **生活例子**：全班级 60% 的人戴眼镜（P(眼镜) = 0.6），其中 10% 是程序员……反过来，程序员中戴眼镜的比例可能更高。条件概率就是把"已知信息"加进去后的概率。

> 💡 **Aha Moment**：条件概率让"概率"从静止变成了"可以更新的"。看到新证据，你更新自己的判断——`P(A|B)` 和 `P(A)` 的差别就是证据 B 带来的信息量。**这直接通向贝叶斯定理（下一节），而贝叶斯定理是理解"模型怎么根据数据调整信念"的框架。**

> 💻 **NumPy 验证**（建文件 `ch4_conditional.py`）：

```python
import numpy as np
rng = np.random.default_rng(0)

# 模拟 10000 个人：是不是程序员？戴不戴眼镜？
n = 10000
is_coder = rng.binomial(1, 0.2, n)         # 20% 是程序员
wears_glasses = rng.binomial(1, 0.15, n)   # 基础戴镜率 15%
# 程序员戴镜率高一点：程序员里 60% 戴，非程序员 15%
for i in range(n):
    wears_glasses[i] = rng.binomial(1, 0.6 if is_coder[i] else 0.15)

# P(戴眼镜) —— 全体中的比例
P_glasses = wears_glasses.mean()
# P(戴眼镜 | 程序员) —— 只看程序员
coders = is_coder == 1
P_glasses_given_coder = wears_glasses[coders].mean()
# P(程序员 | 戴眼镜) —— 只看戴眼镜的
glasses = wears_glasses == 1
P_coder_given_glasses = is_coder[glasses].mean()

print(f"P(戴眼镜)          = {P_glasses:.3f}")
print(f"P(戴眼镜|程序员)   = {P_glasses_given_coder:.3f}（条件改变了概率）")
print(f"P(程序员|戴眼镜)   = {P_coder_given_glasses:.3f}")
```

> 📱 **这和 ML 有什么关系**：条件概率是"分类问题"的语言——`P(垃圾邮件 | 邮件内容)` 就是"给定内容，算它是垃圾邮件的概率"。逻辑回归学到的正是这个条件概率（只不过用了 sigmoid 和权重拟合）。**理解"模型输出 = 条件概率"是理解分类的金钥匙。**

### 4.9 贝叶斯定理

> 📱 **直觉**：贝叶斯定理是把条件概率"反过来"用的工具：如果你知道 `P(症状|疾病)`，贝叶斯定理能算出 `P(疾病|症状)`。它在 ML 里更像一个**思维方式**："根据证据（数据）更新先前的信念（先验）"。

> 📐 **公式**：

> P(A|B) = P(B|A) × P(A) / P(B)

> 其中 P(A) 叫**先验**（看到证据前怎么想），P(B|A) 叫**似然**（假设 A 真时看到 B 的可能），P(A|B) 叫**后验**（看到证据后怎么想）。

> 📱 **经典例子（疾病检测）**：某病发病率 1%（先验），检测灵敏度 99%（有病检出率），误报率 2%（没病也报阳性）。某人检测阳性，他真的患病概率是多少？直觉上很多人说 99%，但正确答案只有约 **33%**——因为发病率太低，假阳性的人数远超真阳性。这个"反直觉"是贝叶斯最著名的故事。

> 💻 **NumPy 验证**（建文件 `ch4_bayes.py`）：

```python
import numpy as np

# 贝叶斯定理：P(病|阳性) = P(阳性|病) * P(病) / P(阳性)
P_disease = 0.01            # 先验：发病率 1%
P_pos_given_disease = 0.99  # 灵敏度：有病时检出率 99%
P_pos_given_healthy = 0.02  # 误报率：没病时阳性率 2%
P_healthy = 1 - P_disease

# P(阳性) = 得病且阳性 + 没病且阳性（全概率公式）
P_pos = P_pos_given_disease * P_disease + P_pos_given_healthy * P_healthy

P_disease_given_pos = P_pos_given_disease * P_disease / P_pos
print(f"P(阳性) = {P_pos:.4f}")
print(f"P(病|阳性) = {P_disease_given_pos:.4f}（约 33%，不是 99%！）")

# 用大规模模拟交叉验证：生成 100 万人
rng = np.random.default_rng(0)
n = 1000000
sick = rng.binomial(1, P_disease, n)
positive = np.zeros(n, dtype=bool)
for i in range(n):
    positive[i] = rng.binomial(1, P_pos_given_disease if sick[i] else P_pos_given_healthy)
positives = positive.sum()
sick_and_pos = (sick & positive).sum()
print(f"模拟：阳性 {positives} 人，其中真患病 {sick_and_pos} 人")
print(f"模拟 P(病|阳性) = {sick_and_pos/max(positives,1):.4f}（和公式一致 ✓）")

# 直觉：把"误报人数"放大看
false_pos = ((~sick) & positive).sum()
print(f"假阳性 {false_pos} 人 ≈ 真阳性 {sick_and_pos} 人的 {false_pos/max(sick_and_pos,1):.1f} 倍 → 所以阳性≠患病")
```

> 📱 **这和 ML 有什么关系**：① 贝叶斯思维贯穿 ML："模型先有一个**先验**（初始参数），看到**数据**后更新成**后验**（训练好的参数）"；② 朴素贝叶斯分类器（一个经典 ML 算法）直接用贝叶斯定理做分类；③ 面试高频题"为什么阳性不等于患病"就是这道。**阶段三不会直接考你贝叶斯，但理解"证据更新信念"让你读训练流程时多一层眼光。**

### 4.10 最大似然估计：从概率到损失函数

> 📱 **这是第四章最重要的一节**，因为它直接解释了一个困扰很多人的问题："**MSE 和交叉熵这些损失函数，到底是从哪冒出来的？**" 答案是：它们都是最大似然估计（MLE）换了个马甲。

> 📱 **直觉**：你有一堆数据，想知道"这些数据最可能是从哪个分布里抽出来的"。最大似然估计的做法：**找到让"抽到当前这批数据"的概率最大的那个分布参数**。

> 📱 **硬币例子**：抛一枚硬币 10 次，正面 7 次。最合理的 p 是多少？答案 p=0.7。为什么？因为如果真实 p=0.7，抛 10 次恰好出现 7 正的概率最大。**"让数据出现的概率最大"的参数，就是最大似然估计。**

> 📐 **数学步骤**（只用直觉，不用推导）：
> 1. 写出"抽到这批数据"的概率——**似然函数** L(θ) = ∏ P(xᵢ; θ)（每个样本概率相乘）
> 2. 取对数（乘积变求和，求导方便）——**对数似然** log L(θ) = Σ log P(xᵢ; θ)
> 3. 最大化对数似然 → 等价于**最小化它的负数** → 这个"负对数似然"就是**损失函数**！

> 💡 **Aha Moment（本章的高潮）**：如果假设数据服从**高斯分布**（误差是正态噪声），最大似然估计推导出的损失函数恰好就是 **MSE**。如果假设数据服从**伯努利分布**（二分类标签），推导出的损失函数恰好就是**交叉熵**。**你学的每一个损失函数，背后都是一个概率假设。** 这不是巧合，这是设计。

> 💻 **NumPy 验证**（建文件 `ch4_mle.py`）：

```python
import numpy as np

# ==== 例子 1：抛硬币，估计 p ====
# 10 次抛掷：7 正 3 反。遍历候选 p，找让数据最"可能"的那个
k, n = 7, 10
p_grid = np.linspace(0.01, 0.99, 200)
likelihood = (p_grid ** k) * ((1 - p_grid) ** (n - k))   # ∏ P(xᵢ)
best_p = p_grid[np.argmax(likelihood)]
print(f"似然最大的 p = {best_p:.3f}（理论值 k/n = {k/n}）")

# 对数似然（防止乘积下溢，数值上更稳）
log_likelihood = k*np.log(p_grid) + (n-k)*np.log(1-p_grid)
best_p2 = p_grid[np.argmax(log_likelihood)]
print(f"对数似然最大的 p = {best_p2:.3f}（结果一致）")

# ==== 例子 2：假设误差服从高斯分布 → MLE = 最小化 MSE ====
rng = np.random.default_rng(0)
# 真实 w=3，生成带高斯噪声的数据
x = rng.uniform(0, 10, 200)
y_true = 3.0 * x + rng.normal(0, 1, 200)

# 遍历候选 w，看"哪个 w 使数据最可能"（误差的平方和最小）
w_grid = np.linspace(0, 6, 600)
sse = ((y_true.reshape(-1,1) - w_grid*x.reshape(-1,1)) ** 2).sum(axis=0)  # 误差平方和
best_w = w_grid[np.argmin(sse)]
print(f"MSE 最小的 w = {best_w:.3f}（真实值 3.0，验证了 MSE 是高斯假设下的 MLE）")
```

> 📱 **这和 ML 有什么关系**：这是**理解损失函数的根源**。当你在 `05-阶段三上` 看到"MSE 为什么这么设计"时，答案在这里：**MSE = 高斯噪声假设下的负对数似然**。当你在第 8 周问"逻辑回归为什么用交叉熵不用 MSE"时，答案也在这一节 + 下一章：**交叉熵 = 伯努利假设下的负对数似然，而且它的梯度更漂亮（不会像 sigmoid+MSE 那样梯度消失）**。把"损失函数 = 负对数似然"这句记在心里，整个损失函数的世界就通了。

> ⚠️ **常见陷阱**：MLE 不是"猜分布"的唯一方法，但它是最常用的。它的隐患是**过拟合**——如果模型太灵活，它能把"恰好抽到这批数据"的概率推到 1（把噪声也学进去）。正则化（L2/L1，第 9 周）就是对 MLE 加"先验约束"，防止它走极端。这个联系在第 9 周会再次出现。

### 4.11 概率与统计小结

> 📱 **把这一章压缩成四句话**：
> 1. **分布描述"不确定性"**：伯努利（一次抛币）、二项（多次抛币）、高斯（钟形）、均匀（处处等可能）。
> 2. **期望=均值（在哪），方差=离散度（散不散）**：标准化就是 `(x-μ)/σ`。
> 3. **条件概率=加了已知信息的概率**，贝叶斯定理把它"反过来"用：证据更新信念。
> 4. **最大似然估计 = 找让数据最可能的参数**，它的"负对数似然"就是损失函数：高斯假设→MSE，伯努利假设→交叉熵。

> 📊 **本章公式速查**：

| 概念 | 公式 | 一句话直觉 |
|------|------|-----------|
| 伯努利 | P(X=1)=p | 一次抛硬币 |
| 二项 | E=n·p | n 次抛硬币正面几次 |
| 高斯 | N(μ, σ²) | 钟形，68-95-99.7 |
| 期望 | E[X]≈均值 | 数据的中心 |
| 方差 | Var≈均方偏离 | 数据多散 |
| 条件概率 | P(A\|B)=P(A∩B)/P(B) | 已知 B 后 A 的概率 |
| 贝叶斯 | P(A\|B)=P(B\|A)P(A)/P(B) | 证据更新信念 |
| MLE | max ∏P(xᵢ;θ) | 找让数据最可能的参数 |

### 5.1 信息量：一个事件带来多少"惊讶"

> 📱 **直觉**：一个事件**越不可能发生，它发生时所携带的信息量越大**。太阳从东边升起（概率≈1）说了等于没说，信息量≈0。"明天会有彗星撞地球"（概率≈0）如果真发生，信息量爆炸。

> 📱 **信息量的单位是"比特"（bit）**：抛一枚公平硬币，"正面"这件事携带 1 比特信息（因为它在两种等可能中选了一种，log₂2 = 1）。

> 📐 **公式**：事件 x 的概率是 p(x)，它的信息量：

> I(x) = -log₂(p(x))

> - p = 0.5 → I = 1 比特（公平硬币）
> - p = 0.25 → I = 2 比特
> - p = 1.0 → I = 0 比特（确定事件，无信息）

> 💻 **NumPy 验证**（建文件 `ch5_information.py`）：

```python
import numpy as np

def info(p):
    return -np.log2(p)

print("P=0.5 的信息量:", info(0.5), "比特")
print("P=0.25 的信息量:", info(0.25), "比特")
print("P=0.1 的信息量:", round(info(0.1), 3), "比特")
print("P=1.0 的信息量:", info(1.0), "比特（确定的事没有信息）")

# 指数验证：概率减半，信息量加一（log 的性质）
print("info(0.5) - info(1.0) =", info(0.5) - info(1.0))      # 1
print("info(0.25) - info(0.5) =", info(0.25) - info(0.5))    # 1
```

> 📱 **这和 ML 有什么关系**：交叉熵损失里那个 `-log(ŷ)`，就是"真实标签为 1，而模型给它的概率是 ŷ"这件事的信息量。模型给正确类的概率越低 → 信息量越大 → 惩罚越大。**损失函数 = 对"模型低估正确类"的惩罚。**

### 5.2 熵：分布的"平均信息量"

> 📱 **直觉**：熵是一个分布的平均信息量，也等于它的"**不确定程度**"。公平硬币（p=0.5）熵最大，因为结果最难猜；如果硬币 100% 正面，熵 = 0，因为没有任何不确定性。

> 📐 **公式**：对分布 `P = (p₁, p₂, ..., pₙ)`：

> H(P) = -Σ pᵢ · log₂(pᵢ)

> - 公平硬币：H = -(0.5·log₂0.5 + 0.5·log₂0.5) = 1 比特
> - 偏硬币 p=0.9：H ≈ 0.47 比特（更有"谱"，不确定性小）
> - 确定性事件：H = 0

> 📱 **决策树里的"信息熵"**（`05-阶段三上` 第 8 周决策树）就是它：熵越高，数据越"混乱"，越需要分裂。`H = -Σ pᵢ log₂(pᵢ)` 那个公式，你在这里正式见过了。

> 💻 **NumPy 验证**（建文件 `ch5_entropy.py`）：

```python
import numpy as np

def entropy(p):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                     # 概率为 0 的项贡献 0（log0 无定义）
    return -(p * np.log2(p)).sum()

print("公平硬币 H =", entropy([0.5, 0.5]))          # 1.0（最不确定）
print("偏硬币 p=0.9 H =", round(entropy([0.9, 0.1]), 4))  # 0.469
print("确定性 H =", entropy([1.0, 0.0]))            # 0.0（完全确定）

# 三分类情况：越"平均"熵越高
print("三分类均等 H =", round(entropy([1/3, 1/3, 1/3]), 4))   # 约 1.585
print("三分类偏斜 H =", round(entropy([0.9, 0.05, 0.05]), 4)) # 约 0.569

# 直觉验证：熵 = 平均信息量
p = np.array([0.5, 0.25, 0.25])
avg_info = (p * -np.log2(p)).sum()
print("熵 = 平均信息量:", entropy(p) == avg_info)
```

> 📱 **这和 ML 有什么关系**：① **决策树**用它选分裂特征（信息增益 = 分裂前后熵的减少）；② **Softmax 输出的"置信度"**：一个分布越"尖"（某个类概率接近 1），熵越低，模型越确信；**采样**（第 14 周 GPT 的 temperature）就是调节 softmax 分布的"尖度"。熵是你读懂这些的底层直觉。

### 5.3 交叉熵：用别人的分布来编码

> 📱 **直觉**：熵是"用**真实分布** P 的平均信息量"。交叉熵问：**"如果我误以为真实分布是 Q（而真实是 P），我平均要多浪费多少信息？"**

> 📱 **换个说法（更贴近 ML）**：真实标签分布是 P（比如"第 2 类"是确定事件，P = [0,1,0]），模型预测分布是 Q（比如 [0.1, 0.7, 0.2]）。交叉熵衡量"**用 Q 来描述 P 有多不准确**"。Q 越接近 P，交叉熵越小；Q 和 P 差得越远，交叉熵越大。

> 📐 **公式**：

> H(P, Q) = -Σ pᵢ · log(qᵢ)

> ⚠️ **注意**：log 里是 Q（模型预测），外面的权重是 P（真实标签）。**只有 Q 上的 log 被真实分布 P 加权。** 这个不对称性很重要。

> 💻 **NumPy 验证**（建文件 `ch5_cross_entropy.py`）：

```python
import numpy as np

def cross_entropy(P, Q):
    P = np.asarray(P, dtype=float)
    Q = np.asarray(Q, dtype=float)
    Q = np.clip(Q, 1e-12, 1.0)     # 防止 log(0)
    return -(P * np.log(Q)).sum()

# 二分类：真实 P=[1,0]（第 0 类是确定的），模型预测 Q
# 预测完美：Q = [0.9999, 0.0001]
ce_perfect = cross_entropy([1, 0], [0.9999, 0.0001])
# 预测糟糕：Q = [0.0001, 0.9999]（模型把第 0 类判成几乎不可能）
ce_bad = cross_entropy([1, 0], [0.0001, 0.9999])
print(f"预测完美时 CE = {ce_perfect:.5f}（很小）")
print(f"预测糟糕时 CE = {ce_bad:.4f}（很大，9.21 ≈ -ln(0.0001)）")

# 交叉熵 ≠ 熵：当 Q≠P 时，CE 一定 ≥ H(P)
P = [0.5, 0.5]
Q = [0.8, 0.2]
print(f"H(P) = {-(np.array(P)*np.log2(P)).sum():.3f} 比特")
print(f"H(P,Q) = {-(np.array(P)*np.log2(Q)).sum():.3f} 比特（更大）")
```

> 📱 **这和 ML 有什么关系**：**二分类交叉熵就是 `05-阶段三上` 的公式**：`Loss = -[y·log(ŷ) + (1-y)·log(1-ŷ)]`。当 y=1 时，P = [1,0]，Loss = -log(ŷ)（上式第一项）；当 y=0 时，P = [0,1]，Loss = -log(1-ŷ)（第二项）。**你第 8 周背的那个公式，就是交叉熵在"二分类 + one-hot 标签"下的展开形式。** 多分类版（第 7 章）同理：`Loss = -log(q_k)`，k 是真实类别。

### 5.4 KL 散度：两个分布的"距离"

> 📱 **直觉**：KL 散度量化"两个分布的差距有多大"。它等于"交叉熵 - 熵"：多出来的那一部分，就是**因为用错分布（Q 代替 P）而浪费的信息**。

> 📐 **公式**：

> KL(P‖Q) = Σ pᵢ · log(pᵢ/qᵢ) = H(P, Q) - H(P)

> 📱 **性质（直觉层面）**：
> - KL ≥ 0 永远成立，且当且仅当 P=Q 时为 0。
> - **它不对称**：KL(P‖Q) ≠ KL(Q‖P)。所以叫"散度"不叫"距离"。
> - 训练里，P 是真实标签分布（固定），Q 是模型输出（可变）。我们**只关心 KL 的 Q 部分**，而 `H(P)` 是个常数——所以最小化 KL = 最小化交叉熵。**这就是"交叉熵 = KL 散度去掉常数项"的故事。**

> 💻 **NumPy 验证**（建文件 `ch5_kl.py`）：

```python
import numpy as np

def kl(P, Q):
    P = np.asarray(P, dtype=float)
    Q = np.asarray(Q, dtype=float)
    Q = np.clip(Q, 1e-12, 1.0)
    P = np.clip(P, 1e-12, 1.0)
    return (P * np.log(P / Q)).sum()

P = [0.5, 0.5]
Q1 = [0.5, 0.5]          # 完全一样
Q2 = [0.8, 0.2]          # 有偏差
Q3 = [0.99, 0.01]        # 偏差更大

print(f"KL(P‖P) = {kl(P, Q1):.5f}（分布相同，为 0）")
print(f"KL(P‖Q2) = {kl(P, Q2):.4f}")
print(f"KL(P‖Q3) = {kl(P, Q3):.4f}（偏差越大，KL 越大）")

# 不对称性验证
print(f"KL(P‖Q2) = {kl(P, Q2):.4f}  但 KL(Q2‖P) = {kl(Q2, P):.4f}")

# 关键关系：KL = 交叉熵 - 熵
def cross_entropy(P, Q):
    Q = np.clip(np.asarray(Q, dtype=float), 1e-12, 1.0)
    return -(np.asarray(P, dtype=float) * np.log(Q)).sum()
def entropy(P):
    P = np.clip(np.asarray(P, dtype=float), 1e-12, 1.0)
    return -(P * np.log(P)).sum()
print(f"验证 KL = CE - H: {kl(P,Q2):.4f} ≈ {cross_entropy(P,Q2)-entropy(P):.4f}")

# ML 视角：H(P) 是常数，最小化 KL = 最小化 CE
# 训练时 P 是固定标签，只有 Q（模型输出）在变
print("→ 训练只动 Q：CE 和 KL 差一个常数，优化它俩等价")
```

> 📱 **这和 ML 有什么关系**：KL 散度在三个地方出现：① 解释损失函数（CE = KL + 常数）；② 第 15 周 Transformer 生成时的**采样温度**（调节分布"尖度"，本质是调节它和均匀分布的 KL）；③ 一些高级算法（VAE、知识蒸馏）的核心度量。**现在你只要记住：KL 衡量两个分布差多少，训练分类模型最小化它，等价于最小化交叉熵。**

### 5.5 为什么交叉熵当损失函数

> 📱 **现在回答第 8 周的灵魂问题**：逻辑回归为什么用交叉熵，不用 MSE？三个理由，层层递进。

> 📐 **理由一：概率正确性**。逻辑回归输出的是"概率"（伯努利分布的参数），衡量"我猜的概率分布有多错"天然该用交叉熵/KL——它是信息论里"分布差距"的正牌度量。MSE 是为"数值预测"设计的，用在概率上"名不正言不顺"。

> 📐 **理由二：梯度不消失**。这是最硬核的理由，直接看图。把 sigmoid 和损失拼起来求导：
> - **sigmoid + MSE**：`∂loss/∂w = (ŷ - y) × ŷ(1-ŷ) × x`。当模型错得很离谱时（ŷ 接近 0 或 1），`ŷ(1-ŷ)` 那项接近 0，梯度被"掐死"→ 学不动。**错得越离谱，越是学不动，越学越不动。**
> - **sigmoid + 交叉熵**：`∂loss/∂w = (ŷ - y) × x`。那个 `ŷ(1-ŷ)` 被 log 求导"抵消"了！梯度正比于"误差"，错得多梯度就大，学得快。
>
> 这就是 `05` 文件说的"交叉熵的优雅之处：梯度形式简洁，和线性回归完全一致"的数学原因。

> 📐 **理由三：惩罚力度**。交叉熵对"自信的错误"惩罚极重（`-log(0.0001) ≈ 9.2`），对"接近正确"几乎不罚（`-log(0.9999) ≈ 0.0001`）——差约 92000 倍。这种"越错越狠"的性质，正是分类训练想要的。

> 💻 **NumPy 验证**（建文件 `ch5_why_ce.py`）：用数值梯度对比两种组合的"学习速度"，你会亲眼看到 MSE 怎么让模型卡住。

```python
import numpy as np

def sig(z):
    return 1 / (1 + np.exp(-z))

# 模拟：一个"错得很离谱"的样本，x=3, y=1，初始预测约 0
x, y = 3.0, 1.0
w = -10.0           # 初始权重 → σ(wx) ≈ 0（模型极不自信地猜错了）

def grad_ce(w):     # 交叉熵损失的梯度（解析）
    p = sig(w * x)
    return (p - y) * x

def grad_mse(w):    # MSE 损失的梯度（解析）
    p = sig(w * x)
    return (p - y) * p * (1 - p) * x   # 多乘了 p(1-p)

w_ce, w_mse = -10.0, -10.0
lr = 0.1
for step in range(101):
    w_ce  -= lr * grad_ce(w_ce)
    w_mse -= lr * grad_mse(w_mse)
    if step in (0, 25, 50, 75, 100):
        print(f"step {step:3d}: CE的w={w_ce:8.3f} p={sig(w_ce*x):.4f} | "
              f"MSE的w={w_mse:8.3f} p={sig(w_mse*x):.8f}")

print(f"\n100 步后：交叉熵把概率推向 {sig(w_ce*x):.4f}（接近正确 1）")
print(f"         MSE 还停在 {sig(w_mse*x):.8f}（梯度被 p(1-p) 掐死，完全没动）")
```

> 📱 **实验结果说明什么**：同样的起点、同样的学习率，**交叉熵 100 步就把概率从 ≈0 推到了 0.98，而 MSE 因为乘上了 `p(1-p)` 这个小因子，100 步后概率还是 0.00000000**——错得离谱时梯度≈0，模型完全学不动。这就是"梯度消失"在损失函数层面的现场演示，它正是 `05` 第 8 周那行"为什么不用 MSE"注释的完整答案。

> ⚠️ **常见陷阱**：PyTorch 的 `nn.CrossEntropyLoss` / `F.cross_entropy` **内部自带 softmax**。如果先手动 softmax 再传进去，等于做了两次 softmax，结果错误（`05` 第 11 周专门强调了）。你手写时要养成习惯：**传 logits（原始分数），让损失函数自己做 softmax。**

### 5.6 信息论小结

> 📱 **把这一章压缩成四句话**：
> 1. **信息量 = -log(概率)**：越不可能，越有信息。
> 2. **熵 = 分布的平均信息量 = 不确定性**：全等可能时最大。
> 3. **交叉熵 = 用错误分布 Q 编码真实分布 P 的成本**：Q 越接近 P 越小。
> 4. **交叉熵 - 熵 = KL 散度**：训练里标签分布固定，最小化交叉熵 = 最小化 KL。

> 📊 **递进关系一张图**：

```
信息量 I(x) = -log p(x)       单个事件的信息
        ↓ 取平均
熵 H(P) = Σ pᵢ·I(pᵢ)         分布自身的平均信息
        ↓ 把 log 换成别人的分布
交叉熵 H(P,Q) = -Σ pᵢ·log qᵢ  用 Q 描述 P 的成本
        ↓ 减去 H(P)
KL 散度 KL(P‖Q) = H(P,Q) - H(P)  两个分布的差距
```

## 六、向量化与广播

> 📱 **这一章是"效率章"**。前面的章节教你数学，这一章教你**怎么把数学写进代码还不慢**。核心就一件事：NumPy 能对整个数组同时做运算（向量化），还能让不同形状的数组自动对齐（广播）。阶段三里所有 `X @ w`、`(X - mean)/std`、softmax 一行写完，都是这两个机制在背后撑腰。

> 🎯 **本章目标**：学完你应能①解释为什么向量化比 for 循环快；②说出广播的三条规则；③手写常见向量化模式（标准化、softmax、批量矩阵乘法）。第 7 章的综合实战将大量依赖这些技能。

### 6.1 为什么要向量化

> 📱 **直觉**：Python 的 for 循环慢，是因为每一行 Python 代码都要经过解释器"翻译"一次；NumPy 的底层是 C 语言写的，一次操作处理整个数组。更关键的是，现代 CPU 的**SIMD**（单指令多数据）可以让一条指令同时处理多个数字。

> 📱 **ML 的残酷现实**：一次训练要算几百万次"样本×权重"。用 for 循环写，慢到无法忍受；用矩阵乘法写，一次搞定。**你写 ML 代码的第一反应应该是"能不能用矩阵运算代替循环"，而不是"这个循环怎么写"**。这个思维转变，就是从"菜鸟"到"工程师"的分水岭。

> 💻 **NumPy 验证**（建文件 `ch6_vectorize.py`）：

```python
import numpy as np
import time

rng = np.random.default_rng(0)
n = 1_000_000
a = rng.uniform(0, 1, n)
b = rng.uniform(0, 1, n)

# 方式 1：Python 循环
t0 = time.time()
s1 = 0.0
for i in range(n):
    s1 += a[i] * b[i]
t_loop = time.time() - t0

# 方式 2：向量化（一次算完）
t0 = time.time()
s2 = np.dot(a, b)
t_vec = time.time() - t0

print(f"点积结果一致: {s1 == s2}")
print(f"for 循环耗时: {t_loop*1000:.1f} ms")
print(f"向量化耗时:   {t_vec*1000:.3f} ms")
print(f"加速比: {t_loop/t_vec:.0f} 倍")
```

> 📱 **实验结果说明什么**：通常向量化比循环快 10~100 倍（机器不同数字不同，但量级一定是这样）。这就是为什么阶段三所有训练代码全是矩阵运算。**看到任何自己写的 Python 循环，先问一句："这能不能改成 NumPy 的一行？"**

### 6.2 for 循环 vs 向量化：用时间说话

> 💻 **建文件 `ch6_batch.py`**：更贴近 ML 的场景——一次性算 10000 个样本的线性预测。

```python
import numpy as np
import time

rng = np.random.default_rng(0)
n_samples, n_features = 10000, 50
X = rng.standard_normal((n_samples, n_features))   # 10000×50 的特征矩阵
w = rng.standard_normal(n_features)                # 50 维权重

# 循环版：每个样本算一次点积
t0 = time.time()
y_loop = np.empty(n_samples)
for i in range(n_samples):
    s = 0.0
    for j in range(n_features):
        s += X[i, j] * w[j]
    y_loop[i] = s
t_loop = time.time() - t0

# 向量化版：一次矩阵乘法 X @ w
t0 = time.time()
y_vec = X @ w
t_vec = time.time() - t0

print(f"两种结果一致: {np.allclose(y_loop, y_vec)}")
print(f"双层循环耗时: {t_loop*1000:.1f} ms")
print(f"矩阵乘法耗时: {t_vec*1000:.3f} ms")
print(f"加速比: {t_loop/t_vec:.0f} 倍")
```

> 📱 **这和 ML 有什么关系**：阶段三所有 `X @ w` 都是这个模式。PyTorch 的 Tensor 在 GPU 上做的也是向量化，只是把"CPU 的 SIMD"换成了"GPU 的并行"。**你学过的每一处批量计算，都是向量化的受益者。**

### 6.3 广播：NumPy 的"自动扩张"规则

> 📱 **直觉**：广播（broadcasting）让**不同形状的数组也能直接做运算**——NumPy 自动把小的数组"拉长"成和大的数组一样的形状，再逐元素运算。

> 📱 **生活类比**：一个班级 40 人，老师宣布"全班每人加 5 分"。你不需要对 40 个人逐个说——"加 5 分"这个标量自动广播到了每个人。同理，`scores + 5`、`X - mean`、`X / std`，那个标量或小数组会自动"铺开"。

> 📐 **广播的三条规则（背下来）**：
> 1. 从**最后一个维度**开始向前比较。
> 2. 两个维度**相等**，或者**有一个是 1**，就能对齐；否则报错。
> 3. 维度是 1 的那个，会被"拉伸"成另一个的大小。

> 📱 **最常见的两种广播**：
> - **标量广播**：`X + 5`，形状 `(n, d)` + 标量 → 每个元素都加 5。
> - **向量广播**：`X - mean`，其中 `X` 是 `(n, d)`，`mean` 是 `(d,)` → 每一行都减去同一个 mean（**按列标准化**就是这个模式）。或者 `X - col_mean` 中 col_mean 是 `(1, d)`，需要 reshape。

> 💻 **NumPy 验证**（建文件 `ch6_broadcast.py`）：

```python
import numpy as np

# 规则演示 1：标量广播
X = np.arange(6).reshape(2, 3)   # [[0 1 2],[3 4 5]]
print("X + 10:\n", X + 10)       # 每个元素 +10

# 规则演示 2：行向量广播到每一行
col_mean = np.array([1, 2, 3])   # shape (3,)
centered = X - col_mean
print("X 减去每列均值（每行都减）:\n", centered)

# 规则演示 3：列向量广播到每一列
row_mean = np.array([1, 4]).reshape(2, 1)   # shape (2,1)
print("X 减去每行均值（每列都减）:\n", X - row_mean)

# 规则 2 的报错演示：维度对不上又不满足"有一个是 1"
try:
    np.array([1, 2, 3]) + np.array([[1, 2], [3, 4]])   # (3,) vs (2,2)
except ValueError as e:
    print("广播失败（预期内）:", str(e)[:60], "...")

# 广播的等价手写（理解"自动扩张"发生了什么）
a = np.array([1, 2, 3])                # (3,)
expanded = np.tile(a, (2, 1))          # 手动复制成 (2,3)
print("手动扩张等价:\n", expanded)
print("X + a 等于 X + expanded:", np.allclose(X + a, X + expanded))
```

> 📱 **这和 ML 有什么关系**：**标准化**（第 9 周特征工程）`(X - mean) / std` 就是两处广播；**批量加偏置** `z = X @ w + b` 里的 `b` 是一个 `(d,)` 向量，广播到每个样本；**softmax 减 max**（数值稳定）也是广播。**读得懂广播，就读得懂一半的"一行式"预处理代码。**

> ⚠️ **常见陷阱**：广播规则"从最后一个维度开始比较"意味着 `(3,)` 和 `(2,2)` 不兼容（3 vs 2，都不为 1），但 `(3,)` 和 `(2,3)` 兼容（最后一个 3=3，然后 1 vs 2 → 广播成 2）。**Shape 报错时，先把两个数组的 shape 打印出来，用"末位对齐"的规则检查。**

### 6.4 常见向量化模式（ML 里天天用）

> 📱 **ML 预处理和损失计算里反复出现的五个模式**，全部一行搞定。这些就是你在阶段三里会反复看到的代码形态。

> 💻 **建文件 `ch6_patterns.py`**：

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.uniform(0, 10, (5, 3))     # 5 个样本，3 个特征

# 模式 1：标准化（按列）—— 广播的教科书案例
mean = X.mean(axis=0)              # 每列的均值 (3,)
std  = X.std(axis=0)               # 每列的标准差 (3,)
X_std = (X - mean) / std           # 广播：每行都减同一列均值、除同一列 std
print("标准化后每列均值≈0、std≈1:")
print("  列均值:", np.round(X_std.mean(axis=0), 10))
print("  列标准差:", np.round(X_std.std(axis=0), 4))

# 模式 2：批量线性层 z = X @ W + b（W: (d_in, d_out), b: (d_out,)）
W = rng.standard_normal((3, 2))
b = rng.standard_normal(2)
z = X @ W + b                      # (5,3)@(3,2) -> (5,2)，b 广播到 5 行
print("批量线性输出形状:", z.shape)

# 模式 3：数值稳定的 softmax（对每一行）
def softmax_rows(Z):
    Z = Z - Z.max(axis=1, keepdims=True)     # 减每行最大值（广播）
    E = np.exp(Z)
    return E / E.sum(axis=1, keepdims=True)  # 每行除以行和

scores = rng.standard_normal((4, 5))
P = softmax_rows(scores)
print("每行 softmax 求和:", np.round(P.sum(axis=1), 6), "（全是 1）")

# 模式 4：掩码（boolean mask）—— 过滤与统计
noise = rng.standard_normal(1000)
print("正数比例:", (noise > 0).mean())   # 约 0.5
big = noise[np.abs(noise) > 2]           # 选出 |x|>2 的元素
print("|x|>2 的元素个数:", len(big), "（标准正态约 5% 落在 2σ 外，即约 45 个）")

# 模式 5：批量欧氏距离（点积 + 广播的合体）
A = rng.standard_normal((3, 4))    # 3 个向量
B = rng.standard_normal((2, 4))    # 2 个向量
# 想要 (3,2) 的"每对距离"矩阵：用 (3,1,4) - (2,4) 广播
diff = A[:, None, :] - B[None, :, :]      # (3,1,4)-(1,2,4) -> (3,2,4)
dist = np.sqrt((diff ** 2).sum(axis=-1))
print("距离矩阵形状:", dist.shape)        # (3,2)
```

> 📱 **这和 ML 有什么关系**：这五个模式就是阶段三里"数据预处理 → 前向传播 → softmax → 评估"的全部基础动作。第 10 周 PyTorch 的 Tensor 用法和这里几乎一一对应（`axis` 换成 `dim`）。**你现在练熟的每个模式，到了 PyTorch 都是肌肉记忆。**

### 7.1 线性回归 + 梯度下降（全流程）

> 📱 **问题**：给一堆 (x, y) 数据点，找一条直线 `y = wx + b` 尽量穿过它们。

> 📐 **模型**：`ŷ = wx + b`；**损失**：MSE = (1/n)Σ(ŷᵢ - yᵢ)²；**梯度**（第二章速查表）：`∂MSE/∂w = (2/n)Σ(误差)·x`、`∂MSE/∂b = (2/n)Σ(误差)`；**更新**：`w ← w - lr·梯度`。

> 💡 **Aha Moment**：把 `w` 和 `b` 拼成一个向量 `θ = [w, b]`，再把每个样本的 `x` 拼成 `Xb = [x, 1]`，那么 `ŷ = Xb @ θ`——**一个矩阵乘法同时算出全部样本的预测**。这就是向量化的力量，也是"增广特征"技巧的第一次亮相（逻辑回归、softmax 回归都会复用）。

> 💻 **建文件 `linreg_scratch.py`**：

```python
import numpy as np

rng = np.random.default_rng(42)

# ---------- ① 生成带噪声的数据 ----------
n = 100
X = rng.uniform(0, 10, (n, 1))
true_w, true_b = 3.0, 2.0
y = true_w * X + true_b + rng.normal(0, 2, (n, 1))   # 高斯噪声

# 增广特征：把 b 的吸收进权重向量 → 一次矩阵乘法搞定全部
Xb = np.c_[X, np.ones((n, 1))]    # (100, 2)，第二列全 1
theta = rng.standard_normal((2, 1)) * 0.1   # [w, b]

# ---------- ② 前向 + 损失 ----------
def predict(Xb, theta):
    return Xb @ theta

def mse(y_hat, y):
    return ((y_hat - y) ** 2).mean()

# ---------- ③ 梯度 + 训练循环 ----------
lr = 0.01
print("训练开始，初始 loss =", round(mse(predict(Xb, theta), y), 2))
for epoch in range(2000):
    y_hat = predict(Xb, theta)                 # 前向（向量化）
    err = y_hat - y                            # 误差
    grad = (2 / n) * Xb.T @ err                # 梯度（速查表 ③ 的向量版）
    theta -= lr * grad                         # 更新

    if epoch in (0, 99, 499, 999, 1999):
        print(f"  epoch {epoch:4d}: loss = {mse(y_hat, y):8.3f}  "
              f"w = {theta[0,0]:6.3f}  b = {theta[1,0]:6.3f}")

# ---------- ④ 验证 ----------
print(f"\n学到的 w = {theta[0,0]:.3f}（真实 3.0），b = {theta[1,0]:.3f}（真实 2.0）")
print("→ 噪声存在时逼近但不精确，这是'拟合'的本意")

# 梯度正确性验证：解析梯度 vs 数值梯度（差应 < 1e-5）
def num_grad_all(f, theta0, h=1e-6):
    g = np.zeros_like(theta0)
    for i in range(len(theta0)):
        tp = theta0.copy(); tp[i] += h
        tm = theta0.copy(); tm[i] -= h
        g[i] = (f(tp) - f(tm)) / (2 * h)
    return g

theta0 = np.array([[1.0], [0.5]])
f = lambda th: mse(Xb @ th, y)
analytic = (2 / n) * Xb.T @ (Xb @ theta0 - y)
numeric = num_grad_all(f, theta0)
print("解析梯度 vs 数值梯度最大差:", np.abs(analytic - numeric).max())  # < 1e-5
```

> 🎉 **恭喜！你完成了人生第一个"训练"**：loss 从几百降到接近噪声下限，w、b 逼近真实值。`05-阶段三上` 第 8 周手写线性回归就是这段代码加了画图。**注意那个"解析梯度 vs 数值梯度"的验证——它证明你手写的梯度公式没写错。** 这个验证习惯要保留一生。

### 7.2 逻辑回归（分类）

> 📱 **问题**：给定两类点（红色/蓝色），学一个"这个点属于红色类的概率"。模型输出在 (0,1) 之间。

> 📐 **模型**：`z = w·x + b`（线性），`ŷ = σ(z) = 1/(1+e⁻ᶻ)`（sigmoid 压缩成概率）。**损失**：交叉熵 `Loss = -[y·log(ŷ) + (1-y)·log(1-ŷ)]`。**梯度**（第五章的优雅结果）：`∂Loss/∂w = (ŷ - y)·x`、`∂Loss/∂b = (ŷ - y)`。**和线性回归的梯度形式几乎一样**，只是预测从 `wx+b` 换成了 `σ(wx+b)`、损失从 MSE 换成了交叉熵。

> 💻 **建文件 `logreg_scratch.py`**：

```python
import numpy as np

rng = np.random.default_rng(1)

# ---------- ① 生成两类可线性分的数据 ----------
c1 = rng.normal(0, 1, (60, 2)) + np.array([2.0, 2.0])   # 正类，中心 (2,2)
c0 = rng.normal(0, 1, (60, 2)) + np.array([-2.0, -2.0]) # 负类，中心 (-2,-2)
X = np.vstack([c1, c0])
y = np.r_[np.ones(60), np.zeros(60)].reshape(-1, 1)     # 标签 1 / 0

Xb = np.c_[X, np.ones((len(X), 1))]      # 增广：含偏置列
theta = np.zeros((3, 1))

# ---------- ② 模型（sigmoid）----------
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def predict_proba(Xb, theta):
    return sigmoid(Xb @ theta)

def cross_entropy_loss(p, y, eps=1e-12):
    p = np.clip(p, eps, 1 - eps)          # 防 log(0)
    return -(y * np.log(p) + (1 - y) * np.log(1 - p)).mean()

# ---------- ③ 梯度 + 训练 ----------
lr = 0.1
print("训练开始，初始 loss =", round(cross_entropy_loss(predict_proba(Xb, theta), y), 3))
for epoch in range(2000):
    p = predict_proba(Xb, theta)          # 前向
    grad = Xb.T @ (p - y) / len(X)        # 梯度 = (预测 - 真实)·x（速查表 ⑤）
    theta -= lr * grad
    if epoch in (0, 199, 499, 999, 1999):
        print(f"  epoch {epoch:4d}: loss = {cross_entropy_loss(p, y):8.4f}")

# ---------- ④ 验证 ----------
pred = (predict_proba(Xb, theta) >= 0.5).astype(int).ravel()
acc = (pred == y.ravel()).mean()
print(f"\n训练集准确率: {acc*100:.1f}%")
p0 = predict_proba(Xb, theta)[0, 0]
print(f"第一个样本预测概率: {p0:.4f} → 分类为 {'正类' if p0 >= 0.5 else '负类'}")

# 决策边界：w·x + b = 0 那条线（二维里就是 x2 = -w1/w2*x1 - b/w2）
w1, w2, b = theta[0,0], theta[1,0], theta[2,0]
print(f"决策边界: x₂ = {-w1/w2:.3f}·x₁ + {-b/w2:.3f}（把两类分开的直线）")
```

> 🎉 **你实现了一个分类器**。注意它的梯度就是 `(预测 - 真实) × 特征`——和线性回归几乎一模一样，这就是 `05` 文件说的"数学的精心设计"。第 8 周面试题"线性回归和逻辑回归的区别"的答案，你已经在代码里写出来了：**线性回归输出实数用 MSE；逻辑回归外层包 sigmoid 输出概率用交叉熵，梯度形式相同。**

### 7.3 Softmax 回归（多分类）

> 📱 **问题**：三类或更多类。给一个样本，输出"它属于每一类的概率"，全部概率加起来等于 1。

> 📐 **模型**：对 K 类，`logits = X @ W`（W 是 (特征数, K) 的权重矩阵），**softmax**：`Pᵢ = e^zᵢ / Σe^zʲ`。**损失**：多分类交叉熵 `Loss = -log(P[真实类别])`。**梯度**（速查表 ⑤）：`∂Loss/∂W = Xᵀ @ (P - Y)`，其中 Y 是 one-hot 标签矩阵。**这是全指南最优雅的一条梯度。**

> 💻 **建文件 `softmax_scratch.py`**：

```python
import numpy as np

rng = np.random.default_rng(7)

# ---------- ① 生成三团可分的数据 ----------
blobs = []
for k in range(3):
    blobs.append(rng.normal(0, 1, (80, 2)) + np.array([k * 3.0, 0]))
X = np.vstack(blobs)                       # (240, 2)
y = np.repeat([0, 1, 2], 80)               # 三类标签
Xb = np.c_[X, np.ones((len(X), 1))]        # (240, 3)

# ---------- ② softmax + 交叉熵 ----------
def softmax(logits):
    z = logits - logits.max(axis=1, keepdims=True)   # 数值稳定
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

def predict_proba(Xb, W):
    return softmax(Xb @ W)

def cross_entropy_loss(P, y, eps=1e-12):
    n = len(y)
    return -np.mean(np.log(P[np.arange(n), y] + eps))   # 只取真实类别那列

# ---------- ③ 训练 ----------
W = np.zeros((3, 3))        # (特征数+1, 类数)
lr = 0.5
Y_onehot = np.eye(3)[y]     # 标签 → one-hot 矩阵
print("训练开始，初始 loss =", round(cross_entropy_loss(predict_proba(Xb, W), y), 3))
for epoch in range(1500):
    P = predict_proba(Xb, W)                 # 前向
    grad = Xb.T @ (P - Y_onehot) / len(X)    # 梯度 = Xᵀ(P - Y)（速查表 ⑤）
    W -= lr * grad
    if epoch in (0, 199, 499, 999, 1499):
        print(f"  epoch {epoch:4d}: loss = {cross_entropy_loss(P, y):8.4f}")

# ---------- ④ 验证 ----------
P = predict_proba(Xb, W)
pred = np.argmax(P, axis=1)
acc = (pred == y).mean()
print(f"\n训练集准确率: {acc*100:.1f}%")
print("每个样本概率和（应全为 1）:", np.round(P.sum(axis=1)[:3], 6))
print("第一个样本的类别概率分布:", np.round(P[0], 3),
      "→ 预测类别", pred[0], "（真实", y[0], "）")
```

> 🎉 **多分类完成！** 你刚刚实现的就是 `05-阶段三上` 第 8 周末尾预告的"多分类逻辑回归 = softmax 回归"。第 11 周你会手写 softmax 和 PyTorch 官方对比——现在你已经提前会了。**注意梯度 `Xᵀ(P-Y)`：它把"预测 - 真实"推广到了多分类。深度学习的"梯度 = 预测减真实"这个家族，你已经集齐了三种：回归（MSE）、二分类（sigmoid+CE）、多分类（softmax+CE）。**

### 7.4 数值验证：手写梯度 vs 数值梯度

> 📱 **为什么需要这一节**：手写梯度最容易出 bug（形状错了、少乘了个系数、符号反了）。**数值梯度是"照妖镜"**：它不需要任何推导，直接用"参数动一丁点，loss 变多少"来近似梯度。如果手写梯度和数值梯度不一致，说明你的推导或代码有错。PyTorch 的 Autograd 就是"手写梯度"的替身，而数值梯度永远是最终裁判。

> 💻 **建文件 `gradient_check.py`**：把 7.3 的 softmax 梯度用数值梯度全面验证一次。这是全指南的"压轴验证"。

```python
import numpy as np

rng = np.random.default_rng(3)
X = rng.standard_normal((5, 3))          # 5 个样本，3 维特征
y = rng.integers(0, 4, 5)                # 4 类
Xb = np.c_[X, np.ones((5, 1))]           # (5, 4)
W = rng.standard_normal((4, 4)) * 0.5
Y_onehot = np.eye(4)[y]

def softmax(logits):
    z = logits - logits.max(axis=1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

def loss_of(W):
    P = softmax(Xb @ W)
    return -np.mean(np.log(P[np.arange(len(y)), y] + 1e-12))

# 手写梯度：Xᵀ(P - Y) / n
P = softmax(Xb @ W)
grad_analytic = Xb.T @ (P - Y_onehot) / len(X)

# 数值梯度：每个权重动一丁点
grad_numeric = np.zeros_like(W)
h = 1e-6
for i in range(W.shape[0]):
    for j in range(W.shape[1]):
        Wp = W.copy(); Wp[i, j] += h
        Wm = W.copy(); Wm[i, j] -= h
        grad_numeric[i, j] = (loss_of(Wp) - loss_of(Wm)) / (2 * h)

diff = np.abs(grad_analytic - grad_numeric).max()
print(f"手写梯度 vs 数值梯度 最大差 = {diff:.2e}")
print("结论：", "✅ 梯度公式正确（差 < 1e-7）" if diff < 1e-7 else "❌ 梯度有误，请检查")

# 故意写错一个符号演示照妖镜的作用
grad_wrong = -Xb.T @ (P - Y_onehot) / len(X)
print(f"若符号写反，差 = {np.abs(grad_wrong - grad_numeric).max():.2e} → 照妖镜立刻现形")
```

> 📱 **这和 ML 有什么关系**：这是你以后调试所有模型的**标准动作**。第 10 周 PyTorch 用 `loss.backward()` 自动算梯度，你同样可以用数值梯度验证它（`06` 第 12 周的手写反向传播 vs Autograd 验证就是同一个思想）。**记住这条黄金流程：实现 → 数值验证 → 再往前。** 它能省下你数不清的调试时间。

### 8.1 线性代数练习

**练习 1**（点积）：`a = [1, 2, 3]`，`b = [4, 5, 6]`，手算 `a·b`，再用 `np.dot` 验证。（答案：32）

**练习 2**（矩阵乘法形状）：`A` 是 `(3, 4)`，`B` 是 `(4, 2)`，`A @ B` 的形状是？（答案：(3, 2)；内维 4=4 对齐）

**练习 3**（增广特征）：为什么 `y = wx + b` 可以写成 `y = Xb @ theta`？（答案：把 `[x, 1]` 当特征、`[w, b]` 当权重，b 就变成了"和常数 1 相乘的权重"，一次矩阵乘法搞定全部样本）

**练习 4**（sigmoid 导数）：证明 `σ'(z) = σ(z)(1-σ(z))`，并用数值梯度验证 `z=0.7` 处。（答案：用商法则或直接对 `1/(1+e⁻ᶻ)` 求导；数值验证约 0.2217）

> 💻 **代码验证**：

```python
import numpy as np
# 练习 1
a, b = np.array([1,2,3]), np.array([4,5,6])
print("练习1 点积:", a @ b)                      # 32

A = np.ones((3,4)); B = np.ones((4,2))

# 练习 4
z = 0.7
s = 1/(1+np.exp(-z))

numeric = (1/(1+np.exp(-(z+1e-6))) - 1/(1+np.exp(-(z-1e-6))))/(2e-6)
print("练习4 sigmoid导数 解析:", analytic, "数值:", numeric)
```

### 8.2 微积分练习

**练习 5**（导数直觉）：函数 `f(x) = x³`，`x=2` 处的导数是？（答案：12；用 `(f(x+h)-f(x-h))/(2h)` 验证）

**练习 6**（偏导数）：`f(w, b) = w² + 3b`，求 `∂f/∂w` 和 `∂f/∂b` 在 `(w=2, b=1)` 的值。（答案：∂f/∂w = 2w = 4；∂f/∂b = 3）

**练习 7**（链式法则）：`z = e^(3x)`，用链式法则求 `dz/dx`，在 `x=1` 处验证。（答案：dz/dx = 3e^(3x)，x=1 时 ≈ 60.26）

**练习 8**（梯度下降）：对 `loss(w) = (w-5)²`，从 `w=0` 出发，用 `lr=0.1` 走 30 步，最后 w 接近？（答案：接近 5；梯度 `2(w-5)` 把 w 推向谷底）

> 💻 **代码验证**：

```python
import numpy as np
# 练习 5
f = lambda x: x**3
print("练习5 导数:", (f(2+1e-6)-f(2-1e-6))/(2e-6))          # 12
# 练习 7
g = lambda x: np.exp(3*x)
print("练习7 链式:", (g(1+1e-6)-g(1-1e-6))/(2e-6), "解析 3e³ =", 3*np.exp(3))
# 练习 8
w = 0.0
for _ in range(30):
    w -= 0.1 * 2*(w-5)
print("练习8 梯度下降终值:", round(w, 4))                    # ≈5.0
```

> 💻 **代码验证**：

```python
import numpy as np
```

### 8.4 信息论练习

**练习 12**（熵）：三分类分布 `[0.5, 0.3, 0.2]` 的熵（以 2 为底）约是多少？（答案：约 1.485 比特）

**练习 13**（交叉熵）：二分类，真实标签 `y=1`，模型输出 `ŷ=0.001`，损失 `-log(0.001)` ≈ ?（答案：约 6.91）

**练习 14**（交叉熵 vs MSE 的梯度）：在 `ŷ=0.01`、`y=1`、`x=3` 时，比较交叉熵梯度 `(ŷ-y)x` 和 MSE+sigmoid 梯度 `(ŷ-y)ŷ(1-ŷ)x` 的大小。（答案：交叉熵 ≈ -2.97，MSE 版 ≈ -0.029——交叉熵大 100 倍，学得快）

> 💻 **代码验证**：

```python
import numpy as np
# 练习 12
p = np.array([0.5, 0.3, 0.2])
print("练习12 熵:", round(-(p*np.log2(p)).sum(), 3))       # ≈1.485
# 练习 13

y_hat, y, x = 0.01, 1.0, 3.0
```
