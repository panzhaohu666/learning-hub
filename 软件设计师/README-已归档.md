# ⚠️ 本目录已归档：方向从「软件设计师」改为「网络工程师」

**归档日期：2026-11-04**

## 为什么归档

本目录下 6 个文件（合计 17,539 行）是为**软件设计师（中级）**准备的备考材料。实际报考的是**网络工程师（中级）**，两个方向的考试内容几乎没有交集：

| | 软件设计师 | 网络工程师 |
|---|---|---|
| 上午/科目一 | 数据结构与算法、软件工程、面向对象与 UML、程序设计语言、操作系统、计算机组成、数据库、计算机网络（仅 5–7 分） | 计算机系统、系统开发运行、**网络技术**（主体）、网络安全、标准化、信息化、专业英语 |
| 下午/科目二 | DFD、ER 图、UML、算法设计 | 网络规划与设计、设备配置、故障排查、安全配置 |

**结论：本目录对网络工程师考试的有效贡献接近零。** 数据结构和算法、UML、设计模式、软件工程过程模型这些占了本目录大部分篇幅的内容，网络工程师一份都不考。

## 那为什么没删

留下来的不是内容，是**结构**：

- `05-教材重点笔记_速查版.md` 的「章 → 节 → 速查表」三层切分，以及「每节一张对照表」的密度，这个组织形式是可复用的。
- `02/03` 两份每日指南的「手机 30 分钟 + 电脑 2 小时」二元结构，用在了新的 `网络工程师/03-每周执行模板.md` 里（比例按 3 小时/周重算为 1h + 2h）。

**不能复用的是切分本身。** 本目录的章节切分绑死在《软件设计师教程（第 5 版）》12 章和它自己的分值体系上（文件里到处是 `（6分/75）` 这类标注）。网络工程师的科目一按 9 个模块划分，粒度完全不同——「网络技术」在网工里是主干，在软工里只值 5–7 分。照搬切分会把主干和边角搞反。

## 使用规则

1. **不要**把本目录当成备考材料读。读它准备网络工程师是浪费时间。
2. **可以**借鉴文件组织形式，但内容必须重新按网络工程师大纲写。
3. 本目录**不再更新**。其中已知的错误也不会再修（例如 `06-软件开发全流程SOP.md` 原被指为「放错位置」，但它在本目录内的定位是自洽的：README 曾把它列为「软件工程模块新增」，而软件工程在软件设计师上午题占 10–12 分）。
4. 目录名保留，是为了让后来的人能看到「换过方向」这件事，也知道为什么换。
