### 手机摸鱼 · 上午 30 分钟
阅读主题：顺序表 vs 单链表

核心知识点（手机直接看，不需要翻教材）

1. 顺序表

本质：一个数组。
地址：LOC(a_i) = LOC(a_1) + (i-1) × sizeof(元素)
每一个元素在内存中紧挨着存储，所以可以通过下标直接访问。

优点：O(1) 随机访问。知道第 i 个元素在哪，直接跳过去。
缺点：插入/删除 O(n)。因为要移动后面所有元素。
比如在位置 3 插入一个元素，位置 3 到末尾的每个元素
都要往后挪一格。10万元素的数组，平均要移动 5 万次。

适用场景：频繁查找、少插入删除。

2. 单链表

本质：一串"结点"，每个结点包含两部分——数据 + 指向下一个的指针。
地址：不连续。每个结点在内存中的位置是任意的。
通过指针串联起来。

优点：插入/删除 O(1)。只需修改指针指向，不需要移动元素。
缺点：访问 O(n)。要找第 i 个元素必须从头开始一个个数。

适用场景：频繁插入删除、少随机访问。

3. 核心操作：单链表的插入和删除（面试背这四行！）

在 p 指向的结点后面插入一个新结点：
newNode.next = p.next;   // 新结点的 next 指向 p 原来指向的下一个
p.next = newNode;         // p 的 next 指向新结点
注意顺序！先连后面再断前面。如果反过来（先改p.next），
原来 p.next 指向的结点就找不到了——内存泄漏。

删除 p 后面的结点：
q = p.next;               // 记下要删的结点
p.next = q.next;          // p 跨过 q 指向 q 的下一个
free(q);                  // 释放内存（C语言）或 del q（Python自动回收）

4. 其他链表结构
双向链表：每个结点有 prev 和 next 两个指针。
可以双向遍历，删除时不需要找前驱。
循环链表：最后一个结点的 next 指向头结点，形成环。
约瑟夫问题（报数出圈）的经典解法。

```python
def reverse(self):

               第一轮后：head→A→None  (B→C→...暂存)
               第二轮后：head→B→A→None
               第三轮后：head→C→B→A→None

            p = self.head.next      # 当前处理的结点
            self.head.next = None   # 断开链表
```

```python
                # 头插法：把 p 插到 head 后面
```

### 手机摸鱼 · 上午 30 分钟
阅读主题：栈 —— 后进先出（LIFO）

核心知识点

1. 栈的概念

只在一端（栈顶）进行插入和删除操作。另一端是栈底。
想象一摞盘子：最后放上去的（栈顶）最先被拿走。

操作：
push：入栈（压栈），在栈顶放一个元素
pop：出栈（弹栈），从栈顶取走一个元素
peek/top：查看栈顶元素但不删除
isEmpty：判空

全用 O(1) 完成。

2. 顺序栈（用数组实现）

```python
     class SeqStack:
         def __init__(self, maxsize=100):
             self.data = [None] * maxsize  # 预分配数组
             self.top = -1                 # 栈顶指针，-1 表示空栈
```

```python
def push(self, x):
             if self.top == len(self.data) - 1:
                 raise OverflowError("栈满")
             self.top += 1           # 指针上移
             self.data[self.top] = x # 存数据
```

```python
def pop(self):
             if self.top == -1:
                 raise IndexError("栈空")
             x = self.data[self.top]  # 取数据
             self.top -= 1            # 指针下移
             return x
```

```python
def is_empty(self):
             return self.top == -1
     ```
```

入栈：top++ 再存。出栈：取数据后再 top--。

3. 链栈（用链表实现，栈顶在链表头）

```
```python
     class LinkStack:
         def __init__(self):
             self.top_node = None  # 栈顶结点（即链表头）
```

```python
def push(self, x):
             new_node = Node(x)
             new_node.next = self.top_node  # 头插法
             self.top_node = new_node
```

```python
def pop(self):
             if self.top_node is None:
                 raise IndexError("栈空")
             x = self.top_node.data
             self.top_node = self.top_node.next  # 头删法
             return x
     ```
```

链栈不用数组预分配，不会栈满，理论上可以无限扩容。

4. 栈的经典应用：括号匹配
问题：判断一个表达式中的括号是否匹配。
例："{[()]}" → 匹配；"{[(])}" → 不匹配；"((())" → 不匹配。

算法思路（用一个栈）：
扫描表达式的每个字符：
- 遇到左括号 '('、'{'、'[' → 压入栈
- 遇到右括号 ')'、'}'、']' → 查看栈顶：
如果栈空 → 匹配失败（右括号多了）
如果栈顶的左括号和当前右括号不是一对 → 匹配失败
如果是一对 → 弹出栈顶
扫描完后：
- 栈空 → 全部匹配成功
- 栈非空 → 左括号多了

这道题年年变形考。考场遇到直接默写思路。
```

```
1. 队列的概念

2. ★ 循环队列（考试重点！）

问题：用数组实现普通队列时，入队出队多次后，
front 在数组中间，前面空着但后面满了 → 假溢出。

解决：把数组"头尾相连"成环。当 rear 走到数组末尾时，
不是报错，而是回到 0 位置继续。

关键公式（必须背！）：
rear 入队后移：rear = (rear + 1) % MAXSIZE
front 出队后移：front = (front + 1) % MAXSIZE
队列长度：(rear - front + MAXSIZE) % MAXSIZE

- ⭐ 判空判满（考试最高频考点！）★
方法 1（牺牲一个空间）：判空 front==rear；判满 (rear+1)%MAXSIZE==front
方法 2（额外用一个变量计数）：count==0 空；count==MAXSIZE 满
方法 3（加 tag 标记）：tag=0 上次是出队则 front==rear 为空；
tag=1 上次是入队则 front==rear 为满

考试中默认用方法 1。问"容量为 n 的循环队列最多存几个元素"→ n-1 个。

```
```python
     class CircularQueue:
         def __init__(self, capacity):
             self.capacity = capacity + 1  # 多开一个空间用于判满
             self.data = [None] * self.capacity
             self.front = 0
             self.rear = 0
```

```python
def is_empty(self):
             return self.front == self.rear
```

```python
def is_full(self):
             return (self.rear + 1) % self.capacity == self.front
```

```python
def enqueue(self, x):
             if self.is_full():
                 raise OverflowError("队列满")
             self.data[self.rear] = x
             self.rear = (self.rear + 1) % self.capacity
```

```python
def dequeue(self):
             if self.is_empty():
                 raise IndexError("队列空")
             x = self.data[self.front]
             self.front = (self.front + 1) % self.capacity
             return x
```

```python
def length(self):
             return (self.rear - self.front + self.capacity) % self.capacity
     ```

```
### 第1周 · 星期四：串 + KMP
---
### 手机摸鱼 · 上午 30 分钟
阅读主题：KMP 算法

核心知识点

1. BF（暴力匹配）

模式串 "abc" 在主串 "ababcabc" 中查找。
从主串位置 0 开始逐个比较。匹配失败 → 主串回退到 i-j+2
（回到这次匹配的起始位置的下一位），模式串回到开头。
最坏 O(m×n)。

2. KMP 的核心思想

匹配失败时，主串不回退！只移动模式串。
利用已匹配部分的信息——失配字符之前已匹配的子串中，
前缀和后缀相等的最大长度就是模式串可以"跳过"的长度。

3. next 数组（手动推导法）

next[j]：第 j 个字符失配时，模式串应跳到哪个位置继续匹配。
也就是"前 j-1 个字符中，前缀和后缀相等的最长长度"。

例：模式串 "ababc"
j=1: 没有前 0 个字符 → next[1] = 0
j=2: "a"的前缀和后缀相等最长 = 0 → next[2] = 1
j=3: "ab"的前缀和后缀相等最长 = 0 → next[3] = 1
j=4: "aba"的前缀"a"=后缀"a"=1 → next[4] = 2
j=5: "abab"的前缀"ab"=后缀"ab"=2 → next[5] = 3

next = [0, 0, 1, 1, 2]  (第1个位置习惯设为0)

实际做题验证：
next[4]=2 意思是：第4个字符 b 失配时，模式串跳过 1 个字符，
从第 2 个字符继续和主串当前位置比较。因为 "aba" 的前缀"a" = 后缀"a"，
所以"ab" 已经匹配的部分在跳过时直接对齐。

4. nextval 数组（KMP 改进版，考试也可能考）
nextval 是对 next 的优化。如果在 next[j] 位置上的字符和失配字符一样，
那跳过去也会失配，不如继续往前跳。

例："aaaab"
next = [0, 0, 1, 2, 3]
但 j=4 时跳到 j=3，字符也是 'a'，一样失配 → 继续跳到 j=2 → 继续跳...
nextval 直接跳到最终位置：[0, 0, 0, 0, 3]
```

```python
    def get_next(pattern):
        """求 KMP 的 next 数组"""
        m = len(pattern)
        next_arr = [0] * m
        j = 0  # j 指向"已匹配前缀的末尾"
        for i in range(1, m):
            # 不匹配时 j 回退
            while j > 0 and pattern[i] != pattern[j]:
                j = next_arr[j-1]
            # 匹配时 j 前进
            if pattern[i] == pattern[j]:
                j += 1
            next_arr[i] = j
        return next_arr
```

```python
def kmp_search(text, pattern):
        """KMP 字符串匹配"""
        n, m = len(text), len(pattern)
        if m == 0:
            return 0
        next_arr = get_next(pattern)
        j = 0
        for i in range(n):
            while j > 0 and text[i] != pattern[j]:
                j = next_arr[j-1]
            if text[i] == pattern[j]:
                j += 1
            if j == m:  # 完全匹配
                return i - m + 1
        return -1
```

```
### 手机摸鱼 · 上午 30 分钟
阅读主题：二叉树

核心知识点

1. 二叉树性质（每年必考 1-2 道选择题！背下来！）

① 第 i 层最多 2^(i-1) 个结点（i≥1）
② 深度为 k 的二叉树最多 2^k - 1 个结点
③ n₀ = n₂ + 1（叶子数 = 度为 2 的结点数 + 1）

推导：总边数 = n-1 = n₁ + 2n₂（每个度为 1 的结点贡献 1 条边，
度为 2 的贡献 2 条边）
又 n = n₀ + n₁ + n₂
联立两式：n₀ + n₁ + n₂ - 1 = n₁ + 2n₂
消去 n₁：n₀ - 1 = n₂ → n₀ = n₂ + 1 ✓

2. 满二叉树 vs 完全二叉树（概念题高频）

满二叉树：每层都满。深度 k 时结点数 = 2^k - 1。
完全二叉树：最后一层从左到右连续排列，其余层全满。
堆就是一棵完全二叉树。

完全二叉树的特点：
- 顺序存储（数组）不会浪费空间
- 编号为 i 的结点：左孩子 2i，右孩子 2i+1，父结点 i/2 向下取整
（编号从 1 开始的话）

3. 四种遍历（闭眼能默写！）

前序（Preorder）：根 → 左 → 右   （前缀表达式）
中序（Inorder）：左 → 根 → 右    （二叉搜索树排序）
后序（Postorder）：左 → 右 → 根  （后缀表达式/求树高）
层序（Level）：从上到下，从左到右（BFS）
```

```
前序 + 中序 → 唯一确定二叉树！
后序 + 中序 → 唯一确定二叉树！

方法（以"前序+中序"为例）：
① 前序第一个是整棵树的根
② 在中序中找根的位置 → 左边是左子树的中序，右边是右子树的中序
③ 前序中根后面左子树长度个结点是左子树的前序
④ 递归

例：前序=ABDEC  中序=DBEAC
→ 根=A，中序中 A 左边 DBE=左子树，右边 C=右子树
→ 左子树：前序=BDE，中序=DBE → 根=B，中序中 B 左边 D，右边 E
→ 树形：A(左=B(左=D, 右=E), 右=C)
```

```
### 手机摸鱼 · 上午 30 分钟
阅读主题：二叉排序树（BST）和哈夫曼树

核心知识点

1. 二叉排序树（BST / 二叉搜索树）

性质：左子树 < 根 < 右子树（中序遍历得升序序列）

查找过程：从根开始，比根小走左边，比根大走右边。
平均 O(logn)，最坏 O(n)（退化成链表）。
退化的原因：数据本身有序 → 插入后全是左孩子或全是右孩子。

插入：查找失败的位置就是插入位置（一定是叶子）。

删除（分三种情况）：
① 叶子结点：直接删
② 只有一个孩子：孩子替代它
③ 有两个孩子：用右子树的最小结点（中序后继）替代它
（或者左子树的最大结点）

2. 哈夫曼树（最优二叉树）

目标：带权路径长度 WPL = Σ(wᵢ × lᵢ) 最小。
其中 wᵢ 是叶子权值，lᵢ 是从根到叶子的路径长度。

构造方法（贪心法）：
① 每个权值是一棵单结点树，放入集合
② 每次选权值最小的两棵树合并为新树（新树权值=两树之和）
③ 重复②直到只剩一棵树

例：权值 {2, 3, 5, 7}
第1步：选 2 和 3 → 合并权值=5
第2步：选 5（刚合并的）和 5（原）→ 合并权值=10
第3步：选 7 和 10 → 合并权值=17
WPL = 2×3 + 3×3 + 5×2 + 7×1 = 6+9+10+7 = 32

哈夫曼编码：每个叶子的路径（左0右1）就是该字符的编码。
特性：前缀编码——任一个字符的编码不是另一个的前缀。
因为所有字符都在叶子结点，彼此不"包含"。

今日思考题

步骤：先排序 {1,1,2,3,5} → 1+1=2 → {2,2,3,5} → 2+2=4 → {3,4,5}
→ 3+4=7 → {5,7} → 5+7=12
WPL = (1+1)×3 + 2×2 + 3×2 + 5×1 = 6+4+6+5 = 21

### 手机摸鱼 · 上午 30 分钟
阅读主题：二分查找 + 哈希表

核心知识点

1. 二分查找

前提：有序顺序表！链表不行（无法 O(1) 取中间元素）。
过程：每次取 mid=(low+high)//2，和目标值比较：
相等 → 找到了
目标 < arr[mid] → 去左半边（high=mid-1）
目标 > arr[mid] → 去右半边（low=mid+1）
时间复杂度 O(logn)，空间 O(1)。

判定树（也叫比较树）：把查找过程画成二叉树。
树的高度 = ⌈log₂(n+1)⌉，最大比较次数 = 树的高度。
查找成功时，比较次数 = 从根到该结点的路径长度 + 1。

2. 哈希表 ★ 上午题必考 2 道！

核心思想：通过哈希函数 H(key) 直接把 key 映射到数组下标。

哈希函数构造：
最常见：除留余数法 H(key)=key % p（p 是不大于表长的最大质数）

冲突处理（两个不同的 key 映射到同一位置）：
① 开放地址法：
线性探测：Hᵢ = (H(key) + i) % m   （i=0,1,2,...）
→ 问题：聚集——连续多个位置被占，查找变慢
二次探测：Hᵢ = (H(key) + i²) % m   （i=1,2,3,...）
→ 减少聚集但不保证能找到空位
② 链地址法：每个位置挂一个链表，冲突的元素链在一起。
→ 查找高效，不担心表满。最常用的方法。

- ⭐ ASL（平均查找长度）计算 ★ 上午题每年考！
成功 ASL = Σ(每个元素查找 1 次所需的比较次数) / 元素个数
失败 ASL = Σ(每个位置查找失败所需的比较次数) / 哈希表长度

例：H(key)=key%7，插入 {8, 15, 16, 22, 30}
8%7=1, 15%7=1(冲突→线性探测→2), 16%7=2(→3), 22%7=1(→4), 30%7=2(→5)
位置 0:空 1:8 2:15 3:16 4:22 5:30 6:空
成功 ASL：8(1次)+15(2次)+16(2次)+22(3次)+30(4次) / 5 = 2.4

3. 装填因子 α

α = 表中已存元素数 / 哈希表长度
α 越大 → 冲突概率越高 → ASL 越大。
一般 α 控制在 0.5-0.85 之间。

考场技巧
ASL 计算是"死分"——给数据就按过程一步步算，不需要理解。
但要注意：成功 ASL 除以元素个数，失败 ASL 除以表长度（不是元素个数！）

### 手机摸鱼 · 上午 30 分钟
阅读主题：插入排序、希尔排序、冒泡排序、快速排序

核心知识点（每种排序都从这三方面理解：怎么做、为什么、记住什么）

1. 直接插入排序（Insertion Sort）

怎么做：像打牌时整理手中的牌。从第二张开始，每张牌
插入到前面已排好的序列中的正确位置。

代码：
```
```python
     def insertion_sort(arr):
         for i in range(1, len(arr)):
             key = arr[i]          # 当前要插入的牌
             j = i - 1
             while j >= 0 and arr[j] > key:
                 arr[j+1] = arr[j] # 比key大的往后移
                 j -= 1
             arr[j+1] = key        # 插入
     ```
```

为什么O(n²)？外层循环 n-1 次，内层最坏移 i 次（i从1到n-1），
总共约 n²/2 次比较和移动。
最好O(n)？当数据已经有序时，内层while永远不执行。

记住：稳定、空间O(1)、最好O(n)、最坏O(n²)。

2. 希尔排序（Shell Sort）

怎么做：先按大的间隔(gap)做插入排序，不断缩小 gap 直到 1。
让元素"大步快跑"接近目标位置，最后 gap=1 时基本有序。

代码关键：
```
```python
     def shell_sort(arr):
         n = len(arr)
         gap = n // 2
         while gap > 0:
             for i in range(gap, n):  # 从 gap 开始，每个元素向前插入
                 key = arr[i]
                 j = i - gap
                 while j >= 0 and arr[j] > key:
                     arr[j+gap] = arr[j]
                     j -= gap
                 arr[j+gap] = key
             gap //= 2
     ```
```

记住：不稳定、空间O(1)，时间复杂度取决于 gap 序列。

3. 冒泡排序（Bubble Sort）

怎么做：每轮把最大的元素"冒泡"到最后面。
相邻比较，大的往后换。

优化（加 flag）：如果某轮没有任何交换 → 已经有序 → 提前结束。
所以最好情况 O(n)。

记住：稳定、空间O(1)、最好O(n)、最坏O(n²)。
考试陷阱：问你冒泡排序最好时间复杂度，记得是 O(n) 不是 O(n²)！

4. 快速排序（Quick Sort）★ 最重要！
怎么做：
① 选一个 pivot（基准）
② partition：把小于 pivot 的放左边，大于 pivot 的放右边
③ 递归对左右两边做同样的事

partition 过程（左右指针法）：
i 从左向右找第一个大于 pivot 的元素
j 从右向左找第一个小于 pivot 的元素
交换 i 和 j
重复直到 i 和 j 相遇

```
```python
     def quick_sort(arr, low, high):
         if low < high:
             pi = partition(arr, low, high)  # partition 返回 pivot 位置
             quick_sort(arr, low, pi - 1)    # 排左边
             quick_sort(arr, high, pi + 1)   # 排右边
```

```python
def partition(arr, low, high):
         pivot = arr[low]  # 选第一个元素为 pivot
         i, j = low, high
         while i < j:
             while i < j and arr[j] >= pivot: j -= 1  # j 向左找小的
             while i < j and arr[i] <= pivot: i += 1  # i 向右找大的
             if i < j:
                 arr[i], arr[j] = arr[j], arr[i]       # 交换逆序对
         arr[low], arr[i] = arr[i], arr[low]            # pivot归位
         return i
     ```
```

为什么不稳定？因为交换时可能跳过相等的元素。
为什么最坏 O(n²)？当 pivot 选取不当，每次只能排除 1 个元素
（如已排序时选第一个为 pivot），退化成一棵单支树，递归深度 n。

### 手机摸鱼
5. 简单选择排序
每轮选最小的和未排序部分的第一个交换。不管数据如何都是 O(n²)。
记住：不稳定（因为交换可能跳过相等的元素）。

6. 归并排序（Merge Sort）
分治：先递归拆成单个元素，再两两合并有序序列。
合并过程：两个指针分别指向两个有序序列的开头，每次取小的。
记住：始终 O(nlogn)，稳定，但需要 O(n) 额外空间。

7. 堆排序（Heap Sort）
① 建大根堆：从最后一个非叶结点开始（位置 n/2-1），
向下调整 heapify
② 取堆顶（最大值）和最后一个元素交换，堆大小减 1
③ 对新的堆顶做 heapify
④ 重复 ②③ 直到堆空

记住：O(nlogn)，不稳定，空间 O(1)。
考试中常考"建堆的过程"——给你一个序列，画出建堆过程。

### 第4周 · 星期一-二：4 种算法策略（分治/DP/贪心/回溯）
---
### 手机摸鱼
核心知识点

1. 分治法（Divide and Conquer）

三步：分解 → 解决（递归）→ 合并
和 DP 的区别：子问题独立，无重叠。
经典算法：归并排序、快速排序、二分查找。

2. 动态规划（Dynamic Programming）

和分治的核心区别：子问题有重叠！如果重复计算相同的子问题，
用表记录下来避免重复，就是 DP。

两个条件缺一不可：
① 最优子结构：问题的最优解包含子问题的最优解
② 子问题重叠：不同决策路径会遇到相同的子问题

经典例题：斐波那契、0-1 背包、最长公共子序列 LCS

例：斐波那契
递归（分治）：fib(n) = fib(n-1)+fib(n-2) → O(2^n)，大量重复计算
DP（记忆化）：dp[i]=dp[i-1]+dp[i-2] → O(n)，每项只算一次

例：LCS（最长公共子序列）
s1=ABCBDAB, s2=BDCABA
dp[i][j] = s1 前 i 个字符和 s2 前 j 个字符的 LCS 长度
if s1[i]==s2[j]: dp[i][j] = dp[i-1][j-1] + 1
else:            dp[i][j] = max(dp[i-1][j], dp[i][j-1])

3. 贪心法

每步选当前看起来最好的（局部最优），希望最终全局最优。
和 DP 的区别：DP 考虑所有可能，贪心每步只选一个。
不一定能得到最优解（但有些问题恰好局部最优=全局最优）。

典型应用：哈夫曼编码、最小生成树（Prim/Kruskal）、活动选择问题

4. 回溯法
试探 + 回退：深度优先遍历所有可能解，遇到不可行的就退回上一步
换另一个分支。

经典应用：N皇后问题、0-1背包（求所有可能方案的版本）、迷宫

考点速记：如何判断用哪种算法？
子问题独立无重叠 → 分治
子问题重叠 → DP
最优子结构但每步只选一个不看全局 → 贪心（注意是否一定得最优解）
需要列举所有可能解 → 回溯

- ⭐ 必考计算题，稳稳拿分！★
三步法：
① 顺推求最早(正向)：起点=0，每步累加取最大值
② 逆推求最晚(反向)：终点=最早完成时间，递减取最小值
③ 总时差=最晚-最早，时差为0的节点组成关键路径

例：活动 A(3天)→B(4天)→C(2天)，A→D(5天)→C
A 最早0→3，B 最早3→7，D 最早3→8，C 最早max(7,8)=8→10
关键路径=A→D→C=3+5+2=10天（项目最短完成时间）

三点估算公式：期望时间=(乐观+4×最可能+悲观)/6
标准差=(悲观-乐观)/6

和装饰者的区别：装饰者增强功能，代理控制访问（延迟加载、权限控制）

外观(Facade)：统一的高层接口，隐藏子系统复杂性
生活类比：遥控器的"一键关闭"——内部要关电视、关音响、关灯，但用户只按一个键

### 星期三
行为型 11 种（高频：观察者、策略、模板方法）
观察者(Observer)：一对多依赖，主题变化→通知所有观察者
生活类比：微信公众号推送
代码特征：Subject 维护一个 Observer 列表，状态变化时循环调用 observer.update()

策略(Strategy)：算法族可互相替换
生活类比：去北京可以选择飞机/高铁/自驾
代码特征：Context 持有 Strategy 接口引用，在运行时切换具体策略

模板方法：定义算法骨架，子类重写特定步骤（钩子方法）
代码特征：父类方法调用了一系列抽象/可重写方法，子类只需实现这些方法

考场技巧：设计模式关键字匹配法
"唯一实例" → 单例
"动态添加功能/层层包装" → 装饰者
"接口转换/适配" → 适配器
"一对多通知/订阅/监听" → 观察者
"算法互换/根据不同情况选不同方案" → 策略
"步骤固定但细节不同" → 模板方法
"延迟创建/按需加载" → 代理（虚代理）

### 第8周 · 操作系统（PV 操作 + 银行家 + 页面置换）
---
### 星期一
PV 操作与信号量 ★必考大题★
P 操作（申请资源）：S=S-1; if S<0 → 阻塞自己，放入等待队列
V 操作（释放资源）：S=S+1; if S≤0 → 唤醒一个等待进程

互斥信号量 mutex 初值=1：保证同一时刻只有一个进程访问临界区
同步信号量 empty/full：控制资源的数量

生产者-消费者模板（背！）：
生产者：P(empty) → P(mutex) → 放入产品 → V(mutex) → V(full)
消费者：P(full) → P(mutex) → 取出产品 → V(mutex) → V(empty)

- ⭐ 死锁考点：P(empty)和P(mutex)顺序不能错！
如果先P(mutex)再P(empty)：
生产者拿到mutex后发现empty=0 → 阻塞等消费者释放empty
但消费者需要P(mutex)才能消费 → mutex被生产者占着
死锁！两个进程互相等待对方释放资源。

晚上：手写生产者消费者代码，在白板上画信号量的变化过程。
做 5 道 PV 操作真题。

### 星期二
银行家算法
步骤：
① 计算 Need = Max - Allocation（还需要的资源数）
② 找一个 Need ≤ Available（当前可满足）的进程
③ 假分配：Available += Allocation（该进程完成任务释放资源）
④ 标记该进程已执行
⑤ 重复②-④直到所有进程都执行过（存在安全序列）或无法继续（不安全）

晚上：做 3 道银行家算法手算题

### 星期三
页面置换算法
- ⭐ 必考计算题 ★
OPT（最佳）：淘汰未来最远才用到的页 → 理论最优，实际不可实现
FIFO：淘汰最早进来的页 → 可能有 Belady 异常（增加物理块反而缺页更多！）
LRU：淘汰最近最少使用的页 → 性能最好，但实现开销大

缺页率 = 缺页次数 / 总访问次数

手算步骤（以 LRU 为例）：
给访问序列和物理块数，画一个表格，行=时刻/列=块号
每次访问后更新表格，最久未用的在底部，新访问的在顶部
数缺页多少行标记了"×"

晚上：同一个序列分别用 OPT/FIFO/LRU 算缺页次数，对比三种算法的缺页率

### 星期四
分页 + 分段 + 段页式
分页：等大小页面。逻辑地址=页号+页内偏移，物理地址=块号+块内偏移
分段：不等长段（更符合程序逻辑结构）
段页式：先分段再分页（取两者的优点）

地址变换过程（给逻辑地址求物理地址）：
① 从逻辑地址拆出页号和偏移量：页号=地址/页面大小，偏移=地址%页面大小
② 查页表：页号→块号
③ 物理地址=块号×块大小+偏移

晚上：做 10 道地址变换计算题

### 星期一-二
计组计算题专项
补码运算：正数补码=原码，负数补码=反码+1
移码 = 补码符号位取反（用于浮点数阶码）

IEEE 754 单精度：(-1)^S × 1.M × 2^(E-127)
S(1bit 符号) + E(8bit 阶码) + M(23bit 尾数)
例：-6.625 = 110.101₂ = 1.10101×2²
S=1, E=2+127=129=10000001₂, M=1010100...
结果是 1 10000001 10101000000000000000000

流水线吞吐率 = 指令数 / 执行时间
加速比 = 不用流水线时间 / 用流水线时间

Cache 平均访问时间 = 命中率 × Cache时间 + (1-命中率) × 主存时间

晚上：做 15 道补码/IEEE754/流水线/Cache 计算题

### 星期三-四
数据库设计专项（下午题第 2 题核心技能）
- ⭐ ER 图转关系模式口诀（背！）★
实体 → 关系（属性=列，主键=主键）
M:N 联系 → 独立关系（双方主键组成联合主键 + 联系自身属性）
1:N 联系 → 并入 N 端（1端主键作为 N 端外键）
1:1 联系 → 并入任一端

范式判断三步骤（秒杀题）：
① 找候选键（属性组合能唯一标识一个元组且不可再少）
② 分主属性和非主属性（属于候选键的属性→主属性；其余→非主属性）
③ 判断依赖：
非主属性部分依赖候选键 → 不是 2NF（消除后→2NF）
非主属性传递依赖候选键 → 不是 3NF（消除后→3NF）

关系代数（选择题常考）：
σ(选择)——选行；π(投影)——选列
⋈(连接)——两表按条件拼接；÷(除)——找到"满足所有条件"的元组

SQL 关键语法：SELECT...FROM...WHERE...GROUP BY...HAVING...ORDER BY
执行顺序：FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY
（很多考生记反！先分组再筛选，HAVING 在 GROUP BY 之后执行）
```
