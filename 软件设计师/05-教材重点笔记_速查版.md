# 第1章 计算机系统知识（6分/75）

## 1.1 数据表示

### 进制转换
- **R进制→十进制**：按权展开求和
- **十进制→R进制**：整数除R取余（倒序），小数乘R取整（正序）
- **二↔八**：3位一组；**二↔十六**：4位一组

### 原码/反码/补码/移码

| 编码 | 正数规则 | 负数规则 | 0的表示 | 范围（8位） |
|------|---------|---------|---------|------------|
| 原码 | 符号位0+数值 | 符号位1+数值 | +0和-0 | -127~+127 |
| 反码 | 同原码 | 原码数值位取反 | +0和-0 | -127~+127 |
| 补码 | 同原码 | 反码+1 | 唯一0 | **-128~+127** |
| 移码 | 补码符号位取反 | 补码符号位取反 | 唯一0 | -128~+127 |

> **核心**：计算机内部用补码运算；移码用于浮点数阶码

### 浮点数
- **IEEE 754 单精度（32位）**：1位符号 + 8位阶码（移码，偏移127） + 23位尾数
- **IEEE 754 双精度（64位）**：1位符号 + 11位阶码（移码，偏移1023） + 52位尾数
- **规格化**：尾数最高位必须为1（隐含位）

### 校验码

| 类型 | 原理 | 检错能力 | 纠错能力 |
|------|------|---------|---------|
| 奇偶校验 | 1的个数奇/偶 | 奇数位错 | 无 |
| CRC | 模2除法 | 任意位错 | 无 |
| **海明码** | 分组奇偶校验 | 2位错 | **1位错** |

> **海明码关键公式**：2^k ≥ n + k + 1（k为校验位，n为数据位）

## 1.2 CPU 组成

```
CPU = 运算器（ALU/AC/DR/PSW） + 控制器（PC/IR/ID/时序）
```

- **PC（程序计数器）**：存放下条指令地址，自动+1
- **IR（指令寄存器）**：存放当前执行指令
- **ALU（算术逻辑单元）**：执行算术/逻辑运算
- **PSW（状态字寄存器）**：存标志位（进位/溢出/零/符号）

> **CISC vs RISC**：CISC 指令复杂可变长（x86），RISC 指令精简定长（ARM/MIPS），RISC 用大量寄存器、硬布线控制

### 流水线
- **流水线周期** = 执行时间最长的段
- **流水线执行时间** = 1条指令总时间 + (n-1) × 流水线周期
- **吞吐率** = n / 总时间
- **加速比** = 不用流水线的时间 / 用流水线的时间

> **三种冲突**：资源冲突、数据冲突（RAW/WAR/WAW）、控制冲突

## 1.3 存储系统

### 层次结构（速度↓容量↑）
```
寄存器 → Cache → 主存 → 外存
```

### Cache 映射方式

| 方式 | 特点 | 冲突概率 |
|------|------|---------|
| 直接映射 | 主存块号 mod Cache行数，**简单** | 高 |
| 全相联 | 任意位置，灵活性最高 | 低 |
| 组相联 | 组内全相联，组间直接映射 | 中（主流） |

> **命中率 H** = Cache命中次数 / 总访问次数
> **平均访问时间 T** = H × T_cache + (1-H) × T_mem

### 主存编址
- **按字编址**：每个存储单元为一个字
- **按字节编址**：每个存储单元为一个字节
- **地址线 n 根 → 寻址 2^n 个单元**

### I/O 方式

| 方式 | CPU参与度 | 速度 | 适用 |
|------|----------|------|------|
| 程序查询 | CPU全程控制 | 慢 | 简单设备 |
| 程序中断 | 外设主动通知CPU | 中 | 一般I/O |
| **DMA** | CPU只参与开始/结束 | **快** | 高速批量传输 |

## 1.4 可靠性

- **MTTF**（平均无故障时间）、**MTTR**（平均修复时间）
- **MTBF** = MTTF + MTTR（平均故障间隔）
- **系统可用性** = MTTF / MTBF × 100%

**串联系统可靠性** = R1 × R2 × ... × Rn
**并联系统可靠性** = 1 - (1-R1)(1-R2)...(1-Rn)

# 第2章 程序设计语言基础（6分/75）

## 2.1 语言分类

| 类别 | 代表 | 特点 |
|------|------|------|
| 机器语言 | 二进制代码 | 计算机直接执行 |
| 汇编语言 | MOV/ADD | 助记符，需汇编 |
| 高级语言 | C/Java/Python | 需编译或解释 |
| 4GL | SQL | 非过程化 |

## 2.2 编译过程（高频必考）

```
源程序 → 词法分析 → 语法分析 → 语义分析 → 中间代码 → 代码优化 → 目标代码
```

| 阶段 | 输入 | 输出 | 工具/方法 |
|------|------|------|----------|
| 词法分析 | 字符流 | 记号流(token) | 正规式、有限自动机 |
| 语法分析 | 记号流 | 语法树 | 上下文无关文法、推导/归约 |
| 语义分析 | 语法树 | 带标注的语法树 | 类型检查、作用域分析 |
| 中间代码生成 | 语法树 | 三地址码/四元式 | — |
| 代码优化 | 中间代码 | 优化后中间代码 | — |
| 目标代码生成 | 中间代码 | 机器码 | 寄存器分配 |

> **解释 vs 编译**：编译是**整体翻译**再执行；解释是**逐句翻译**并执行。解释灵活性高，编译执行速度快。

## 2.3 文法

- **0型**（短语文法）：无限制，图灵机
- **1型**（上下文有关）：αAβ → αγβ
- **2型**（上下文无关）：A → γ（语法分析用）
- **3型**（正规文法）：A → aB 或 A → a（词法分析用）

## 2.4 自动机

- **DFA（确定有限自动机）**：每个状态对每个输入有唯一转移
- **NFA（非确定有限自动机）**：可有多个转移或空转移
- **DFA 与 NFA 等价**，可互相转换

## 2.5 传值与传址

| 方式 | 原理 | 影响 |
|------|------|------|
| **传值（call by value）** | 拷贝实参值 | 不改变实参 |
| **传址（call by reference）** | 传递地址 | **改变实参** |

> **常考题**：给一段交换函数代码，问最终变量值。传值交换无效，传址交换有效。

# 第3章 数据结构（9分/75 + 算法基础）

## 3.1 线性表

### 顺序表 vs 链表

| 操作 | 顺序表 | 链表 |
|------|--------|------|
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1) |
| 空间 | 连续，需预分配 | 动态，有指针开销 |

### 栈与队列

| | 特点 | 常见应用 |
|------|------|------|
| **栈** | LIFO（后进先出） | 函数调用、表达式求值、括号匹配 |
| **队列** | FIFO（先进先出） | BFS、缓冲区、打印队列 |
| 循环队列 | 队空：front==rear；队满：(rear+1)%MAX==front | — |

> **后缀表达式（逆波兰）求值**：遇操作数入栈，遇运算符弹出两操作数计算

## 3.2 树（核心重点）

### 二叉树性质
1. 第 i 层最多 2^(i-1) 个节点
2. 深度为 k 的二叉树最多 2^k - 1 个节点
3. **n0 = n2 + 1**（度为0的节点数 = 度为2的节点数 + 1）

### 遍历方式

| 方式 | 顺序 |
|------|------|
| 先序（根左右） | 根 → 左子树 → 右子树 |
| 中序（左根右） | 左子树 → 根 → 右子树 |
| 后序（左右根） | 左子树 → 右子树 → 根 |
| 层次 | 从上到下，从左到右 |

> **已知 前序+中序 或 后序+中序 → 唯一确定二叉树**。前序+后序不能唯一确定。

### 哈夫曼树（最优二叉树）
- **带权路径长度 WPL** = Σ 叶子权值 × 路径长度
- 构建：每次选**权值最小**的两个节点合并
- WPL 最小，用于数据压缩

### 二叉排序树（BST）
- 左子树 < 根 < 右子树
- 中序遍历得**递增序列**

### 平衡二叉树（AVL）
- |左子树深度 - 右子树深度| ≤ 1
- LL / RR / LR / RL 四种旋转

## 3.3 图

### 存储方式
- **邻接矩阵**：n×n 矩阵，O(n²) 空间，适合稠密图
- **邻接表**：链表数组，O(n+e) 空间，适合稀疏图

### 遍历
- **DFS**：栈/递归，一条路走到底
- **BFS**：队列，逐层展开

### 最小生成树
- **Prim 算法**：从点出发，每次加最短边（O(n²)，适合稠密图）
- **Kruskal 算法**：边排序，用并查集防环（O(elog₂e)，适合稀疏图）

### 拓扑排序
- 每次选入度为0的顶点输出，删除其出边
- **AOV 网**（有向无环图）才有拓扑序列

### 关键路径（AOE 网）
- **关键路径** = 最长路径，决定项目最短工期
- 关键活动：最早开始 = 最晚开始（松弛时间为0）

### 最短路径
- **Dijkstra**：单源最短路径，**不能有负权边**（O(n²)）
- **Floyd**：所有顶点对最短路径（O(n³)）

## 3.4 查找

| 方法 | 平均查找长度 ASL | 前提 |
|------|-----------------|------|
| 顺序查找 | (n+1)/2 | 无 |
| 折半查找 | log₂(n+1)-1 | **有序顺序表** |
| 分块查找 | (b+s)/2+1 | 块间有序 |
| 哈希查找 | 取决于冲突处理 | 构造哈希函数 |

### 哈希冲突处理
- **开放定址法**：线性探测 / 二次探测 / 随机探测
- **链地址法**：同义词放在同一链表

### B树
- **m 阶 B树**：每个节点最多 m 个子树，最少 ⌈m/2⌉ 个子树（根除外）
- 关键字数 = 子树数 - 1
- 所有叶子在同一层

## 3.5 排序

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|---------|---------|------|--------|
| 直接插入 | O(n²) | O(n²) | O(1) | **稳定** |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆排序 | **O(nlog₂n)** | O(nlog₂n) | O(1) | 不稳定 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | **稳定** |
| 快速排序 | **O(nlog₂n)** | O(n²) | O(log₂n) | 不稳定 |
| 归并排序 | **O(nlog₂n)** | O(nlog₂n) | O(n) | **稳定** |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(r) | **稳定** |

> - **快排最坏**：每次选的基准都是最值（已有序/逆序）
> - **堆排序建堆**：从 n/2 处向前调整，O(n)
> - **归并排序**：唯一需要 O(n) 额外空间的 O(nlog₂n) 排序

# 第4章 操作系统（6分/75）

## 4.1 进程管理

### 进程三态/五态
```
三态：就绪 → 运行 → 阻塞 → 就绪
五态：新建 → 就绪 → 运行 → 阻塞 → 终止
```
- **就绪→运行**：被调度选中
- **运行→就绪**：时间片用完
- **运行→阻塞**：等待I/O或事件
- **阻塞→就绪**：I/O或事件完成

### ★ PV 操作（必考大题）

```c
P(S):  S = S - 1;  if S < 0 then 阻塞该进程
V(S):  S = S + 1;  if S ≤ 0 then 唤醒一个等待进程
```

> **S 的物理意义**：S>0 表示可用资源数；S<0 表示等待进程数

**经典同步模型**：
- **生产者-消费者**：互斥信号量（初值1）+ 空缓冲区信号量 + 满缓冲区信号量
- **读者-写者**：读可共享，写需独占

### 死锁

**四个必要条件（缺一不可）**：
1. 互斥条件
2. 请求保持（部分分配）
3. 不可剥夺
4. **环路等待**

**死锁避免—银行家算法**：
- 每个进程声明最大需求
- 分配前检查是否存在安全序列
- 存在安全序列 → 可分配；否则 → 拒绝

**死锁定理**：资源分配图中存在环路且资源类只有一个实例 → 死锁

## 4.2 存储管理

### 分页存储

- **逻辑地址** = 页号P + 页内偏移W
- **物理地址** = 页帧号（从页表查得）× 页大小 + 页内偏移W
- **页表**存在内存，**TLB（快表）**缓存活跃页表项

> **页大小 4KB = 12位偏移**，逻辑地址除以页大小取商（页号）余数（偏移）

### 分段存储
- 按逻辑单位分段（代码段/数据段/堆栈段）
- 段表项：段基址 + 段长 + 访问权限

### 段页式 = 分段 + 分页
- 逻辑地址 → 段表 → 页表 → 物理地址
- 三次访问内存（可用TLB降低）

### 页面置换算法

| 算法 | 原理 | 特点 |
|------|------|------|
| **OPT（最佳）** | 淘汰未来最远才用的页 | 理论最优，无法实现 |
| **FIFO** | 淘汰最早进入的页 | 有**Belady异常** |
| **LRU（最近最久未用）** | 淘汰最久没用过的 | 性能好，开销大 |
| **CLOCK（时钟）** | 近似LRU，访问位轮转 | 实用，Unix使用 |

> **Belady 异常**：增加页帧数反而缺页次数增加（仅 FIFO 有）

## 4.3 磁盘调度

| 算法 | 策略 |
|------|------|
| FCFS（先来先服务） | 按请求顺序 |
| SSTF（最短寻道） | 选最近磁道，可能饥饿 |
| **SCAN（电梯）** | 单向移动到底再折返 |
| **C-SCAN** | 单向移动到底，快速返回起点（不服务） |
| **LOOK / C-LOOK** | 到最远请求即折返 |

## 4.4 文件管理

### 文件物理结构

| 方式 | 特点 |
|------|------|
| 连续分配 | 简单、查找快，外碎片 |
| 链接分配 | 无外碎片，随机访问慢 |
| **索引分配** | i-node 集中存储指针，**Unix/Linux 多级索引** |

### 索引文件结构（常考计算）

> 索引节点大小=1KB，地址项大小=4B → 最多 256 个直接索引项
> 一级间接：256×(1KB/4B)=256×256=65536个块
> 二级间接：256³ 个块

### 位示图
- 每bit对应一个物理块，0=空闲，1=占用
- **第 i 行第 j 列对应的块号** = i × 每行位数 + j

# 第5章 软件工程基础（13分/75 ★★★）

## 5.1 软件过程模型

| 模型 | 特点 | 适用场景 |
|------|------|---------|
| **瀑布模型** | 阶段间严格顺序，文档驱动 | 需求明确、稳定的项目 |
| **增量模型** | 分模块分批交付 | 需求较明确，可分模块 |
| 演化/原型模型 | 快速原型→反馈→修改 | 需求模糊的项目 |
| **螺旋模型** | 引入**风险分析**，迭代 | 大型高风险项目 |
| 喷泉模型 | **面向对象**，迭代无间隙 | OO 项目 |
| **RUP/UP** | 用例驱动、架构中心、迭代 | 面向对象统一过程 |
| **敏捷开发** | 轻文档、快速迭代、客户协作 | 需求多变的小团队 |

### 敏捷方法
- **XP（极限编程）**：结对编程、持续集成、TDD
- **Scrum**：Sprint（冲刺）、每日站会、Product Backlog / Sprint Backlog
- **看板**：可视化流程、限制 WIP

## 5.2 软件测试

### ★ McCabe 环路复杂度（必考）

```
V(G) = m - n + 2
     = 判断节点数 + 1
     = 封闭区域数 + 1
```
> m = 边数，n = 节点数

**测试用例数** = 环路复杂度（基本路径覆盖至少需要 V(G) 条路径）

### 测试分类

| 维度 | 类型 | 说明 |
|------|------|------|
| 是否执行 | 静态测试 | 代码审查、静态分析（不运行程序） |
| | 动态测试 | 运行程序 |
| 是否看代码 | **黑盒测试** | 不看代码，关注输入输出 |
| | **白盒测试** | 基于代码逻辑 |

### 黑盒测试方法
- **等价类划分**：有效等价类 + 无效等价类
- **边界值分析**：边界值及其左右
- 因果图、决策表、正交实验

### 白盒测试方法（覆盖标准从弱到强）
```
语句覆盖 → 判定覆盖 → 条件覆盖 → 判定/条件覆盖 → 条件组合覆盖 → 路径覆盖
```

### 测试阶段

| 阶段 | 测试对象 | 关注点 |
|------|---------|--------|
| **单元测试** | 最小模块 | 模块接口、内部逻辑 |
| **集成测试** | 模块间接口 | 模块协作 |
| **确认测试** | 整个系统 | 是否满足需求 |
| **系统测试** | 完整系统+环境 | 性能/负载/安全 |

> **驱动模块**：模拟上层调用；**桩模块**：模拟被调用模块

### 测试策略
- **自顶向下**：从主控模块开始，需要桩模块 → 早期可见框架
- **自底向上**：从底层开始，需要驱动模块 → 底层模块先测好
- **三明治**：上层自顶向下，下层自底向上，中间会合

## 5.3 项目管理

### ★ PERT 图（必考）

### 进度管理
- **甘特图**：横道图，直观但不反映任务依赖
- **PERT图**：网络图，反映依赖关系

- **中间 COCOMO**：考虑产品/硬件/人员/项目属性
- **详细 COCOMO**：分阶段估算

```
风险暴露（RE）= 风险发生概率 × 风险造成损失
```

# 第8章 算法设计与分析（下午题4 ★★★）

## 8.1 算法分析基础

- **时间复杂度**：O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
- **空间复杂度**：算法运行所需辅助空间

## 8.2 ★ 五大算法策略（下午题4核心）

### 1. 分治法

| 步骤 | 分解→求解→合并 |
|------|------|
| 特征 | 问题可分解为独立子问题，子问题与原问题同构 |

**常考算法**：
- **归并排序**：T(n) = 2T(n/2) + O(n) → **O(nlog₂n)**
- **快速排序**：平均 O(nlog₂n)，最坏 O(n²)
- 二分查找：O(log₂n)
- 大整数乘法（Karatsuba）

### 2. ★ 动态规划 DP

| 特征 | 最优子结构 + 子问题重叠 |
|------|------|
| 与分治区别 | 子问题**不独立**，有重叠 |
| 实现方式 | 自底向上（填表）+ 备忘录 |

**常考算法**：
- **0/1 背包**：dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)
- **最长公共子序列 (LCS)**
- **矩阵连乘**：最少乘法次数
- **Floyd 最短路径**：dp\[k\]\[i\]\[j\] = min(dp\[k-1\]\[i\]\[j\], dp\[k-1\]\[i\]\[k\] + dp\[k-1\]\[k\]\[j\])

### 3. 贪心法

| 特征 | 每步局部最优 → 全局最优 |
|------|------|
| 前提 | 必须满足贪心选择性质和最优子结构 |

**常考算法**：
- **Prim / Kruskal（最小生成树）**
- **Dijkstra（最短路径）**
- **哈夫曼编码**
- 活动选择/区间调度
- 部分背包（可分割）

> **DP vs 贪心**：DP 考虑所有子问题，贪心只做当前最优选择。0/1背包用DP，部分背包用贪心。

### 4. 回溯法

| 特征 | 深度优先 + 剪枝，求所有解/最优解 |
|------|------|
| 框架 | 试探 → 满足条件则前进 → 不满足则回溯 |

**常考**：
- N皇后问题
- 0/1背包（回溯求解）
- 图的着色
- 哈密顿回路

### 5. 分支限界法

| 特征 | 广度优先/最小代价优先 + 限界剪枝 |
|------|------|
| 与回溯区别 | 回溯是DFS，分支限界是BFS/优先队列 |
| 常用 | 求最优解（TSP、任务分配） |

## 8.3 算法策略识别（下午题4核心技能）

| 代码特征 | 算法策略 |
|---------|---------|
| 函数递归调用，每次规模减半，最后合并结果 | **分治** |
| 双重循环填二维数组，`dp[i] = max(dp[i-1]..., dp[i-n]+w)` | **DP** |
| 每步选最大值/最小值，不回溯 | **贪心** |
| 递归搜索+`if(不满足) return`（剪枝） | **回溯** |
| 用队列/优先队列，有上界/下界判断 | **分支限界** |

## 9.5 ★ 范式规范化（常考）

### 各级范式

| 范式 | 条件 | 常见问题 |
|------|------|---------|
| **1NF** | 属性不可再分（原子性） | 数据冗余、更新异常 |
| **2NF** | 1NF + 非主属性完全依赖于主键（消除**部分函数依赖**） | 传递依赖引起冗余 |
| **3NF** | 2NF + 非主属性不传递依赖于主键 | 仍可能有更新异常 |
| **BCNF** | 3NF + 主属性不部分/传递依赖于候选键 | — |

### 快速判断范式
1. 找候选键（能唯一标识元组的属性组）
2. 列出函数依赖
3. 检查：部分依赖 → 不是2NF；传递依赖 → 不是3NF

> **模式分解**：分解后必须**无损连接**，最好**保持函数依赖**

## 9.6 事务与并发控制

### ★ ACID 特性
- **原子性 Atomicity**：全做或全不做
- **一致性 Consistency**：事务前后数据库一致
- **隔离性 Isolation**：事务间不干扰
- **持久性 Durability**：提交后永久保存

### 并发问题
- **丢失更新**：两个事务同时改同一数据
- **不可重复读**：读了两次得到不同值
- **读脏数据**：读了未提交的数据（可能回滚）

### 封锁协议

| 协议 | 要求 | 解决 |
|------|------|------|
| 一级封锁 | 修改前加X锁，事务结束释放 | 丢失更新 |
| 二级封锁 | 一级 + 读前加S锁，读完释放 | 丢失更新 + 读脏数据 |
| 三级封锁 | 一级 + 读前加S锁，事务结束释放 | 全部问题 |
| 两段锁（2PL） | 先统一加锁，后统一释放 | 可串行化 |

## 10.2 ★ 子网划分（常考计算题）

### IP 地址分类

| 类别 | 范围 | 默认掩码 | 网络/主机位 |
|------|------|------|------|
| A类 | 1.0.0.0 ~ 126.255.255.255 | 255.0.0.0 | 8/24 |
| B类 | 128.0.0.0 ~ 191.255.255.255 | 255.255.0.0 | 16/16 |
| C类 | 192.0.0.0 ~ 223.255.255.255 | 255.255.255.0 | 24/8 |

### 子网划分核心公式

```
子网数 = 2^n（n=借用的主机位数）
每子网可用IP数 = 2^m - 2（m=剩余主机位数，减2因为网络地址和广播地址）
子网掩码 = 网络位+子网位全1，主机位全0
```

- **包过滤防火墙**：检查包头（网络层/传输层）
- **应用代理防火墙**：检查应用层内容
- **状态检测防火墙**：记录连接状态，最常用

### 安全协议

| 协议 | 层 | 用途 |
|------|------|------|
| **SSL/TLS** | 传输层 | Web 安全（HTTPS） |
| **IPSec** | 网络层 | VPN |
| **PGP** | 应用层 | 电子邮件加密 |
| **SET** | 应用层 | 电子商务安全 |
| **SSH** | 应用层 | 安全远程登录 |

# 第11章 标准化与知识产权（3分/75）

## 11.1 标准化

### 标准分级
**国际标准（ISO/IEC）→ 国家标准（GB）→ 行业标准 → 地方标准 → 企业标准**

### 标准类型
- **强制性标准**：必须执行
- **推荐性标准**：自愿采用（GB/T）

## 11.2 ★ 知识产权（常考选择题）

### 保护对象与期限

| 类型 | 保护对象 | 保护期限 |
|------|---------|---------|
| **著作权（版权）** | 文学/艺术/科学作品/软件 | 作者终生 + 死后 **50 年**（单位作品：发表后 50 年） |
| **专利权—发明** | 新产品/方法 | 申请日起 **20 年** |
| **专利权—实用新型** | 产品形状/构造 | 申请日起 **10 年** |
| **专利权—外观设计** | 产品外观 | 申请日起 **15 年** |
| **商标权** | 商标标识 | 注册日起 **10 年**（可续展） |
| **商业秘密** | 非公开技术/经营信息 | **无固定期限**（保密期内） |

### ★ 著作权归属判定

| 情形 | 归属 |
|------|------|
| 个人创作 | **作者** |
| 职务作品（一般） | 作者享有署名权，单位有优先使用权（2年内） |
| 职务作品（特殊，利用单位物质技术条件） | 署名权归作者，其他权利归**单位** |
| 委托创作 | **按合同约定**；无约定归受托人（创作者） |
| 合作作品 | 合作者共有 |

### 侵权判定
- 引用他人作品需注明出处，不得构成主要部分
- 为个人学习/研究/欣赏使用他人作品 → **不侵权**
- 未经许可复制/发行/改编 → **侵权**
- 软件反向工程（合法取得）→ 一般**不侵权**（研究兼容性）

### 专利
- 授予条件：**新颖性、创造性、实用性**
- 不授予专利：科学发现、智力活动规则、疾病诊断方法、动植物品种、原子核变换方法
